# Superpowers Skills 触发词

## 核心高频

| 技能 | 触发词 |
|------|--------|
| claude code规划 | 模糊想法、没想清楚、帮我规划、怎么做、思路、方案 |
| version-planner | 拆版本、版本规划、MVP、分阶段 |
| subagent-driven | 开工、开始执行、跑起来 |
| TDD | 写测试、TDD、单元测试 |
| debugging | 调试、排查、bug、报错、修复 |

## 其他高频

| 技能 | 触发词 |
|------|--------|
| frontend-design | 前端、极致美学、界面设计参考 |
| skill-creator | 创建/优化/测试 skill |
| commit | 提交、commit、push |
| code-review | 审查、检查代码 |
| code-simplifier | 简化、重构、优化代码 |

## 核心原则

- **先想后做**：模糊需求 → claude code规划收敛 → version-planner 拆版本 → subagent 执行
- **强制设计门槛**：未经用户确认设计，不得写代码
- **TDD 优先**：RED-GREEN-REFACTOR，不先写实现
- **小步提交**：每 2-5 分钟任务完成后即 commit
