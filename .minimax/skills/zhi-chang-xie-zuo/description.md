# 职场写作技能

将工作成果转化为专业书面表达的专业工具。让你的每一份工作成果都能被看见、被认可、被归档。

## 核心价值

- **成果化思维**：把日常工作成果转化为可积累、可追溯、可传播的专业文档
- **行动导向**：每一份职场写作都要促成明确的结果，而非仅仅"写完了"
- **用户意识**：让信息真正抵达受众，而非自说自话
- **默认公开**：写出来就要禁得起检验，经得起传阅

## 适用场景

- 周报月报：提高工作透明度，让协作更顺畅
- 会议纪要：高效记录并推进执行
- 工作计划：赢得对工作的掌控感
- 方案建议：提升说服力，推动决策
- 复盘报告：留给下一任的信
- 年终总结 / 竞聘报告：面向明年的价值展示
- 申请报告：争取最大支持
- 公开讲话：管理听众注意力

## 使用方式

用户提供场景背景和关键信息，技能自动：

1. **确认写作目标** — 明确这份文档要达成什么结果
2. **分析受众** — 谁会读？他们的关注点是什么？
3. **构建框架** — 按文体类型组织内容结构
4. **输出内容** — 按职场写作规范生成文档
5. **核验合规** — 检查行动导向、用户意识、默认公开三原则

---

## 底层原理：三大原则（必须遵守）

### 原则一：导向行动

职场写作的本质不是"记录"，而是"促成结果"。

**要求：**
- 每份文档必须有一个明确的"下一步"
- 读者知道他们需要做什么
- 有清晰的时间节点

### 原则二：用户意识

每一份文档都有它的受众。下笔之前，必须先回答：
- 这份文档的受众是谁？
- 他们的关注点是什么？
- 他们现在处于什么状态？

### 原则三：默认公开

职场文档不是私密日记，是公共传播的载体。
- 每一个数据都有来源
- 表达克制，不夹带私货
- 前后文逻辑自洽

---

## 核心设计：约束 + 空间

职场写作的输出质量依赖于两个维度：

| 维度 | 说明 |
|------|------|
| **约束层** | 三大原则 + 结构要求 + 质量红线（不可突破） |
| **空间层** | 表达方式、结构选择、细节填充、案例选择（AI自主） |

**约束层必须遵守，空间层允许发挥。**

好的职场写作，既不是填模板，也不是自由发挥，而是在约束和空间之间找到最佳位置。

---

## 文体类型与结构要求

| 文体 | 核心目标 | 约束要求 |
|------|----------|----------|
| 周报 | 提高工作透明度 | 必须有：进度/成果/计划/风险 |
| 会议纪要 | 高效推进执行 | 必须有：决策/待办(含责任人和时间) |
| 工作计划 | 赢得掌控感 | 必须有：目标/路径/资源/时间节点 |
| 方案建议 | 提升说服力 | 必须有：问题/方案/预期回报/风险 |
| 复盘报告 | 知识传承 | 必须有：事实/分析/改进建议 |
| 年终总结 / 竞聘 | 面向明年 | 必须有：成果量化/能力定位/规划 |
| 申请报告 | 争取支持 | 必须有：理由/请求/预期回报/成本说明 |
| 公开讲话 | 管理注意力 | 必须有：听众视角/记忆点/行动指向 |

**约束说明：**
- "必须有"列是最低要求，不是固定模板
- 具体怎么呈现，由AI根据场景和受众判断
- 同一文体可以有多种结构方式

---

## 质量红线（任何情况下都不可突破）

1. **事实准确**：数据有来源，描述可核实
2. **逻辑自洽**：前后文不矛盾，结论有依据
3. **受众匹配**：信息排列按读者逻辑，不是按作者逻辑
4. **行动明确**：读者知道下一步该做什么
5. **时间节点**：所有待办/计划必须有截止时间

---

## AI自主空间（可以自由发挥）

| 方面 | AI可以自主决定 |
|------|---------------|
| **结构选择** | 根据内容复杂度选择：线性/模块/叙事结构 |
| **表达方式** | 根据受众选择：正式/简洁/口语化 |
| **案例填充** | 根据领域选择合适的比喻、案例、数据 |
| **细节程度** | 根据场景决定展开的颗粒度 |
| **格式装饰** | emoji使用、标题层级、段落长度 |

**判断原则：**
- 如果受众是高层决策者 → 结构优先于细节
- 如果受众是执行者 → 步骤和交付物要详细
- 如果内容复杂 → 先结论后展开
- 如果内容简单 → 直接切入不要铺垫

---

## 输出规范

每份文档输出时，AI需要自己核验：

**✅ 约束层核验**
- [ ] 三大原则都满足了吗？
- [ ] 文体要求的"必须有"都包含了吗？
- [ ] 质量红线都没有突破？

**✅ 空间层选择**（在文档完成后说明）
- 我为什么选择这个结构？
- 我为什么选择这种表达方式？
