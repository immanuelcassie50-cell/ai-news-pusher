# 职场写作术语表

## 核心概念

| 术语 | 定义 |
|------|------|
| 成果化 | 将日常工作转化为可积累、可追溯、可传播的专业文档的思维方式 |
| 行动导向 | 职场写作的核心目标是"促成结果"，不是"写完了" |
| 用户意识 | 写作前先想清楚谁在读、他们关心什么、他们处于什么状态 |
| 默认公开 | 职场文档不是私密日记，是公共传播的载体，写出来就要禁得起传阅 |
| 约束层 | 职场写作中必须遵守的部分：三大原则 + 结构要求 + 质量红线 |
| 空间层 | 职场写作中AI可以自主决定的部分：结构选择/表达方式/细节程度/格式装饰 |

---

## 三大底层原则

| 原则 | 核心要求 |
|------|----------|
| 导向行动 | 每份文档必须有一个明确的"下一步"，读者知道他们需要做什么，有时间节点 |
| 用户意识 | 下笔前回答三个问题：受众是谁？关注点是什么？现在处于什么状态？ |
| 默认公开 | 事实准确、表达克制、逻辑自洽——文档写出来就要禁得起传阅 |

---

## 文体相关

| 文体 | 核心目标 | 必须包含的要素 |
|------|----------|----------------|
| 周报 | 提高工作透明度 | 进度/成果/计划/风险 |
| 会议纪要 | 高效推进执行 | 决策记录/待办(含责任人和时间) |
| 工作计划 | 赢得掌控感 | 目标/路径/资源/时间节点 |
| 方案建议 | 提升说服力 | 问题/方案/预期回报/风险 |
| 复盘报告 | 知识传承 | 事实还原/原因分析/改进建议 |
| 年终总结/竞聘 | 面向明年 | 成果量化/能力定位/规划 |
| 申请报告 | 争取支持 | 理由/请求/预期回报/成本说明 |
| 公开讲话 | 管理注意力 | 听众视角/记忆点/行动指向 |

---

## 结构要素

| 术语 | 定义 |
|------|------|
| 标题区 | 文档最上方，包含类型、主题、作者、日期的部分 |
| 决策记录 | 会议纪要中，明确的结论和决定部分 |
| 待办事项 | 需要执行的具体行动，包含责任人、截止时间、交付物 |
| 风险提示 | 可能影响目标达成的阻塞点或不确定性 |
| 背景分析 | 方案/建议中，对问题和现状的描述 |
| 预期回报 | 投入后的预期效果，通常需要量化 |

---

## 质量红线

| 红线 | 说明 |
|------|------|
| 事实准确 | 每一个数据都有来源，每一段描述都可核实 |
| 逻辑自洽 | 前后文不矛盾，结论有依据 |
| 受众匹配 | 信息排列按读者逻辑，不是按作者逻辑 |
| 行动明确 | 读者知道下一步该做什么 |
| 时间节点 | 所有待办/计划必须有截止时间 |

---

## 格式相关

| 术语 | 定义 |
|------|------|
| 三要素 | 待办事项必须包含：责任人 + 截止时间 + 交付物 |
| 表格格式 | Markdown表格标准格式，用于结构化展示 |
| 时间格式 | 标准格式：YYYY-MM-DD HH:mm |
| 分隔线 | 用 `--` 或 `---` 分隔文档主要部分 |

---

## 常见问题

| 术语 | 定义 |
|------|------|
| 流水账 | 只写"做了什么"，不写"达成了什么"——周报大忌 |
| 空洞化 | 只有方案没有背景，只有结果没有过程 |
| 无节点 | 待办事项没有截止时间——无效文档 |
| 自说自话 | 不考虑受众，只按自己的逻辑写——信息无法抵达 |
| 功劳簿 | 复盘只写做得好的，不写踩过的坑——没有传承价值 |
| 机械填充 | 严格按照模板填，没有自主发挥——让文档失去生命力 |

---

## AI自主空间相关

| 术语 | 定义 |
|------|------|
| 线性结构 | 按步骤顺序组织内容，适用于内容简单、需知道"怎么做"的场景 |
| 模块结构 | 分成独立区块，便于选择性阅读，适用于内容复杂、受众需要快速定位的场景 |
| 叙事结构 | 按故事线铺垫，适用于需要说服、受众对结论有抵触的场景 |
| 颗粒度 | 内容展开的详细程度，根据场景决定展开的细致与否 |
