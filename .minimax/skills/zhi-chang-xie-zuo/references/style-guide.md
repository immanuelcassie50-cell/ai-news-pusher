# 职场写作风格规范

## 核心理念：约束 + 空间

**约束层（必须遵守）：**
- 三大底层原则（导向行动 / 用户意识 / 默认公开）
- 文体要求的"必须有"要素
- 质量红线（事实准确 / 逻辑自洽 / 受众匹配 / 行动明确 / 时间节点）

**空间层（AI自主）：**
- 结构选择：线性 / 模块 / 叙事
- 表达方式：正式 / 简洁 / 口语化
- 细节程度：展开颗粒度
- 格式装饰：emoji / 标题层级 / 段落长度

---

## 通用格式要求

- **编码**：UTF-8
- **语言**：简体中文（中文标点符号）
- **标题格式**：`【文档类型】主题 — 作者 — 日期`
- **数字**：保留适当位数，百分比保留1位小数
- **时间格式**：YYYY-MM-DD HH:mm（如 2024-03-15 14:00）

---

## 标题区规范

所有文档的标题区必须包含：

```
【文档类型】主题 — 作者 — 日期
```

示例：
```
【周报】产品部 — 张三 — 2024年第12周
【会议纪要】Q2产品规划评审 — 李四 — 2024-03-15
【申请报告】关于追加市场预算的申请 — 王五 — 2024-03-10
【竞聘报告】市场部负责人 → 市场总监 — 张三 — 2024-03-10
```

---

## 主体结构规范

### 周报结构

**约束要求：** 必须有进度/成果/计划/风险

**推荐结构：**
```
【周报】部门 — 姓名 — 第X周

📊 本周进展
✅ 已完成
  | 事项 | 成果 | 状态 |

🔄 进行中
  | 事项 | 进度 | 阻塞 |

📅 下周计划
  1. 具体计划事项

⚠️ 风险提示（如有）
  - 风险描述
```

**空间层选择：**
- 如果内容少，可以合并"已完成"和"进行中"
- 如果风险多，可以加"需要领导协调事项"
- 如果是项目周报，可以在最后加"项目里程碑进度"

---

### 会议纪要结构

**约束要求：** 必须有决策记录 + 待办事项（含责任人和时间）

**推荐结构：**
```
【会议纪要】会议主题 — 记录人 — 日期

会议信息
  - 时间：
  - 参与：
  - 记录：

📋 决策记录
  | 议题 | 结论 | 备注 |

📌 待办事项
  | 待办 | 负责人 | 截止时间 | 交付物 |

下次会议（如有）
```

**空间层选择：**
- 如果决策少，可以用文字描述而非表格
- 如果待办多，可以用分组（按责任人或按紧急程度）
- 如果有重要讨论但未形成决策，可以加"未决事项"栏

---

### 申请报告结构

**约束要求：** 必须有理由/请求/预期回报/成本说明

**推荐结构：**
```
【申请报告】申请事项 — 申请人 — 日期

申请背景
  - 问题1
  - 问题2

申请内容
  - 具体请求

预期回报
  | 投入方向 | 金额 | 预期效果 |

成本说明

请决策时间
```

**空间层选择：**
- 如果背景复杂，可以用叙事结构先说一个完整的故事
- 如果申请多个资源，可以用分组表格
- 如果涉及跨部门协调，可以加"相关方意见"栏

---

### 复盘报告结构

**约束要求：** 必须有事实还原 + 原因分析 + 改进建议

**推荐结构：**
```
【复盘报告】项目名称 — 负责人 — 日期

项目概况
  | 指标 | 数据 |

✅ 做对了的事
  1. 经验描述
     - 具体做法
     - 效果

❌ 踩过的坑
  1. 问题描述
     - 影响
     - 避坑建议

📋 交接清单（如有）
  | 内容 | 位置 | 备注 |

⚠️ 接手后注意事项（如有）
```

**空间层选择：**
- 如果做得好的事少，可以只列最重要的3项
- 如果踩过的坑多，可以按"可避免/可优化/不可控"分类
- 如果是团队复盘，可以加"团队贡献"和"个人成长"部分

---

### 方案建议结构

**约束要求：** 必须有问题 + 方案 + 预期回报 + 风险

**推荐结构：**
```
【方案建议】方案主题 — 建议人 — 日期

背景：问题与挑战
  | 指标 | 当前值 | 目标值 | 差距 |

问题根源分析
  1. 原因1
  2. 原因2

方案：核心思路
  - 思路说明

系统功能（如有）
  | 模块 | 功能 | 预期效果 |

实施路径
  | 阶段 | 时间 | 内容 |

投入预算

预期回报
  | 指标 | 当前 | 引入后 | 提升 |

风险与应对
  | 风险 | 应对 |

请决策时间
```

**空间层选择：**
- 如果是小型方案，可以合并"背景"和"问题根源"
- 如果有多个可选方案，可以加"方案对比"表格
- 如果方案复杂，可以加"技术架构"或"运营模式"详细说明

---

### 竞聘报告结构

**约束要求：** 必须有成果量化 + 能力定位 + 规划

**推荐结构：**
```
【竞聘报告】现职位 → 目标职位 — 姓名 — 日期

核心定位
  - 一句话概括你的核心价值

📊 核心成果
  1. 成果领域
     | 指标 | 去年 | 今年 | 增长 |
     - 关键动作

🎯 我的核心优势
  1. 优势1
  2. 优势2

📋 明年规划
  - 目标
  - 核心策略

为什么我是合适的人选
  - 一段话总结
```

**空间层选择：**
- 如果成果领域多，可以只选最重要的3个
- 如果想强调管理能力，可以加"团队建设"单独部分
- 如果有重要项目经历，可以加"代表项目"详细说明

---

## 表格格式

```
| 列1 | 列2 | 列3 |
|------|------|------|
| 内容 | 内容 | 内容 |
```

规范：
- 表头加粗
- 内容左对齐
- 数字右对齐
- 空单元格用 "-" 表示

---

## 符号使用规范

| 符号 | 用途 | 说明 |
|------|------|------|
| ✅ | 已完成状态 | 周报已完成事项 |
| 🔄 | 进行中状态 | 进行中但未完成的事项 |
| 📋 | 信息分类 | 决策记录、表格 |
| 📌 | 行动指向 | 待办、注意事项 |
| 📅 | 计划指向 | 下周计划、下次会议 |
| ⚠️ | 风险提示 | 风险、阻塞、问题 |
| 🎯 | 目标指向 | 核心优势、规划 |

**空间层选择：** Emoji使用是可选的。如果受众是高层或正式场合，可以省略；如果团队文化开放，可以使用。

---

## 标点符号规范

- **中文文档使用中文标点**：，。：；？！""
- **数字和英文之间留空格**：如 "3个需求"、"UTF-8编码"
- **避免使用"等等"**：尽量列出具体内容
- **避免使用感叹号**：职场写作保持客观克制

---

## 长度控制

| 文体 | 建议字数 | 说明 |
|------|----------|------|
| 周报 | 300-500字 | 简洁，突出重点 |
| 会议纪要 | 500-800字 | 结构清晰，执行导向 |
| 申请报告 | 800-1200字 | 理由充分，说服力强 |
| 复盘报告 | 1000-1500字 | 深度分析，经验沉淀 |
| 方案建议 | 1000-1500字 | 问题+方案+预期+风险 |
| 竞聘报告 | 800-1200字 | 成果+能力+规划 |

**空间层选择：** 如果内容复杂，可以超出建议字数；如果内容简单，不必凑字数。

---

## 敏感信息处理

- **数据脱敏**：客户姓名、手机号等敏感信息用"张先生"、"138****5678"表示
- **内部信息**：涉及组织内部政治的，客观描述，不夹带情绪
- **保密信息**：涉及商业机密的，明确标注"内部文件"
