# 团队协作详细执行指南

本文件是SKILL.md的执行细则补充。首次使用技能时通读，协作时按角色查阅对应章节。

---

## 全局协作协议

### Agent职责边界

| Agent | 产出物 | 接受来自 | 交付给 |
|-------|--------|---------|--------|
| city-architect | 都会隐喻场景方案 + 双层语义图 | 用户输入 | rhythm-designer |
| rhythm-designer | 节拍蓝图 + 半押/切分/延音图 | city-architect | lyrics-melody |
| lyrics-melody | 歌词+旋律注释+和弦建议 | rhythm-designer | harmony-groove |
| harmony-groove | 讽刺韵律和声编排 | lyrics-melody | arrangement-designer |
| arrangement-designer | 编曲/音色/音景/混响方案 | harmony-groove | emotion-cooler |
| emotion-cooler | 冷校检验报告（通过/打回） | arrangement-designer | music-production |
| music-production | MP3 + 8维评分卡 | emotion-cooler | team-lead |
| team-lead | 终稿 + 创作手记 | music-production | 用户 |

### 状态传递格式（交接块）

每个Agent完成后必须输出以下交接块，再传递给下一Agent：

```
---
## [Agent X] → [Agent Y] 交接

**场景主题：** （一句话描述）
**表面线：** （明线场景）
**暗讽线：** （暗线讽喻命题）
**节奏节型：** （如 Swing Shuffle / 弱起 / 切分）
**调式建议：** C minor，90 bpm
**核心和弦：** Am7 - D9 - G - Cmaj7
**情绪基准：** 机智讽刺 → 脆弱淡然 → 释怀
**用户特别要求：** （如有）
---
```

### 干预指令

- "停一下" / "等等" → 暂停当前Agent
- "回到角色X" → 回工到指定Agent
- "跳过" → 跳过当前Agent
- "直接写" → 跳过city-architect/rhythm-designer，直接进入lyrics-melody
- "更理性一点" → 提高智性密度权重
- "再冷一点" → 强化反讽，减少情绪流露

### 回工规则

| 触发条件 | 回工目标 | 规则 |
|---------|---------|------|
| 评分<64 | lyrics-melody | 保留节拍蓝图，调整词曲融合方式 |
| 评分<56 | rhythm-designer | 节拍根本问题，重新设计节奏型 |
| 出现直接哭腔/感叹句 | emotion-cooler | 打回lyrics-melody重写该句 |
| 曲出现高音爆发 | emotion-cooler | 打回lyrics-melody重新设计副歌 |
| 连续2轮评分提升<5% | 当前最优版签发 | 标注风险维度 |

## city-architect 执行细则

### 输入处理

**模糊输入：** 用户说"写首歌"但没给主题时，最多问2个问题：
1. "这首歌想呈现哪种都市情绪——疲惫？荒谬？还是一种说不出的疏离感？"
2. "有没有什么日常场景让你产生这种感觉？比如某条街、某家店、某个人。"

**过宽输入：** 用户给"爱情"/"人生"等宽泛主题 → 要求细化到都市具体时刻

**林振强式主题特征：** 表面是都会场景，内核是轻讽或哲思

### 场景生成（3-5个差异化方案）

从以下维度生成（至少覆盖3个）：

1. **城市空间类**：便利店、地铁、咖啡馆、天桥、外卖骑手
2. **都市关系类**：合租室友、面具合照、朋友圈默契、不回消息的已读
3. **职场都会类**：甲方修改、KPI焦虑、周五晚上的酒、周一早上的闹钟
4. **夜晚独处类**：凌晨两点的外卖、深夜广播、失眠的猫
5. **讽刺观察类**：任何表面正常、内核荒谬的都市日常

### 双层语义设计原则

每个场景必须同时包含：
- **表面线（Scene）：** 光影、物件、人物动作，可直接描述
- **暗讽线（Subtext）：** 讽喻命题、哲学暗线、情感真相

### 输出格式

```markdown
## 场景方案

**用户主题：** [原始输入]

### 角度1：[场景标题]（[类型]）
- **表面主题：** [明线描述]
- **暗讽命题：** [内核讽刺/哲思]
- **参照原型：** 林振强《___》——因为[相似点]
- **调式建议：** C minor / 90 bpm / 4/4 Swing
- **意象清单：** 场景物件≥5（光影/声音/触感）
- **初评分：** 讽喻深度X / 普世共鸣X / 都会气息X / 曲调契合X = 总XX

### 角度2：...
### 角度3：...

### 推荐
首选角度[N]，理由：___
次选角度[N]，理由：___

请选择一个角度，或告诉我新的方向。
```

## rhythm-designer 执行细则

### 执行前必读

`references/style-anatomy.md` 全文（林振强节奏型）
`references/fusion-guide.md` 全文（词曲节奏共感法）

### 核心：言语节拍共感法

林振强×施立模式：文字**自带节奏**，旋律必须**跟随语音拍子起舞**。

**三段节奏型：**

1. **调皮节拍（Chunky Beat）**：切分词，制造机智感
   - 句式特征：双音节词快速连击
   - 情绪：讽刺、调皮、都会轻嘲
   - 节拍：后半拍进入

2. **流畅叙事节拍（Flow Beat）**：半押，快叙述
   - 句式特征：半韵脚，快句，叙事感强
   - 情绪：城市生活流动感
   - 节拍：等分4拍

3. **延音尾节拍（Suspended Beat）**：延音收尾，制造讽刺呼吸
   - 句式特征：长词尾，不归主音，像叹气
   - 情绪：淡然、释怀、自嘲
   - 节拍：延音>2拍

### 节拍蓝图模板

```markdown
## 节拍蓝图

**场景：** [选定场景]
**基础节拍：** 4/4 Swing Shuffle（Jazz Pop）
**BPM：** 85-95（都市律动）
**切分特征：** 副歌后半拍进入，Verse等分4拍

---

### 句1："[歌词]"
节拍型：调皮节拍（Chunky）
节拍图：强‑弱‑弱‑弱（四拍切分）
切分点：第2.5拍进入
讽刺设计：表面庆祝，实则暗讽

### 句2："[歌词]"
节拍型：流畅叙事节拍（Flow）
节拍图：强‑强‑弱‑次强
韵脚：半押
情绪：都市流动感

### 句3："[歌词]"
节拍型：延音尾节拍（Suspended）
节拍图：强‑次强‑弱‑弱（延音3拍）
尾词：延音>2拍，不归主音
情绪：淡然叹笑

---
```

## lyrics-melody 执行细则

### 执行前必读

1. `references/fusion-guide.md` 全文（林振强×施立对位融合策略）
2. `references/style-anatomy.md` 全文（林振强技法）
3. `references/music-theory-notes.md` 全文（施立反高潮旋律技法）
4. `references/anti-patterns.md` 全文（失败模式）

### 词曲共构核心原则

**固定（不可改动）：**
- 每句歌词对应精确节拍呼吸点
- 副歌≤9字hook句，**不冲高音**，延音>2拍
- 旋律下行而非爆发（反高潮法）
- Verse→Chorus 能量曲线：轻微上扬→不动→微微下沉

**AI空间（灵活发挥）：**
- 讽喻双关句设计
- 城市意象精准调度
- 情绪微差（在低能量区间内的层次）
- 自嘲/冷幽默句

### 施立式反高潮结构

施立旋律的核心是**反高潮**：副歌不炸，而是「往下掉」。

| 段 | 旋律方向 | 典型施立技法 |
|----|---------|-------------|
| Verse1 | C minor 走向，切分节奏，后半句下降三度 | 级进下行，不跳进 |
| Pre-Chorus | 轻微上升，但不冲高音区（B3以内） | 蓄力但克制 |
| Chorus | D♭ major，延音>2拍，节拍轻摆 | 下行主导，不冲E4 |
| Bridge | 声音减弱，动态收缩≤0.8 | 空间感为主 |
| Outro | 停在开放和弦（sus4），不回归主音 | 悬空结尾 |

### 歌词+旋律注释模板

```markdown
## 歌词初稿 + 旋律注释

**标题：** 《____》
**调式：** C minor → D♭ major / **BPM：** 90 / **节拍：** 4/4 Swing
**情绪弧线：** V1(3) → PreC(4) → C(5) → V2(4) → B(6) → 末C(5)
**核心和弦进行：** Am7 - D9 - G - Cmaj7

---

[Verse1]
歌词歌词歌词（节拍：弱起2拍，半押）
旋律走向：C minor 走向，切分节奏，后半句下降三度
和弦：Am - F
情绪张力：场景建立，轻讽铺垫
融合点：[讽喻句式] × [下行旋律] = 机智与克制并存

旋律走向：自然级进，保持低能量区
和弦：F - C
情绪张力：微微上扬，但守住理智
融合点：[快叙述节奏] × [平行旋律] = 流动感

[Pre-Chorus]
歌词歌词歌词（情绪微升）
旋律走向：轻微上行，但不冲高音B3
和弦：Em7 - A7 - Dm7
情绪张力：蓄力中，暗示冲突但不爆发
融合点：[反问句] × [悬置和弦] = 悬念感

[Chorus]
核心hook句（≤9字，双层语义，带讽喻）
旋律走向：D♭ major，延音>2拍，节拍轻摆，不冲高音E4
和弦：D♭ - B♭ - gm - Cmaj7
情绪张力：笑着心疼，情感含而不露
融合点：[自嘲句] × [下行延音] = 克制的性感
可重复三遍：是，节奏型不变

[Verse2]
歌词歌词歌词（时间跳切，不重复V1）
旋律走向：V1动机变体，深化情绪
和弦：Am - F - C - G
情绪张力：比V1深一层，但守住理性

[Bridge]
歌词歌词歌词歌词（哲思转折，从讽刺到淡然）
旋律走向：低音延音构成转调，动态收缩≤0.8
和弦：D - A - Bm - G
情绪张力：全曲最"聪明"段落，讽刺顿悟
融合点：[意象泛化] × [留白空间] = 都会哲思

[Chorus - 末]
```

## harmony-groove 执行细则

### 执行前必读

`references/music-theory-notes.md` 全文（施立和弦理论）

### 讽刺韵律和声设计

林振强×施立的和声特征：**不协和，但协和得很聪明。**

| 和弦类型 | 功能 | 情绪效果 |
|---------|------|---------|
| maj7 | 都市感、轻讽刺 | 明亮但不暖，理性但有光 |
| add9 | 灵动、温柔、都会感 | 都市诗意 |
| sus4 | 缠绕、暧昧、不解决 | 悬念感，持续张力 |
| m7 | 孤独、理性柔光 | 深夜咖啡馆 |

**标准走向：** Am7 – D9 – G – Cmaj7
或 Cmaj9 – Em7 – A7 – Dm7

### Groove编排原则

- Bass与Drum：轻对话，不抢人声
- 切分节奏：Guitar/Piano在后半拍进入
- Brush Drum为主：不使用大镲片片，保持克制

## arrangement-designer 执行细则

### 目标音场：城市夜行声

**音色配置：**
- 主音：Electric Piano（Rhodes或DX7）
- 节奏：Brush Drum / Conga轻拍
- Bass：Slap Round低频律动
- 背景：都市噪声采样（走路声、人声、地铁门音）

**混响参数：** Room 0.25 – Hall 0.32；Stereo Width 0.75
**动态范围：** 0.85

**声像分配：**
- Vocal 中心偏右 0.2
- Electric Piano 左 0.3
- Bass 右 低区 0.2
- 环境音 全景淡入

## emotion-cooler 执行细则

### 核心检验：机智反情绪姿态

**规则（违反任何一条，立即打回）：**
- 不许哭；必须笑着心痛
- 不许煽情；必须理性节奏
- 不许高呼；曲高音区B3以上不超过2处
- 不许直接情绪词：不用"爱""恨""想你""痛"
- 若词太直接，则隐喻重写
- 若曲太甜，则减和弦、降主调

**检验标签：**
- NLP标签含「哭」「痛」「绝望」→ 打回
- 曲冲E4高音 → 打回lyrics-melody
- 感叹号>0 → 打回该句重写
- 尾句归主音（1或5度） → 打回修改结尾

### 输出格式

```markdown
## 冷校检验报告

**检验项 | 状态 | 原因**
词讽喻密度 | ✅ 通过 | 每句均有双关或反语标签
曲克制性 | ✅ 通过 | 高音B3内，无爆发段落
和声理性 | ✅ 通过 | sus4/maj7为主，无强力解决
尾句悬空 | ❌ 需改 | 末句"懂了"归主音，建议改为"好像懂了"
情绪反讽 | ✅ 通过 | 讽刺感>0.6

**决策：** 通过 / 打回（附具体原因）
**打回目标：** lyrics-melody - 修改尾句
```

## music-production 执行细则

### 执行前必读

`references/scoring-rubric.md` 全文（8维评分）

### MP3生成流程

```bash
node scripts/tts-sing.js \
  --lyrics "歌词文件路径" \
  --tempo 90 \
  --key "C minor" \
  --output "D:/Downloads/输出文件名.mp3"
```

### 8维评分执行

| # | 维度 | 满分标准 |
|---|------|---------|
| 1 | 智性密度 | 词句思想、讽喻力度、双关或反语结构 |
| 2 | 节奏匹配度 | 语义与拍子同步，词语呼吸位置与拍点吻合 |
| 3 | 旋律克制性 | 情绪下潜而非爆发，副歌以内收为美 |
| 4 | 音色都会感 | 是否有"夜色+灯光"气息 |
| 5 | 编曲流通度 | Groove自然，Bass与Drum对话灵巧 |
| 6 | 情绪反讽力 | 自嘲/冷幽默，副歌最后一行改变语义 |
| 7 | 普世共鸣力 | 都市人听懂的孤独，虽机智却仍被理解 |
| 8 | 后劲留白度 | 歌停了在脑内转，尾句不回归主音 |

### 签发规则

| 总分区间 | 决策 | 动作 |
|---------|------|------|
| ≥72/80 | 通过签发 | 推送team-lead聚合终稿 |
| 64-71/80 | 小修 | 回lyrics-melody重校节拍与转调 |
| <64/80 | 重工 | 回rhythm-designer重新设计节奏型 |
| <55/80 | 停止 | 主题逻辑错误，重新选题 |

## 安全边界

### 内容安全闸门

以下情况强制调整：
- 全曲过于悲伤/绝望 → 在Bridge或尾句注入淡然/自嘲
- 出现直接情绪词（爱/恨/想你/痛） → 必须以讽喻方式重写
- 曲冲高音E4/B4超过2处 → 打回lyrics-melody降调

### 版权边界

- 不直接引用已发表歌词原句
- 原型作品仅作技法参照，不作内容来源
- "写一首像林振强风格的歌"→学技法不学内容
