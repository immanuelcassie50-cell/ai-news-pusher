# 林振强×施立 词曲一体创作系统（RPD融合版 v1.0）

本技能通过8角色团队协作，生成具备**林振强智性讽喻**与**施立冷静旋律工程学**的完整都会文学歌曲，并输出MP3试听文件。

**核心理念：** 词不直说、曲不直爆，但两者交缠成一种"克制的性感"。用一句话总结——**让听众笑了，却在笑的下一秒感到孤独。**

## 团队成员

| Agent | 角色 | 核心职责 |
|-------|------|---------|
| `city-architect` | 城市主题建构师 | 都会隐喻场景，双层语义（表面+暗线） |
| `rhythm-designer` | 节奏语言设计师 | 歌词节拍蓝图，半押三重节奏，切分/弱起/延音 |
| `lyrics-melody` | 词曲共生引擎 | 反高潮结构，旋律下行而非爆发，和弦跟进语义 |
| `harmony-groove` | 和声律动师 | maj7/add9/sus4/m7 讽刺韵律和声，Groove编排 |
| `arrangement-designer` | 编曲与音景设计师 | 城市夜行声场，Brush Drum/Rhodes/Bass/环境采样 |
| `emotion-cooler` | 情绪冷校监制 | 检验"机智反情绪"姿态，禁止哭腔/煽情/高呼 |
| `music-production` | 评分签发（合并） | 8维评分，80分制，签发决策 |
| `team-lead`（主控） | 协调 + 终稿聚合 | 监控流程，聚合交付物，生成创作手记 |

## 执行流程

```
用户输入主题（如"深夜外卖"）
    ↓
[city-architect] 生成都会隐喻场景方案（3-5个）
    ↓（用户确认）
[rhythm-designer] 构建节拍蓝图（半押/切分/延音图）
    ↓
[lyrics-melody] 词曲共构（歌词+旋律注释+和弦）
    ↓
[harmony-groove] 设计讽刺韵律和声（maj7/sus4/m7走向）
    ↓
[arrangement-designer] 编曲与音景设计
    ↓
[emotion-cooler] 冷校检验（禁止哭腔/煽情/高呼）
    ↓
[music-production] 8维评分 + 签发决策
    ↓
[team-lead] 聚合终稿 + 创作手记 + 评分卡
    ↓
交付：歌词（含旋律注释）.md + MP3文件
```

## 用户输入 / 产出格式

**用户提供（三选一）：**
- A. 模糊主题（如"职场应酬"、"深夜便利店"）→ city-architect 自动发散
- B. 具体情境（如"凌晨两点的外卖小哥"）→ 直接进入节拍蓝图设计
- C. 指定情绪类型 → 适配调式与曲风

**Claude产出：**
1. 完整歌词（含旋律走向注释、和弦、调式建议）
2. MP3试听文件（via MiniMax TTS）
3. 创作手记（≤500字）
4. 8维评分卡

## 协作规则

1. **用户介入点：** city-architect 输出后必须等用户确认角度
2. **回工机制：** music-production 评分<64时自动触发回工，附具体原因
3. **安全闸门：** 若歌词出现直接哭腔/感叹号/高呼 → emotion-cooler 强制打回
4. **迭代上限：** 评分重修最多2轮，超出则以当前最优版签发并标注风险

## Team模式约定

本技能默认开启Team模式。team-lead 在每阶段完成后主动报告进度（SendMessage to "team-lead"），超时3分钟无消息则主控主动询问，超时5分钟则TaskStop并接管。

## 不适用场景

- **已有完整歌词，只需配乐/作曲：** 请使用单独的音乐制作类skill
- **纯抒情、情感爆发类歌曲：** 请使用唐恬×钱雷系统
- **仅需分析现有歌曲的创作技法：** 请使用歌词/作曲分析类skill
- **用户只需要一个音乐文件，不需要歌词创作：** 请使用纯音乐/TTS类skill

## 交付说明

所有产出文件生成完毕后，使用 `present_files` 工具将以下文件交付给用户：
1. 歌词终稿（含旋律走向注释、和弦、调式建议）的 `.md` 文件
2. MP3试听文件

交付时附上一句话完成说明，例如："已完成智性都会歌曲创作和MP3试听，详见文件。"
