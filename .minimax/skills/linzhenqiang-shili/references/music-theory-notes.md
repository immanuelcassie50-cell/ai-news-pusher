# 施立旋律技法与调式理论

本文件深度剖析施立音乐创作的方法论，供lyrics-melody Agent在设计旋律时参照。

---

## 核心信念

**施立不是在写旋律，是在设计一种"冷静的情绪机器"。**

他的旋律不负责告诉你"该哭了"，而是负责让你在某个音符经过的时候，突然想起一件什么事。

**一句话总结：** 施立的旋律是给"有理智的人"听的，他们不允许自己崩溃，但允许自己在某个和弦经过时感到一点什么。

---

## 反高潮结构七型

施立的核心技法：**反高潮（Anti-Climax Melody）**，让旋律不上炸，而是悄悄地下行或悬空。

### 型1：平行下行型

旋律线几乎与和弦音平行，不跳进，不上行，在同一音区滑动。

```
C4 — D4 — E4 — D4 — C4（几乎平行，有微小起伏）
A4 — G4 — F4 — E4（缓慢下行）
```

**适用：** Verse场景描述段落
**词曲融合：** 配合林振强的叙事节拍（Flow Beat），制造"城市生活流水账"的听觉感

---

### 型2：波浪下沉型

旋律线有起伏，但整体方向向下，像微笑的嘴角。

```
G4 — A4 — F4 — E4（拱形，整体下沉）
```

**适用：** Pre-Chorus蓄力段
**词曲融合：** 配合林振强的讽喻反问句，蓄力但克制

---

### 型3：延音悬空型

尾音延长>2拍，不归主音，停在和弦外音上。

```
C4（延长3拍）→ Db4（悬空，不归C）
```

**适用：** Chorus尾句、Outro
**词曲融合：** 配合林振强的延音笑语法（"好像懂了"），制造"话没说完"感

---

### 型4：切分跳变型

在句中某处突然跳进（但不上高音区），随即下行缓冲。

```
F4 — Ab4（跳小三度）→ G4（下行缓冲）
```

**适用：** 副歌Hook句（1-2个音跳进，其余下行）
**词曲融合：** 配合林振强的调皮节拍，制造"机智闪躲"的讽喻感

---

### 型5：调式滑动型

在Verse到Chorus之间，通过过渡音滑入新调式。

```
C minor（Verse末音）→ 过渡音滑行 → D♭ major（Chorus起始）
```

**过渡技法：**
- 半音滑入：G → Gb → F（D♭方向）
- 借用和弦过渡：Cmaj7 → B♭7 → A♭maj7 → D♭（调式转亮）

**词曲融合：** 配合林振强的反语构法（表面语义转换），曲的调式转亮与词的反讽同步

---

### 型6：低音区留白型

整段停留在低音区（B2-E3），不冲高音，制造压抑后的释然。

```
B2 — C3 — D3 — E3（低音区徘徊）
→ 最后一句略升，但不超G3
```

**适用：** Bridge哲思段
**词曲融合：** 配合林振强的意象升维（从"我"到"都市人"），低音区留白给哲思空间

---

### 型7：Groove切分型

旋律落在后半拍（或2.5拍），与节奏形成切分。

```
1   2   3   4
|   ↓   |   |   （2.5拍进入）
```

**适用：** 副歌Hook自嘲句
**词曲融合：** 配合林振强的调皮节拍，Groove切分制造"轻嘲"感

---

## 调式色地图（都会场景对应调式）

### C minor → D♭ major（林振强×施立核心调式）

| 调式 | 适合场景 | 色彩描述 |
|------|---------|---------|
| C minor | 都会冷夜、叙事开场 | 理性、观察、克制 |
| D♭ major | 副歌反讽、明亮冷光 | "太清醒的浪漫"，讽喻感 |
| A minor | 都市独白、合租疏离 | 都市文艺感 |
| F minor | 职场荒谬、深夜加班 | 沉重但可自嘲 |
| E♭ major | 轻快讽喻、释然瞬间 | 轻而不甜，苦笑感 |

### 转调设计（全程只用一次）

林振强×施立歌曲通常在Verse→Chorus之间有一次转调：

```
Verse：C minor → PreC末尾半音下滑 → Chorus：D♭ major
```

**转调目的：** 不是为了"情绪爆发"，而是为了"情绪反转"——曲调变亮，词意反转，讽喻感骤增。

## 和弦进行设计（讽刺韵律和声）

### 施立最爱用的和弦序列

| 进行 | 情绪效果 | 适用段落 |
|------|---------|---------|
| Am7 – D9 – G – Cmaj7 | 都市感、轻讽、理性柔光 | V1/V2 |
| Cmaj9 – Em7 – A7 – Dm7 | 诗意、流动、自嘲 | PreC |
| D♭ – B♭ – gm – Cmaj7 | 冷亮、反讽、留白 | Chorus |
| D – A – Bm – G | 升维、哲思、空间感 | Bridge |
| D♭sus4 – D♭maj7 | 悬空、不解决、后劲 | Outro |

### 禁忌和弦（太甜/太爆）

- G大调作为主和弦（太亮）
- C大调强解决（太直接）
- 属七解决到主音（太戏剧）
- 连续上行和弦（太煽情）

## Groove编排原则

### 节奏组配置

**标准4件套（都会Jazz Pop）：**
1. **Electric Piano / Rhodes：** 主旋律和声填充，Q分数0.7（轻触）
2. **Slap Bass：** 低频Groove，后半拍轻点，制造"踩空感"
3. **Brush Drum：** 不砸片，轻刷，保持克制动感
4. **合成Pad：** 极淡的背景氛围，声像全景

### Bass线设计

施立的Bass线是Groove的灵魂：

```
Am7：| A —— | G —— | F#—— | G —— |（下行琶音，不跳进）
D9：  | D —— | C —— | B♭—— | C —— |（持续低音，不抢）
```

**Bass禁忌：**
- 不走根音-属音-主音的强力跳进（太戏剧）
- 不连续上行（太"舞曲"）
- Bass不应比人声更响

### 切分设计

```
1    2    3    4
|    ↓    |    |     ← Piano/EPT在后半拍进入
♩    ♩    ♩    ♩     ← Bass在第1拍轻点
ch   -    ch  -      ← Drum Brush轻刷（不砸）
```

## 声场参数

### 都会夜行声场（标准参数）

| 参数 | 默认值 | 含义 |
|------|--------|------|
| tempo | 90 bpm | 城市呼吸速率 |
| key | C minor | 情绪中性偏冷 |
| time_signature | 4/4 Swing | 都市律动 |
| dynamic_range | 0.85 | 保留空间感 |
| stereo_width | 0.75 | 集中听感 |
| reverb_type | room 0.28 / light hall | 贴近人声环境 |
| vocal_loudness | -9 LUFS ± 2 | 不压缩太死 |
| bass_energy | 80–120 Hz 轻推 | 律动而温柔 |

### 声像分配

```
左 0.3        中心         右 0.3
[Rhodes]                    [Bass]
       [Vocal 中心偏右 0.2]
              [Guitar 中心]
```

## 旋律走向速查表

| 段落 | 音区范围 | 走向 | 跳进限制 |
|------|---------|------|---------|
| V1 | C3–G3 | 平行或轻微下行 | ≤小三度 |
| PreC | D3–A3 | 轻微上行蓄力 | ≤大二 度 |
| Chorus | Eb3–B3 | 延音为主，下行主导 | ≤小三度（1-2次）|
| Bridge | B2–E3 | 低音区留白 | 不跳进 |
| Outro | C3–Eb3 | 悬空，不归主音 | 禁止跳进 |

**高音禁区：** E4以上原则上禁止出现（除非Hook短音，且停留<0.5拍）

## 典型施立段落分析

### Chorus旋律设计（反高潮标准型）

```
句1：沉默的浪漫——你懂不懂（Eb4 → Db4 → C4）
      延音>2拍，不归主音，停在sus4

句2：城市太聪明——所有人都装作普通（Eb4 → Db4 → Bb3）
      切分进入，后半拍，轻微下行

句3：笑的时候反而孤独（Eb4 → Db4 → C4 → Bb3）
      延音笑语法，尾音散开，混响>2秒
```

**旋律诊断：** 全部在Eb4以下，全部下行，无一处爆发。
**词曲融合：** 林振强的讽喻 × 施立的下行 = "笑着心疼"。

## Groove自检三问

每设计完一段Groove，问自己：

1. **Bass在和谁对话？** Bass应与Drum形成"问答"感，不应独自跳进
2. **切分够不够机智？** Piano/EP是否在后半拍进入？是否制造了"踩空"感？
3. **Groove会让人想走路吗？** 施立的Groove是"走路音乐"——不抢人，不压抑，适合夜行。

三问全✅ → Groove合格
有任何一问❌ → 回harmony-groove调整
