# 林振强×施立 词曲一体评分细则 v1.0

本评分体系用来验证作品是否达成「聪明的情感」目标——机智、克制、深刻、有后劲。

**总分 80。签发条件：总分≥72 通过；64‑71 小修；<64 重工；<55 停止（主题逻辑错误）。**

---

## 评分维度与标准

### 维度1：智性密度（0–10）

词句是否体现理性幽默与语义层。

**评分要点：**
- 有双关或反语结构（表里双意）
- 内容为现实都市观察而非主观宣泄
- 听完歌词能让人想半天才懂

| 得分 | 表现 |
|------|------|
| 9-10 | 每句均有双关或反语，听完当场回昧 |
| 7-8 | 多数句子有讽喻，少数平铺直叙 |
| 5-6 | 有1-2处讽喻，其余叙事 |
| 3-4 | 少量讽喻，更多直接表达 |
| 0-2 | 无讽喻，直接情绪表达为主 |

**满分表现：** 听者笑了，但心里在想。

---

### 维度2：节奏匹配度（0–10）

语言节拍与旋律节奏是否同步。

**评分要点：**
- 词语呼吸位置与拍点吻合
- 切分、弱起、停顿使用自然
- 唱出来的节奏和说出来的节奏一致

| 得分 | 表现 |
|------|------|
| 9-10 | 每句都能唱出语气，节奏与语义完美同步 |
| 7-8 | 多数句子节奏自然，少数有违和感 |
| 5-6 | 部分句子有节奏跳脱，需要调整 |
| 3-4 | 节奏与语义有明显冲突 |
| 0-2 | 节奏混乱，无法唱出 |

**满分表现：** 任何一句都能唱出语气。

---

### 维度3：旋律克制性（0–10）

旋律是否遵守"反高潮法"。

**评分要点：**
- 不乱上高音（E4以上<2处）
- 没有情绪爆炸（无连续高音）
- 副歌以内收为美，下行主导

| 得分 | 表现 |
|------|------|
| 9-10 | 全曲无一处E4以上高音，副歌整体下行 |
| 7-8 | 高音极少，克制感强 |
| 5-6 | 有1-2处高音，但整体克制 |
| 3-4 | 高音较多，有爆发冲动 |
| 0-2 | 高音频繁，情绪爆发段落明显 |

**满分表现：** 一气呵成，淡而有味，副歌往下掉。

---

### 维度4：音色都会感（0–10）

音乐空间是否具有"夜色质地"。

**评分要点：**
- 是否采用电钢琴/Rhodes、爵士鼓、合成pad等都市元素
- 混响小而温，有真实空间感
- 有无都市声景采样（可选）

| 得分 | 表现 |
|------|------|
| 9-10 | 都会夜行声场完整，音色精准匹配场景 |
| 7-8 | 主要音色正确，细节有小缺 |
| 5-6 | 部分音色偏传统（如纯钢琴+弦乐） |
| 3-4 | 音色与都市感不匹配 |
| 0-2 | 完全传统编曲，无都市质感 |

**满分表现：** 听感如深夜咖啡厅、凌晨街头。

---

### 维度5：编曲流通度（0–10）

律动是否流畅，舞步感是否自然。

**评分要点：**
- Groove不突兀，节拍连贯
- Bass与Drum对话灵巧
- Piano/EP切分节奏自然

| 得分 | 表现 |
|------|------|
| 9-10 | Groove自然流畅，能无意识地跟拍 |
| 7-8 | 节拍连贯，少数地方有跳脱 |
| 5-6 | 有Groove但不流畅 |
| 3-4 | 节拍断断续续，不连贯 |
| 0-2 | 无Groove，节拍机械 |

**满分表现：** 听者能无意识地跟拍，夜行律动感。

---

### 维度6：情绪反讽力（0–10）

作品中是否出现自嘲、冷幽默或反情绪机制。

**评分要点：**
- 副歌最后一行改变语义或语气
- Bridge有讽刺顿悟点
- 整首歌有"笑着心疼"的质感

| 得分 | 表现 |
|------|------|
| 9-10 | 全曲自嘲/冷幽默密度高，讽刺贯穿始终 |
| 7-8 | 多数段落有反讽，少量纯情绪表达 |
| 5-6 | 有1-2处明显反讽，其余正常 |
| 3-4 | 少量自嘲，更多正向情绪词 |
| 0-2 | 无反讽，以直接情绪表达为主 |

**满分表现：** 同情又讽刺之并存，让人苦中作乐。

---

### 维度7：普世共鸣力（0–10）

虽机智却仍让人感到被理解。

**评分要点：**
- 使用城市日常意象（≥3项）
- 不高深，不晦涩，知识分子也能被打动
- 痛感从"我"扩容到"都市人"

| 得分 | 表现 |
|------|------|
| 9-10 | 都市意象精准，听者立刻"那也是我" |
| 7-8 | 多数意象有共鸣，少数特殊 |
| 5-6 | 有共鸣点，但意象不够精准 |
| 3-4 | 意象偏个人，共鸣有限 |
| 0-2 | 无明显都市意象，无法共鸣 |

**满分表现：** "人人懂，却人人痛"。

---

### 维度8：后劲留白度（0–10）

结尾声场与情绪是否有延续空间。

**评分要点：**
- 尾句未完，总有回想
- 混响延迟 > 2秒
- Outro停在sus4，不回归主和弦
- 歌曲结束后听者仍在回味

| 得分 | 表现 |
|------|------|
| 9-10 | 歌停后还在脑内转，sus4悬空，不归主音 |
| 7-8 | 尾句留白感强，但混响略短 |
| 5-6 | 有留白但不够，尾句较完整 |
| 3-4 | 结尾明确，情绪关闭感强 |
| 0-2 | 结尾完美解决，无回味 |

**满分表现：** 歌停了，脑子还在转。

---

## 附加项（加分）

| 条件 | 加分 | 说明 |
|------|------|------|
| 语言多层隐喻（≥3层） | +3 | 文本有多层语义结构 |
| 节奏创新（非传统4/4） | +2 | 使用6/8或其他节拍 |
| 副歌可转舞台表演 | +2 | 动作节奏与音乐拍点同步 |

加分上限：+5

## 签发规则

| 范围 | 评价 | 处理 |
|------|------|------|
| ≥77（含加分）| 精品 | 输出MP3，推荐使用 |
| ≥72 | 通过 | 输出MP3 |
| 64–71 | 小修 | 回lyrics-melody重校节拍与转调 |
| <64 | 重工 | 回rhythm-designer重新设计节奏型 |
| <55 | 停止 | 主题逻辑错误，重新选题 |

---

## 评分后必做

1. 每项维度必须给出**一句话说明**（不能只写分数）
2. 任何维度<5分，必须在"质检日志"中注明原因
3. 小修/重工必须给出**具体修改指令**，不能只说"调整"
