# 林振强×施立 风格质感核对表 v1.0

本清单用于最终质检与风格一致性校准。

**核心准则：** "城市讽喻 + 律动优雅 + 情绪倒转"

---

## 一、结构检查

| 模块 | 关键元素 | 检验方式 | 判定标准 |
|------|---------|---------|---------|
| 开头 | 场景与动作导入 | 首句含城市名词或动词 | 有人/物/动作 |
| V1 | 呈现冷幽默观察 | 若文体为陈述+隐讽 | 通过 |
| Pre-Chorus | 节奏加快、语义转向 | 节拍提升 > 10% | 通过 |
| Chorus | 产生情绪反讽或自嘲句 | NLP标签中含「调侃」「讽刺」| 通过 |
| Bridge | 声音减弱+哲思转折 | 动态范围收缩 ≤ 0.8 | 通过 |
| Outro | 音尾不归主音 | 检测最后音程 ≠ 1 或 5 | 通过 |

**任一项❌ → 打回lyrics-melody修改该段落**

---

## 二、语言语料表

### 必须包含（全部满足才通过）

- 都市词汇（地铁/便利店/霓虹/咖啡/外卖/电话/窗口/朋友圈） ≥ 3项
- 反问或双层句 ≥ 1项
- 讽喻/自嘲句 ≥ 1项

### 必须避免（出现任何一项即❌）

- 直接情绪词：爱、恨、想你、痛、哭、绝望
- 哀怨句："为什么你不在"、"你为什么要走"
- 鸡汤句："相信自己"、"明天会更好"、"爱要大声说出来"
- 感叹号（！）
- 过度华丽词：梦幻、翅膀、永恒、星辰大海、岁月长河
- 过度修辞：绽放、铸就、徜徉、诗篇、画卷

**两项必含 + 五项必无 = 语言合格**

---

## 三、旋律与和声核查

- [ ] 调式须含一处轻微转调（C minor → D♭ major 或同等）
- [ ] 至少出现一次 maj7 或 sus4
- [ ] 节拍为 Swing 或 Shuffle（非straight 4/4）
- [ ] 副歌音区 Bb3–Eb4 以内
- [ ] 高音 E4 以上不超过2处
- [ ] 若出现高潮爆点（Bb4以上连续）→ ❌ 判不合格

**任一项❌ → 打回lyrics-melody调整**

---

## 四、编曲声场目标

| 参数 | 理想区间 | 检查说明 |
|------|---------|---------|
| Tempo | 85–95 bpm | 中速律动（不能太快） |
| Dynamic Range | 0.85–0.9 | 保留空间感 |
| Stereo Width | 0.65–0.8 | 集中听感 |
| Reverb Type | room / light hall | 贴近人声环境 |
| Vocal Loudness | -9 LUFS ± 2 | 不压缩太死 |
| Bass Energy | 80–120 Hz 轻推 | 律动而温柔 |

---

## 五、节奏与情绪测试

| 测项 | 要求 | 判定 |
|------|------|------|
| 词句呼吸长度 = 拍长 ± 10% | 自然感 | ✅/❌ |
| Groove连贯性 > 0.7 | Swing分辨成功 | ✅/❌ |
| 主旋律平均上升比 ≤ 30% | 克制度达标 | ✅/❌ |
| 副歌能量下降 ≤ 15% | 反高潮成功 | ✅/❌ |
| Outro回声时间 ≥ 2s | 留白合格 | ✅/❌ |

---

## 六、情绪与讽刺双层验证

| 条件 | 方法 | 判定 |
|------|-------|------|
| 句中存在矛盾词组（如"太清醒的浪漫"） | 语义分析 Contradiction > 0.5 | 带讽刺感 ✅ |
| 音符曲线与词义反向（悲词 → 上行旋律） | 曲词反向率 ≥ 0.4 | 反情绪成功 ✅ |
| 副歌Hook：≤9字且含双关或反语 | 文本标签检测 | Hook合格 ✅ |

---

## 七、哲学一致性检验

作品应符合以下三句核心逻辑（至少映射一句）：

1. 世界不完美，但人仍想生活。
2. 孤独很聪明。
3. 爱是理性里的荒谬。

**若无法映射至少一句 → 退回 city-architect 重新设计场景**

---

## 八、视觉感知测试（MV适配）

- [ ] 是否可于夜景、街灯、咖啡馆场景使用
- [ ] 副歌画面建议为"行走""转身""眺望"（非"拥抱""痛哭"）
- [ ] 动作节奏与音乐拍点同步 ≤ ± 0.2拍

---

## 九、冷校强制规则（单项❌即打回）

| 规则 | 说明 |
|------|------|
| 不许哭 | 任何"哭"相关词汇 → 打回 |
| 不许高呼 | E4以上高音超2处 → 打回lyrics-melody |
| 不许直接 | 直接情绪词（爱/恨/想你/痛）超3处 → 打回该句 |
| 不许爆发 | Bridge能量 > V1能量 → 打回调整 |
| 不许完结 | Outro归主音1/5度 → 打回修改结尾 |

---

## 十、系统终判断语

**听完这首歌，**
**若测试者能微笑并说一句 "这很像我"，**
**则作品达到林振强 × 施立标准：**
**都会孤独的共情艺术。**
