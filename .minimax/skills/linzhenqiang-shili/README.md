# 林振强×施立词曲融合创作系统

> 生成完整歌词（含旋律走向注释）→ 输出 MP3 试听文件

## 核心定位

这是一个词曲一体的创作系统，融合了**林振强的都会智性讽喻**与**施立的冷静旋律工程学**。

**不**是"先写词再配曲"，而是遵循"言语节拍共感"原则：**文字自带节奏，旋律必须跟随语音拍子起舞。**

**核心理念：** 让听众笑了，却在下一秒感到孤独。词不直说、曲不直爆，但两者交缠成一种"克制的性感"。

## 团队协作流程

```
用户输入主题
    ↓
[city-architect] 都会场景建构 + 双层语义设计
    ↓（用户确认）
[rhythm-designer] 节拍蓝图（半押/切分/延音图）
    ↓
[lyrics-melody] 词曲共构（核心）
    ↓
[harmony-groove] 讽刺韵律和声编排
    ↓
[arrangement-designer] 编曲与音景设计
    ↓
[emotion-cooler] 冷校检验（禁止哭腔/高呼）
    ↓
[music-production] 8维评分 + 签发决策
    ↓
[team-lead] 聚合终稿 + 创作手记
    ↓
交付：歌词（含旋律注释）.md + MP3文件
```

## 手动运行 MP3 生成（可选）

```bash
# 基础用法
node scripts/tts-sing.js \
  --lyrics 输出歌词文件.md \
  --tempo 90 \
  --key "C minor" \
  --output D:/Downloads/output.mp3

# 指定音色
node scripts/tts-sing.js \
  --lyrics 输出歌词文件.md \
  --voice "male-qing" \
  --tempo 90 \
  --key "C minor" \
  --output D:/Downloads/output.mp3
```

## 调式快速参考

| 调式 | 适合情绪 | 推荐场景 |
|------|---------|---------|
| C minor | 都市冷调、叙事开场 | 都会疏离、深夜独白 |
| D♭ major | 副歌冷亮、反讽感 | "太清醒的浪漫"、自嘲 |
| A minor | 都市文艺感 | 合租疏离、朋友圈讽喻 |
| F minor | 职场荒谬 | 周五晚上的酒、加班 |
| E♭ major | 轻快讽喻 | 释然瞬间、苦笑感 |

**标准转调：** C minor（Verse）→ D♭ major（Chorus）

## 核心技法对照

| 技法 | 林振强 | 施立 |
|------|--------|------|
| 讽喻 | 反语构法、延音笑语法 | 旋律下行而非上行 |
| 都会感 | 都市意象调度 | Electric Piano + Brush Drum |
| 克制 | 不直接情绪表达 | 不冲高音，E4以内 |
| 留白 | 延音尾，不归主语 | sus4悬空，混响>2s |

## 评分与签发

| 总分（8维×10分） | 决策 |
|-----------------|------|
| ≥72/80 | 通过签发 |
| 64-71/80 | 小修（回lyrics-melody） |
| <64/80 | 重工（回rhythm-designer） |
| <55/80 | 停止（重新选题） |
