# 陈辉阳×林夕 词曲一体评分细则 v1.0

本评分体系用来验证作品是否达成「优雅地心碎」目标——都市感、心理剖析、克制、有后劲。

**总分 80。签发条件：总分≥72 通过；64‑71 小修；<64 重工；<55 停止（主题逻辑错误）。**

---

## 评分维度与标准

### 维度1：都市感（0–10）

场景是否明确、现代、有城市空间感。

**评分要点：**
- 城市场景≥3项（酒店房间/的士/落地窗/便利店/深夜地铁）
- 都市物件精准调度（酒杯/手机/灯光/雨/雾）
- 有城市空间感，而非田园/古典化

| 得分 | 表现 |
|------|------|
| 9-10 | 每句均有精准都市意象，有城市空间感 |
| 7-8 | 多数句子有都市意象，少数较泛 |
| 5-6 | 有1-2处都市意象，其余较泛 |
| 3-4 | 少量都市意象，偏传统 |
| 0-2 | 无都市意象，偏田园/古典 |

**满分表现：** 听完像在一个具体的城市空间里，不模糊。

---

### 维度2：情绪梯度（0–10）

体面→失衡→沉溺→自嘲→收线是否完整。

**评分要点：**
- 五段情绪弧线完整
- 每段情绪有明确的语气/和声标记
- 情绪不是线性上升，而是波形翻涌

| 得分 | 表现 |
|------|------|
| 9-10 | 五段完整，每段有清晰标记，情绪波形明显 |
| 7-8 | 四至五段，情绪递进清晰 |
| 5-6 | 三段，情绪有所变化 |
| 3-4 | 情绪变化少，平铺直叙 |
| 0-2 | 情绪无变化或混乱 |

**满分表现：** 听者能感受到从体面到崩坏的完整弧线。

---

### 维度3：语言锋利度（0–10）

是否有1–2句"听完会刺一下"的句子。

**评分要点：**
- 林夕式双层语义（表面说A，内核说B）
- 刺痛感：不靠高喊，靠语义反转
- 自嘲/淡然句

| 得分 | 表现 |
|------|------|
| 9-10 | 每段均有刺点，全曲有3句以上"会刺一下"的句子 |
| 7-8 | 多数段有刺点，全曲有2句 |
| 5-6 | 有1-2处刺点 |
| 3-4 | 少量刺点，更多叙事 |
| 0-2 | 无刺点，直白表达 |

**满分表现：** "你来的时候，我就开始计算离开"——让人心里咯噔一下。

---

### 维度4：旋律贴合度（0–10）

每句是否唱得出口、节奏跟语气吻合。

**评分要点：**
- 词语呼吸位置与拍点吻合
- 唱出来的节奏和说出来的节奏一致
- 切分、弱起、延音使用自然

| 得分 | 表现 |
|------|------|
| 9-10 | 每句都能唱出语气，节奏与语义完美同步 |
| 7-8 | 多数句子节奏自然，少数有违和感 |
| 5-6 | 部分句子有节奏跳脱，需要调整 |
| 3-4 | 节奏与语义有明显冲突 |
| 0-2 | 节奏混乱，无法唱出 |

**满分表现：** 任何一句都能唱出语气，不需要刻意"唱"。

---

### 维度5：和声精致度（0–10）

maj7/9/sus 和弦运用是否服务情绪。

**评分要点：**
- 频繁使用 maj7/add9/sus4，不依赖传统三和弦
- 和弦选择精准服务情绪（不安→maj7，悬空→sus4）
- sus4 悬空结尾，不解决

| 得分 | 表现 |
|------|------|
| 9-10 | 和声精致，全程maj7/9/sus为主，悬空结尾完美 |
| 7-8 | 多数段落和声精致，有1-2处可改进 |
| 5-6 | 部分段落使用传统和弦，有进步空间 |
| 3-4 | 传统和弦为主，缺少精致感 |
| 0-2 | 大量三和弦，无maj7/9/sus |

**满分表现：** 和声本身就在"说话"——不安的时候 maj7，悬空的时候 sus4。

---

### 维度6：编曲美感（0–10）

钢琴+弦乐是否有"音乐厅级质感"。

**评分要点：**
- 钢琴克制，分解和弦为主
- 弦乐在Pre-C入场，长音铺底，不过度煽情
- 整体"音乐剧式流行歌"质感

| 得分 | 表现 |
|------|------|
| 9-10 | 钢琴+弦乐室内感完整，音乐厅级质感 |
| 7-8 | 主要音色正确，细节有小缺 |
| 5-6 | 部分音色偏传统（如过多弦乐齐奏） |
| 3-4 | 音色偏流行/传统编曲 |
| 0-2 | 完全传统编曲，无室内感 |

**满分表现：** 音乐厅里放不觉得突兀，KTV里放不觉得违和。

---

### 维度7：真相残酷度（0–10）

有没有点出关系本质，而不是粉饰。

**评分要点：**
- 有没有"骂你半天，其实是骂我自己"的句式
- 有没有"拆穿"关系本质的句子
- 有没有自嘲/淡然消解体面的句子

| 得分 | 表现 |
|------|------|
| 9-10 | 多次"拆穿"，真相残酷但克制，不泄愤 |
| 7-8 | 有2-3处真相点，但可以更深 |
| 5-6 | 有1处真相点，主体仍是叙事 |
| 3-4 | 少量真相，整体较粉饰 |
| 0-2 | 无真相，全篇体面粉饰 |

**满分表现：** "你没多坏，是我自己愿意的"——把自己骂进去，但让人更痛。

---

### 维度8：体面收尾度（0–10）

结尾是否"好像放下，又其实没放下"。

**评分要点：**
- 尾句云淡风轻，却是刀
- 和声停在 sus4，不解决
- 延音>2拍，不归主音
- 歌停了，人还在转

| 得分 | 表现 |
|------|------|
| 9-10 | 尾句云淡风轻却是刀，sus4悬空，歌停人还在转 |
| 7-8 | 尾句有余韵，但和声略完整 |
| 5-6 | 有留白但不够，尾句较完整 |
| 3-4 | 结尾明确，情绪关闭感强 |
| 0-2 | 完美解决，无回味 |

**满分表现：** 歌停了，但那句话还在脑子里转。

## 签发规则

| 范围 | 评价 | 处理 |
|------|------|------|
| ≥72/80 | 通过 | 输出MP3 |
| 64–71/80 | 小修 | 回lyrics-melody重校节拍与转调 |
| <64/80 | 重工 | 回emotion-curve重新设计情绪弧线 |
| <55/80 | 停止 | 主题逻辑错误，重新选题 |

---

## 评分后必做

1. 每项维度必须给出**一句话说明**（不能只写分数）
2. 任何维度<5分，必须在"质检日志"中注明原因
3. 小修/重工必须给出**具体修改指令**，不能只说"调整"
