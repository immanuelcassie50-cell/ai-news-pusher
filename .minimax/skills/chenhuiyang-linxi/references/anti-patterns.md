# 陈辉阳×林夕 常见失败模式

本文件列出陈辉阳×林夕词曲融合创作中的常见失败模式，供lyrics-melody Agent在写作迭代时参照规避。

---

## 失败模式一：小言情陷阱

**特征：** 歌词充满"我爱你"、"我想你"、"没有你"等直接情绪词。

**错误示例：**
```
"没有你的夜晚，我一个人好孤单"
"我好想你，你知道吗"
"我爱你，我爱你，我爱你"
```

**林夕式替代：**
```
"习惯了，也不算太坏"
"你来的时候，我就开始计算离开"
"我算过，这种难过有保质期"
```

**触发词检查：**
- [ ] "我爱你" → 改为"习惯了"、"离不开"
- [ ] "我想你" → 改为"删了几次"、"打了又没发"
- [ ] "没有你" → 改为"体面"、"算过时间"

---

## 失败模式二：鸡汤综合症

**特征：** 出现励志/治愈/正向引导句式。

**错误示例：**
```
"你值得更好的人"
"时间会治愈一切"
"爱自己才能爱别人"
"明天会更好"
```

**林夕式替代：**
```
"时间到了就过期"
"习惯了，也不算太坏"
"我没打算让你知道"
```

**触发词检查：**
- [ ] "值得" → 改为"没打算"
- [ ] "治愈" → 改为"过期"、"算了"
- [ ] "爱自己" → 改为"习惯了"
- [ ] "明天" → 改为"今晚"、"月底前"

---

## 失败模式三：狗血滑坡

**特征：** 出现生死/天荒地老/极致浪漫等夸张表达。

**错误示例：**
```
"我愿意为你去死"
"我们的爱天荒地老"
"海枯石烂不变心"
"你是我的唯一"
```

**林夕式替代：**
```
"今晚过期"
"习惯了，也不算太坏"
"你不坏，是我愿意的"
```

**触发词检查：**
- [ ] "死/活" → 改为"过期"、"作废"
- [ ] "天荒地老" → 改为"这段时间"
- [ ] "唯一/最爱" → 改为"习惯了"
- [ ] "永远" → 改为"今晚"、"月底前"

---

## 失败模式四：情绪直线（无波形）

**特征：** 情绪从头到尾平铺直叙，没有弧线变化。

**错误示例：**
- 全曲语气始终平静，无起伏
- 全曲语气始终悲伤，无转变
- 没有"体面崩坏"的过程

**陈辉阳式替代：**
```
V1：表面体面 →（第一针刺进来）
V2：开始失衡 →（情绪沉溺）
Pre-C：蓄力但克制 →（翻涌）
C：核心Hook →（痛感来自波形）
Bdg：自嘲清醒 →（看清楚）
末C：体面收线 →（云淡风轻）
```

**波形图检验：**
```
情绪强度
    ▲
    │    ●
    │   /│
    │  / │   ●
    │ /  │  /│\
    │/   │ / │ \
────●────●───●───●────▶ 歌曲段落
  V1  PreC  C  Bdg  末C
    \      /
     波形  \
           （不爆发，但全身在裂）
```

## 失败模式五：和声贫乏

**特征：** 大量使用传统三和弦（三和弦无扩展音），无maj7/9/sus。

**错误示例：**
```
| C | G | Am | Em | F | G | C |
```
（全是三和弦，无精致感）

**陈辉阳式替代：**
```
| Cmaj7 | Am7 | Dm7 | G7 |
| Cmaj9 | G/B | Am7 | Em7 |
| Fmaj7 | Gsus4 |
```

**和弦升级表：**

| 传统三和弦 | 升级为 | 效果 |
|-----------|--------|------|
| C | Cmaj7 | 都市感，轻微不安 |
| C | Cmaj9 | 精致，不协和但温柔 |
| Am | Am7 | 孤独，理性柔光 |
| F | Fsus2 | 悬空，留白 |
| G | Gsus4 | 悬空，不解决 |

---

## 失败模式六：旋律失控（高音爆发）

**特征：** Chorus冲高音G4以上，靠高音炫技。

**错误示例：**
- 全曲有多处E4以上高音
- 有明显"情绪爆发"段落
- 副歌靠高音制造高潮

**陈辉阳式替代：**
- Chorus音域控制在E4–G4，不冲更高
- 延音>2拍，不靠高音爆发
- 情绪靠和声堆叠，不靠旋律冲高

**检验点：**
```
音高
G4 ──────────────────■ Hook上限
E4 ────────────■───────■ 情绪核心
D4 ──────■───────────────
C4 ──■─────────────────── Verse音域
G3 ──────────────────────
    V1  PreC  C  Bdg  末C
```

---

## 失败模式七：体面崩坏失败

**特征：** 结尾太"说完"了，没有留白。

**错误示例：**
```
"我终于放下了，一切都结束了"（太完整）
"再见了，我的爱"（太煽情）
"这就是结局，再见"（太明确）
```

**陈辉阳式替代：**
```
"好像要结束了"
"习惯了，也不算太坏"
"好像懂了，好像也没打算让你懂"
"下次见面，就当没什么"
```

**检验点：**
- [ ] 尾句停在sus4？
- [ ] 延音>2拍？
- [ ] 不归主音？
- [ ] 歌停了，人还在转？

---

## 失败模式八：意象失焦

**特征：** 都市意象混乱，偏田园/古典，或者意象太空泛。

**错误示例：**
```
"你像天上的星星，照亮我的黑夜"（太古典/俗套）
"我在一片花海中想着你"（太田园）
"风吹过脸庞"（太泛）
```

**林夕式替代：**
```
"落地窗的灯，像说谎的嘴"
"手机屏幕亮了一下"
"便利店的灯，24小时开着"
```

**意象清单（必须≥3项）：**

| 类型 | 示例 |
|------|------|
| 私密空间 | 酒店房间、落地窗、床单温度 |
| 都市移动 | 的士后座、深夜地铁、航班 |
| 城市夜景 | 霓虹灯、便利店灯光、高楼天际线 |
| 数字时代 | 手机屏幕、已读不回、删了又打的号码 |

---

## 失败模式九：Hook 失败

**Hook太长的错误示例：**
```
"我爱你我爱你我爱你我爱你我爱你我爱你"（12+字，太长）
"我真的好爱好爱你啊"（太直接）
```

**无刺痛的错误示例：**
```
"我们在一起，好开心"（太平）
"我想你，你快来吧"（太直接，无反转）
```

**陈辉阳×林夕Hook标准：**
- ≤9字
- 双层语义（表面说A，内核说B）
- 有刺痛感

**成功Hook示例：**

| Hook | 表层 | 内核 |
|------|------|------|
| "你来的时候，我就开始计算离开" | 你来了 | 我早就在准备失去 |
| "习惯了，也不算太坏" | 习惯了 | 已经失去痛感 |
| "好像懂了，好像也没打算让你懂" | 懂了 | 不想沟通 |
| "我们都很体面，连难过都算过时间" | 体面 | 连痛都要算计 |

## 快速自检：常见失败触发词

**歌词出现以下词汇 → 必须修改：**

| 禁用词 | 替代词 |
|--------|--------|
| 我爱你 | 习惯了、离不开 |
| 我想你 | 删了几次、打又没发 |
| 生死/天荒地老 | 今晚、月底、过期 |
| 唯一/最爱 | 习惯了 |
| 永远 | 今晚、这段时间 |
| 值得更好 | 没打算让你知道 |
| 时间治愈 | 习惯了、过期 |
| 爱自己 | 算了 |
| 离开你活不了 | 习惯了，也不算太坏 |

**曲出现以下情况 → 打回：**

| 问题 | 标准 |
|------|------|
| 高音G4以上 | ≤2处 |
| 情绪爆发段落 | 禁止 |
| 传统三和弦 | ≤3处 |
| 尾句归主音 | 禁止 |
