# 陈辉阳×林夕 风格质感核对表

本文件是风格质检的快速核对表，供emotion-truth Agent在终检时参照。

---

## 检验一：都市意象清单

每首歌必须包含以下都市意象中的**至少3项**：

**私密空间：**
- [ ] 酒店房间 / 公寓 / 出租屋 / 落地窗 / 窗帘
- [ ] 浴室的蒸汽 / 枕头的形状 / 床单的温度

**都市移动：**
- [ ] 的士后座 / 深夜地铁 / 开车时的沉默
- [ ] 航班 / 电梯里的沉默 / 停车场

**城市夜景：**
- [ ] 霓虹灯 / 便利店24小时灯 / 高楼天际线
- [ ] 深夜街头 / 路灯光 / 雨夜

**数字时代：**
- [ ] 手机屏幕 / 短信 / 已读不回
- [ ] 删了又打的号码 / 朋友圈默契 / 点赞之交

**身体细节：**
- [ ] 手 / 香水味 / 衣领印记 / 眼泪位置
- [ ] 失眠的姿势 / 头痛

**禁用意象（出现即为不合格）：**
- [ ] 大自然意象（除非有都市转化）
- [ ] "生死"、"天荒地老"
- [ ] "为了你我就怎样"

## 检验二：情绪弧线核对

五段情绪弧线是否完整：

| 段落 | 情绪状态 | 检验点 |
|------|---------|--------|
| V1 | 表面体面 | [ ] 有没有维持克制的语气 |
| V1后半/V2 | 细微失衡 | [ ] 有没有出现第一针刺痛 |
| Pre-C → C | 情绪沉溺 | [ ] 有没有长句叠加/内心辩论 |
| Bdg | 自嘲清醒 | [ ] 有没有自嘲句（"我也不算太好"） |
| 末C → Outro | 体面收线 | [ ] 尾句是否云淡风轻却是刀 |

---

## 检验三：三层语义确认

以下句子必须能说出**Scene / Relation / Self** 三层：

**检验格式：**
```
句：[歌词]
Scene：[表层意象]
Relation：[关系内核]
Self：[自我内核]
```

**示例：**
```
句：落地窗的灯，像说谎的嘴
Scene：落地窗、灯——都市夜景
Relation：说谎——有人在关系里说谎
Self：但我信了——自我委屈
```

**任务：** 至少检验**3句**Chorus/Verse核心句子

---

## 检验四：林夕克制三原则

**以下情况出现任何一项，直接打回：**

1. **小言情（禁用）：**
   - [ ] "没有你我就怎样怎样"
   - [ ] "我好想你"
   - [ ] "我们的爱"

2. **鸡汤（禁用）：**
   - [ ] "你值得更好"
   - [ ] "时间会治愈一切"
   - [ ] "爱自己"

3. **狗血（降级）：**
   - [ ] "生死"、"天荒地老"（→改为"今晚"、"习惯了"）
   - [ ] "最爱"（→改为"习惯了"）
   - [ ] "永远"（→改为"这段时间"、"今晚"）

---

## 检验五：Hook句质检

Chorus Hook 必须满足：

| 标准 | 要求 | 检验 |
|------|------|------|
| 长度 | ≤9字 | [ ] 是/否 |
| 双层语义 | 表面说A，内核说B | [ ] 是/否（需说明） |
| 刺痛感 | 让人心里咯噔 | [ ] 是/否 |
| 延音适合 | 延音>2拍 | [ ] 是/否 |

**成功Hook示例：**
```
"你来的时候，我就开始计算离开"
表面：你来了
内核：我早就在准备失去
```

---

## 检验六：曲检验

**以下情况出现任何一项，打回lyrics-melody：**

- [ ] 高音G4以上超过2处
- [ ] 有明显情绪爆发段落
- [ ] 尾句归主音（1度或5度）
- [ ] 副歌靠高音炫技而非情绪堆叠

---

## 检验七：和声检验

**以下情况必须满足：**

- [ ] 主要和弦为 maj7/add9/sus4
- [ ] 传统三和弦（三和弦无7音）不超过3处
- [ ] Outro停在sus4，不解决
- [ ] Pre-C开始有maj7/add9介入

---

## 检验八：钢琴+弦乐检验

**以下情况必须满足：**

- [ ] Verse以钢琴分解和弦为主
- [ ] 弦乐在Pre-C才开始入场
- [ ] 弦乐长音铺底，不过度煽情
- [ ] 无密集弦乐柱式"喊"情绪

---

## 综合判定

**通过条件：**
- 都市意象 ≥3项 ✓
- 五段情绪弧线完整 ✓
- 三层语义确认 ≥3句 ✓
- 克制三原则通过 ✓
- Hook句质检通过 ✓
- 曲检验通过 ✓
- 和声检验通过 ✓
- 钢琴+弦乐检验通过 ✓

**任何一项不通过 → 打回相关Agent重写**
