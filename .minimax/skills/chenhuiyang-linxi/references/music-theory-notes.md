# 陈辉阳 音乐技法笔记

本文件是陈辉阳作曲/编曲技法的完整笔记，供lyrics-melody Agent在旋律设计时参照。

---

## 核心美学：钢琴+弦乐，音乐厅级质感

陈辉阳的编曲理念：**"音乐剧式流行歌"——音乐厅里也成立，KTV里也能哭。**

- 钢琴：Concert Grand，分解和弦为主，克制
- 弦乐：Chamber编制，长音铺底，不过度煽情
- 和声：精致，maj7/add9/sus4为王
- 整体：痛感来自波形堆叠，而非高音爆发

---

## 调式选择

### 主调：C / D / F 大调

陈辉阳极少用小调开场，大调带来"都市冷调感"：
- 大调的"明亮"但不是暖亮，是"太清醒的浪漫"那种冷光
- 中段可以转小调（如 C → Cm），增加情感深度
- 结尾常停在 sus4，制造悬空感

### 转调时机

- **Pre-Chorus：** 上升半音过渡，准备情绪抬升
- **Chorus：** 维持大调，用和声（maj7/add9）制造不安
- **Bridge：** 可回小调（C → Cm），增加自嘲感
- **Outro：** 大调 sus4 悬空，不回归主音

## 和弦语言

### 核心和弦类型

| 和弦 | 情绪效果 | 使用场景 |
|------|---------|---------|
| Cmaj7 | 都市感，轻微不安 | Verse 标配 |
| Cmaj9 | 精致，不协和但温柔 | Chorus 情绪堆叠 |
| Cadd9 | 灵动，诗意 | Pre-C 蓄力 |
| Csus4 | 悬空，暧昧，不解决 | Bridge / Outro |
| C6 | 都市诗意，比maj7更轻 | Verse 氛围 |
| Cdim | 失衡，第一针刺痛 | 转调过渡 |
| Cm7 | 孤独，理性柔光 | 小调段落 |

### 常用和弦进行

**Verse 标配：**
```
Cmaj7 – Am7 – Dm7 – G7
```
（干净但微微不安，像"一切都好，但哪里不对"）

**Pre-Chorus 蓄力：**
```
Fmaj7 – Em7 – Am7 – Dm7 – G7
```
（maj7介入，弦乐开始入场）

**Chorus 情绪堆叠：**
```
Cmaj9 – G/B – Am7 – Em7 – Fmaj7 – Dm7 – G7 – Cmaj7
```
（精致，和声浓烈，情绪波形堆叠）

**Bridge 自嘲理性：**
```
Fmaj7 – Gsus4 – G
```
（sus4悬空，制造"看清楚了但也没用"感）

**Outro 收线：**
```
Gsus4 – G
或
Csus4
```
（不解决，留白）

## 钢琴技法

### 段落钢琴节奏型

**Verse（慢叙事）：**
```
右手：分解和弦（C - E - G - B）
左手：根音 + 五度低音
节奏：慢，四分音符为主
力度：p - mp
```
（干净，克制，建立叙事感）

**Pre-Chorus（情绪蓄力）：**
```
右手：分解和弦 + 少量柱式
左手：根音推进
节奏：稍微紧凑，附点出现
力度：mp - mf
```
（情绪开始铺上来）

**Chorus（情绪波形）：**
```
右手：柱式 + 分解混合
左手：和弦音支撑
节奏：切分进入（后半拍）
力度：mf - f，但不超过
```
（不靠力度爆，靠波形堆叠）

### 延音技法（Hook句专用）

Hook句的钢琴处理：
- 右手：长音保持，不做装饰
- 左手的和弦：sus4 悬空，不解决
- 踏板：保持踏板，让声音连绵
- 延音时间：>2拍，不归主音

## 弦乐技法

### 陈辉阳弦乐的克制原则

**陈辉阳的弦乐不是用来"爆"的，是用来"铺"的：**

- 从不突然全开，而是在Pre-Chorus开始慢慢入场
- 从不用密集的弦乐柱式，而是长音铺底
- 从不用弦乐"喊"情绪，而是"托"情绪

### 弦乐段落设计

**Verse：**
- 无弦乐，或只有低音提琴（Double Bass）极轻地走根音
- 只留钢琴

**Pre-Chorus（入场）：**
- 小提琴开始在中高音区走长音
- 中提琴走和声垫底
- 力度：pp - p

**Chorus（铺满）：**
- 第一小提琴为主旋律和声（和声而非齐奏）
- 第二小提琴走对位旋律
- 中提琴和大提琴走和声垫底
- 力度：mp - mf

**Bridge（收拢）：**
- 只留大提琴低音长音
- 小提琴退出
- 力度：p

**Outro（淡出）：**
- 只有大提琴单音
- 力度：pp，渐弱至无声

### 弦乐情绪标记

| 情绪阶段 | 弦乐写法 | 力度 |
|---------|---------|------|
| 不安开始 | 颤音（tremolo） | p |
| 情绪沉溺 | 长音铺底 + 和声 | mp - mf |
| 自嘲清醒 | 收敛，只留低音 | p |
| 体面收线 | 淡出 | pp |

## 旋律设计：情绪波形

### 陈辉阳旋律三特征

1. **窄音域：** G3 – G4，不冲高音，靠情绪堆叠
2. **延音技法：** Hook句延音>2拍，不归主音
3. **波形节奏：** 不是"起-承-转-合"，而是"翻涌-翻涌-翻涌"

### 各段旋律音域

| 段落 | 音域 | 方向 | 典型技法 |
|------|------|------|---------|
| V1 | G3–C4 | 窄，稳定 | 级进下行，偶有跳进 |
| Pre-C | C4–D4 | 微上行 | 级进上行，不跳进 |
| C | E4–G4 | 宽但可控 | 延音>2拍，切分 |
| V2 | G3–D4 | 略宽于V1 | V1动机变体 |
| Bdg | D4–C4 | 下行 | 空间感，留白 |
| 末C | E4–G4 | 同C | 延音，混响增大 |
| Outro | G3 | 低音落点 | sus4，不归主音 |

### 旋律走向原则

**反高潮原则：**
- 副歌不冲高音，而是"微微往下掉"
- 情绪的高点不是音高，而是和声的紧张度
- 痛感来自波形堆叠，不是高音爆发

**融合检验：**
```
听完整首歌，问自己：
- 是"全身翻涌"还是"哭出来"？
- 是"脑子在想"还是"心里在痛"？
- 是"优雅地心碎"还是"崩溃了"？
→ 如果是前者 = 陈辉阳✓
→ 如果是后者 = 传统流行 ✗
```

## BPM 与节拍

### 推荐 BPM：72–80

这个速度是"慢中带一点力"：
- 太快：失去叙事感，变成舞曲
- 太慢：失去都市感，变成抒情 ballad

### 节拍：4/4 或 6/8

**4/4：** 叙事感强，Verse/Chorus 都适用
**6/8：** 流动感强，适合情绪沉溺段

---

## 反高潮结构

### 传统流行曲结构

```
Verse(低) → Pre-C(中) → Chorus(高) → 爆发！
```

### 陈辉阳式结构

```
Verse(中低) → Pre-C(微升) → Chorus(微微掉) → 悬空！
```

### 能量曲线

```
              Pre-C
             /
            /
V1 --------               ← 稳定，低，不爆发
            \
             \     末C
              \  /
               \/
          Chorus

特点：整体下行，尾音不归主音
```

## 悬空结尾技法

### sus4 悬空

最典型的陈辉阳结尾：
```
| Gsus4 | G |    或    | Gsus4 | (pause) |
```
- sus4 不解决到 G
- 停在暧昧和弦，听感上"没有结束"
- 配合延音>2拍

### sus2 悬空

另一种悬空结尾：
```
| Fsus2 | (pause) |
```
- 更轻，更都市感
- 配合钢琴分解和弦

### 开放音悬空

尾音不是和弦根音或五度音：
```
| Cmaj7 | Bdim | Am7 | Gsus4 | (pause) |
尾音停在 Gsus4 的四度音（C），不是根音（G）
```

## 编曲空间设计

### Reverb 设置

- **Hall：** 尾音清晰，小厅感（0.25–0.35）
- **Room：** 钢琴/弦乐真实感（0.2–0.3）
- 混响时间：1.5–2.5秒

### Stereo 宽度

- **总体：** 0.75–0.80（中宽）
- **Vocal：** 中心偏右 0.2
- **Piano：** 中左 0.3
- **Strings：** 右侧铺底 0.4
- **Bass：** 低区中心

### 动态范围

- **混音后：** 0.85（保留动态，但不失真）
- **人声：** 贴近耳朵，有气息细节
- **钢琴：** 不过度压缩，保持自然衰减

### 陈辉阳式 Chorus 编配

```
| 段落 | 时长 | 钢琴 | 弦乐 | 力度 |
|------|------|------|------|------|
| 前奏 | 4小节 | 分解和弦Cmaj9 | 无 | p |
| V1 | 8小节 | 分解和弦Cmaj7 | Double Bass根音 | p |
| Pre-C | 4小节 | 分解+柱式混合 | 小提琴长音入场 | mp |
| C | 8小节 | 柱式+分解混合 | 全弦乐铺底 | mf |
| V2 | 8小节 | V1动机变体 | 弦乐和声 | mp |
| Bdg | 4小节 | sus4悬空 | 大提琴单音 | p |
| 末C | 8小节 | 同C，延音多 | 弦乐混响增大 | mf |
| Outro | 4小节 | Gsus4悬空 | 淡出 | pp |
```
