# 陈辉阳×林夕 快速质量自检10项

本文件是10项快速质量自检，供music-production Agent在验收前参照。

---

## 自检1：都市感（2分）

**检查项：**
- [ ] 城市场景≥3项（酒店/的士/落地窗/便利店/深夜地铁）
- [ ] 都市物件精准（酒杯/手机/灯光/雨/雾）
- [ ] 无田园/古典意象

**得分标准：**
- 3项全✓ → 2分
- 2项全✓ → 1分
- 1项或0项 → 0分

---

## 自检2：体面崩坏（2分）

**检查项：**
- [ ] 有明确的"体面"建立（语气克制）
- [ ] 有"崩坏裂缝"（刺痛句出现）
- [ ] 有"崩坏前一秒"（情绪最痛点）
- [ ] 结尾有"体面收线"（云淡风轻却是刀）

**得分标准：**
- 4项全✓ → 2分
- 2-3项 → 1分
- 0-1项 → 0分

---

## 自检3：情绪波形（2分）

**检查项：**
- [ ] 不是情绪直线，而是波形翻涌
- [ ] 有蓄力（Pre-C），但不爆发
- [ ] 情绪靠波形堆叠，不靠高音炫技

**得分标准：**
- 3项全✓ → 2分
- 2项 → 1分
- 0-1项 → 0分

---

## 自检4：三层语义（2分）

**检查项：**
- [ ] Scene层：都市物件/场景（可直接描述）
- [ ] Relation层：关系权力/身份博弈
- [ ] Self层：自我认知/身份焦虑

**得分标准：**
- 3层全有 → 2分
- 2层 → 1分
- 0-1层 → 0分

---

## 自检5：和声精致（2分）

**检查项：**
- [ ] 主要和弦为 maj7/add9/sus4
- [ ] sus4 悬空结尾（不解决）
- [ ] 传统三和弦不超过3处

**得分标准：**
- 3项全✓ → 2分
- 2项 → 1分
- 0-1项 → 0分

---

## 自检6：Hook刺痛感（2分）

**检查项：**
- [ ] Hook≤9字
- [ ] 有双层语义（表面说A，内核说B）
- [ ] 有刺痛感（让人心里咯噔）

**得分标准：**
- 3项全✓ → 2分
- 2项 → 1分
- 0-1项 → 0分

---

## 自检7：克制三原则（2分）

**检查项：**
- [ ] 无小言情（"我爱你"/"我想你"/"没有你"）
- [ ] 无鸡汤（"值得更好"/"时间治愈"）
- [ ] 无狗血（"生死"/"天荒地老"）

**得分标准：**
- 3项全✓ → 2分
- 2项 → 1分
- 0-1项 → 0分

---

## 自检8：旋律贴合（2分）

**检查项：**
- [ ] 词语呼吸位置与拍点吻合
- [ ] 唱出来的节奏和说出来的节奏一致
- [ ] 延音/切分使用自然

**得分标准：**
- 3项全✓ → 2分
- 2项 → 1分
- 0-1项 → 0分

---

## 自检9：钢琴+弦乐质感（2分）

**检查项：**
- [ ] 钢琴分解和弦为主，不抢人声
- [ ] 弦乐在Pre-C入场，长音铺底
- [ ] 无密集弦乐柱式"喊"情绪

**得分标准：**
- 3项全✓ → 2分
- 2项 → 1分
- 0-1项 → 0分

---

## 自检10：后劲留白（2分）

**检查项：**
- [ ] 尾句云淡风轻，却是刀
- [ ] 和声停在sus4，不解决
- [ ] 延音>2拍，不归主音
- [ ] 歌停了，人还在转

**得分标准：**
- 4项全✓ → 2分
- 2-3项 → 1分
- 0-1项 → 0分

## 快速修复指令

**都市感不足：** 加3项都市意象（酒店/的士/手机等）
**体面崩坏失败：** 检查V1是否建立体面，Bdg是否有自嘲
**情绪直线：** 在Pre-C加蓄力，在C用波形堆叠
**三层语义缺失：** 给每句标Scene/Relation/Self
**和声贫乏：** 把三和弦升级为maj7/9/sus
**Hook无刺痛感：** 改为双层语义
**克制失败：** 替换禁用词表
**旋律失贴：** 调整拍点呼吸
**弦乐失控：** 改为长音铺底
**后劲不足：** 改尾句为sus4悬空
