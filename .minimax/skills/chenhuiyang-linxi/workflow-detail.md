# 团队协作详细执行指南

本文件是SKILL.md的执行细则补充。首次使用技能时通读，协作时按角色查阅对应章节。

## 全局协作协议

### Agent职责边界

| Agent | 产出物 | 接受来自 | 交付给 |
|-------|--------|---------|--------|
| scene-architect | 城市场景方案 + 关系身份设定 + 体面设定 | 用户输入 | emotion-curve |
| emotion-curve | 五段情绪弧线 + 关键词 + 和声氛围描述 | scene-architect | lyrics-melody |
| lyrics-melody | 歌词+旋律注释+和弦建议 | emotion-curve | harmony-piano |
| harmony-piano | 讽刺韵律和声编排 | lyrics-melody | arrangement-designer |
| arrangement-designer | 编曲/音色/音景/混响方案 | harmony-piano | emotion-truth |
| emotion-truth | 冷校检验报告（通过/打回） | arrangement-designer | music-production |
| music-production | MP3 + 8维评分卡 | emotion-truth | team-lead |
| team-lead | 终稿 + 创作手记 | music-production | 用户 |

### 状态传递格式（交接块）

每个Agent完成后必须输出以下交接块，再传递给下一Agent：

```
---
## [Agent X] → [Agent Y] 交接

**场景主题：** （一句话描述）
**场景空间：** （酒店房间/旧城区街灯/高楼落地窗/的士后座/深夜地铁）
**关系身份：** （情人/前任/地下关系/婚外/暧昧/旧友新恋）
**体面设定：** （谁更有权力、谁表面占上风、谁在道德上"站得住脚"）
**五段情绪弧线：** 表面体面 → 细微失衡 → 情绪沉溺 → 自嘲清醒 → 体面收线
**调式建议：** C / D / F 大调，BPM 72–80
**核心和弦：** Cmaj7 – Am7 – Dm7 – G7
**关键词：** （每个情绪阶段的关键词）
**用户特别要求：** （如有）
---
```

### 干预指令

- "停一下" / "等等" → 暂停当前Agent
- "回到角色X" → 回工到指定Agent
- "跳过" → 跳过当前Agent
- "直接写" → 跳过scene-architect/emotion-curve，直接进入lyrics-melody
- "更心痛一点" → 提高情绪沉溺段权重
- "再体面一点" → 强化表面克制，减少情绪外露
- "更残酷" → 强化真相校准，提高"拆穿"力度

### 回工规则

| 触发条件 | 回工目标 | 规则 |
|---------|---------|------|
| 评分<64 | lyrics-melody | 保留情绪弧线，调整词曲融合方式 |
| 评分<56 | emotion-curve | 情绪根本问题，重新设计弧线 |
| 出现小言情/高呼/哭腔 | emotion-truth | 打回lyrics-melody重写该句 |
| 曲出现高音爆发 | emotion-truth | 打回lyrics-melody重新设计副歌 |
| 连续2轮评分提升<5% | 当前最优版签发 | 标注风险维度 |

## scene-architect 执行细则

### 输入处理

**模糊输入：** 用户说"写首歌"但没给主题时，最多问2个问题：
1. "这首歌想呈现哪种都市情感——体面的崩塌？关系的沉溺？还是一种说不出的身份焦虑？"
2. "有没有什么城市空间让你产生这种感觉？比如酒店房间、深夜的士、高楼落地窗。"

**过宽输入：** 用户给"爱情"/"人生"等宽泛主题 → 要求细化到都市具体时刻和关系身份

**林夕式主题特征：** 表面是都会场景，内核是心理剖析、身份焦虑、关系成瘾

### 场景生成（3-5个差异化方案）

从以下维度生成（至少覆盖3个）：

1. **私密空间类**：酒店高层房间、深夜公寓、旧城区出租屋、高楼落地窗
2. **移动空间类**：的士后座、深夜地铁、航班上、开车时的沉默
3. **都市夜色类**：城市天际线、便利店灯光、深夜街头、酒吧角落
4. **关系成瘾类**：暧昧、地下恋、婚外、分手后的默契、旧友新恋
5. **身份焦虑类**：职场与私生活、公开与隐蔽、体面与真实

### 体面设定原则

每个场景必须同时包含：
- **权力关系：** 谁在这段关系中更有主动权
- **表面体面：** 双方如何维持表面的正常
- **内在崩塌：** 什么让这个体面开始动摇

### 输出格式

```markdown
## 场景方案

**用户主题：** [原始输入]

### 角度1：[场景标题]（[类型]）
- **场景空间：** [具体城市空间描述]
- **关系身份：** [关系类型 + 权力设定]
- **体面设定：** [谁表面占上风、谁在道德上"站得住脚"]
- **内在张力：** [什么让体面开始动摇]
- **林夕参照：** 《___》——因为[相似点]
- **调式建议：** C 大调 / 75 bpm / 4/4
- **意象清单：** 场景物件≥5（光影/声音/触感/气味）
- **初评分：** 都市感X / 情感复杂度X / 林夕气质X / 曲调契合X = 总XX

### 角度2：...
### 角度3：...

### 推荐
首选角度[N]，理由：___
次选角度[N]，理由：___

请选择一个角度，或告诉我新的方向。
```

## emotion-curve 执行细则

### 执行前必读

`references/style-anatomy.md` 全文（林夕心理剖析技法）
`references/fusion-guide.md` 全文（陈辉阳×林夕情绪波形法）

### 核心：林夕式五段情绪弧线

陈辉阳×林夕模式的情绪是**波形**而非**直线**：

1. **表面体面（Surface Dignity）：**
   - 语气："没什么啦"、"反正这么久了"、"你也没多坏"
   - 和声：大调/模糊和弦，节奏慢，钢琴干净分解
   - 情绪基准：镇定、克制、有一点点刻意

2. **细微失衡（Micro-Imbalance）：**
   - 出现一句刺痛直白：
     - "短信我删了几次"
     - "你说这算什么关系"
   - 旋律微上行，钢琴开始走不稳
   - 和声加入 maj7/add9，不协和但温柔

3. **情绪沉溺（Emotional Absorption）：**
   - 长句叠加、内心辩论
   - 和声转小调或加入不稳定和弦（maj7, add9, dim）
   - 弦乐开始入场，长音铺底
   - 情绪：已经陷进去了，但还在假装没事

4. **自嘲清醒（Self-Mocking Clarity）：**
   - 语言出现自嘲："我也不算太好"、"你也没多坏"
   - 音乐拉回理性，节奏放缓，弦乐收拢
   - 和声：回归大调，但加入 sus4 制造暧昧
   - 情绪：看清楚了，但看清了也没有用

5. **体面收线（Dignified Closure）：**
   - 最后一句看似云淡风轻，却是刀：
     - "下次见面，就当没什么"
     - "习惯了，也不算太坏"
   - 和声留在悬挂音（sus2/sus4），不完全解决
   - 情绪：好像放下了，其实没有

### 情绪弧线模板

```markdown
## 五段情绪弧线

**场景：** [选定场景]
**调式：** C 大调 / 75 bpm / 4/4（慢中带一点力）
**弦乐入场时机：** Pre-Chorus 开始入场

---

### 第1段：表面体面（V1 前半）
语气：平静、叙事、有一点点刻意
和声：Cmaj7 – Am7（干净，稳定）
弦乐：无（纯钢琴）
情绪关键词：镇定、距离感、表面正常
旋律音域：G3–C4（窄，稳定）

### 第2段：细微失衡（V1 后半 + V2）
语气：出现刺痛直白句
和声：Cmaj7 – Am7 – Dm7 – G7（加入maj7，制造不安）
弦乐：低音弦乐轻入
情绪关键词：不对、开始动摇、假装没事
旋律音域：C4–D4（轻微上行）

### 第3段：情绪沉溺（Pre-C → C）
语气：长句叠加，内心辩论，"凭什么委屈到这程度"
和声：Am7 – Dm7 – G7 – Cmaj9（加入 add9，tension 上升）
弦乐：弦乐全开，长音铺底
情绪关键词：陷进去了、无法自拔、还在装
旋律音域：D4–E4（情绪核心，但不冲太高）

### 第4段：自嘲清醒（Bdg）
语气：自嘲句，"我也不算太好"
和声：Fmaj7 – Em7 – Am7（拉回理性）
弦乐：收拢，只留低音弦乐
情绪关键词：看清楚了、看清楚了也没用
旋律音域：D4–C4（开始下行）

### 第5段：体面收线（末C + Outro）
语气：云淡风轻，却是刀
和声：Cmaj7 – Gsus4 – G（sus4 悬空，不完全解决）
弦乐：淡出
情绪关键词：好像放下了、其实没有、后劲留白
旋律音域：C4–G3（落在低音，不归主音）
```

## lyrics-melody 执行细则

### 执行前必读

1. `references/fusion-guide.md` 全文（陈辉阳×林夕对位融合策略）
2. `references/style-anatomy.md` 全文（林夕技法）
3. `references/music-theory-notes.md` 全文（陈辉阳钢琴旋律技法）
4. `references/anti-patterns.md` 全文（失败模式）

### 词曲共构核心原则

**林夕三层语义法：**
1. **表层（Scene）：** 当下场景——酒杯、灯、手机、衣服、雨、雾
2. **中层（Relation）：** 关系张力——谁逃、谁等、谁装睡
3. **深层（Self）：** 自我认知——"我凭什么委屈到这程度"

**句型搭配（林夕式）：**
- 比喻句（意象+情绪）："你说的承诺像夜机航线"
- 直白句："我明白你不会离开她"
- 反语句："我们都很体面，连难过都算过时间"

**陈辉阳旋律核心：**
- 钢琴主导，弦乐铺底
- 旋律像心理波形——不爆发，但全身都在翻涌
- Chorus 靠情绪堆叠，不靠高音炫技
- 痛感 = 和声 + 语气，而非高音

**固定（不可改动）：**
- 每句歌词对应精确节拍呼吸点
- 副歌≤9字hook句，延音>2拍，不冲高音 G4
- 旋律下行而非爆发（情绪下行弧线）
- Verse → Chorus 能量曲线：轻微上扬 → 不动 → 微微下沉

**AI空间（灵活发挥）：**
- 三层语义精准调度
- 林夕式都市隐喻
- 情绪微差（在低能量区间内的层次）
- 自嘲/淡然句

### 陈辉阳式情绪波形结构

| 段 | 旋律方向 | 典型陈辉阳技法 |
|----|---------|---------------|
| V1 | G3–C4，窄音域，钢琴分解和弦 | 级进下行，不跳进，慢起 |
| Pre-C | 轻微上升，弦乐开始入场 | maj7/add9 加tension |
| C | E4–G4，延音>2拍，情绪堆叠 | 下行主导，不冲G4 |
| V2 | V1动机变体，音域略宽 | 和声加厚，弦乐铺垫 |
| Bdg | 拉回理性，空间感 | sus4 制造暧昧 |
| 末C | 同C，混响增大，尾句不归主音 | sus2/sus4 悬空 |

### 歌词+旋律注释模板

```markdown
## 歌词初稿 + 旋律注释

**标题：** 《____》
**调式：** C 大调 / BPM 75 / **节拍：** 4/4
**情绪弧线：** V1 → PreC → C → V2 → Bdg → 末C
**核心和弦进行：** Cmaj7 – Am7 – Dm7 – G7
**弦乐入场：** Pre-Chorus 开始

---

[V1]
歌词歌词歌词（节拍：慢起，叙事感）
旋律走向：G3–C4，钢琴分解和弦，级进为主
和弦：Cmaj7 – Am7
情绪张力：表面体面建立，距离感
融合点：[都市意象] × [窄音域稳定旋律] = 林夕冷静叙事

歌词歌词歌词（节拍：后半句微上行）
旋律走向：C4 附近，不跳进
和弦：Am7 – Dm7
情绪张力：开始动摇，第一针刺进来
融合点：[刺痛直白] × [微上行旋律] = 陈辉阳式不安

[Pre-Chorus]
歌词歌词歌词（情绪抬升，但仍然克制）
旋律走向：D4–E4，轻微上行但不冲
和弦：Fmaj7 – Em7 – Dm7 – G7（maj7 加tension）
弦乐：弦乐开始入场，长音铺底
情绪张力：蓄力中，情绪翻涌但不爆发
融合点：[内心辩论长句] × [弦乐铺底] = 翻涌感

[Chorus]

旋律走向：E4–G4，延音>2拍，不冲G4，下行主导
和弦：Cmaj9 – G/B – Am7 – Em7
弦乐：弦乐全开
情绪张力：痛感=和声+语气，而非高音爆发
融合点：[三层语义] × [情绪波形旋律] = 优雅地心碎
可重复三遍：是，节奏型不变，力度略升

[V2]
歌词歌词歌词歌词（情绪深化，不重复V1）
旋律走向：V1动机变体，音域略宽
和弦：Am7 – Dm7 – G7 – Cmaj7
弦乐：和声加厚

[Bridge]

旋律走向：低音延音，空间感，不解决
和弦：Fmaj7 – Gsus4 – G（sus4 悬空）
弦乐：收拢，留低音弦乐
情绪张力：全曲最清醒段落
融合点：[自嘲句] × [sus4悬空] = 看清楚了也没用

[Chorus - 末]

旋律走向：同Chorus，混响空间增大

[Outro]
最后一句云淡风轻，却是刀
旋律走向：C4–G3，落在低音，不归主音

弦乐：淡出
情绪张力：歌停了，人还在转
```

## harmony-piano 执行细则

### 执行前必读

`references/music-theory-notes.md` 全文（陈辉阳和弦理论）

### 陈辉阳式和声骨架

陈辉阳的和声特征：**温柔，但不协和；精致，但制造不安。**

| 和弦类型 | 功能 | 情绪效果 |
|---------|------|---------|
| Cmaj7 | 都市感、轻讽刺 | 明亮但不暖，理性但有光 |
| add9 | 灵动、温柔、都会感 | 都市诗意 |
| sus4 | 缠绕、暧昧、不解决 | 悬念感，持续张力 |
| m7 | 孤独、理性柔光 | 深夜感 |
| maj9 | 精致、不安 | 像想不通的事 |
| dim | 失衡、转调过渡 | 第一针刺痛 |

**标准走向：** Cmaj7 – Am7 – Dm7 – G7
或 Cmaj9 – Em7 – A7 – Dm7

**段落走向参考：**
- Verse：Cmaj7 – Am7 – Dm7 – G7
- Pre-Chorus：Fmaj7 – Em7 – Am7 – Dm7 – G7
- Chorus：Cmaj9 – G/B – Am7 – Em7 – Fmaj7 – Dm7 – G7 – Cmaj7

**特点：**
- 频繁用 maj7 / 9度音使情绪既"优雅"又"不安"
- 和弦推不猛，但很"滑"，像心理想不通的回圈
- sus4 频繁使用，悬空不解决，制造"永远没有真正解决"感

### Piano + Strings 编排原则

- Piano：Concert Grand，分解和弦为主，副歌可柱式
- Strings：Chamber 编制，不过度，不煽情
- Bass：低频稳定，不抢，不跳
- 节奏：轻刷鼓、低频底鼓，弱存在感

## arrangement-designer 执行细则

### 目标音场：音乐厅级室内感

陈辉阳的编曲理念：**"音乐剧式流行歌"——音乐厅里也成立，KTV里也能哭。**

**乐器层级：**
- 主体：Piano（Concert Grand）、Strings（Chamber）
- 情感层：小号或单簧管少量点缀
- 节奏：轻刷鼓、低频底鼓，弱存在感
- 氛围：Pad / Room tone（空调声、轻微环境）

**空间设定：**
- Reverb：Hall + Room 混合，小厅感，尾音清晰
- Stereo：中宽（0.75–0.8），人声靠前、乐器铺后
- Vocal：贴近耳朵但不爆，保留细节（气息、吞咽）

**声像分配：**
- Vocal 中心偏右 0.2
- Piano 中左 0.3
- Strings 右侧铺底 0.4
- Bass 低区中心
- 环境音 全景淡入

## emotion-truth 执行细则

### 核心检验：林夕式"拆穿"

林夕的最高技法：**骂你半天，其实是骂我自己。**

**规则（违反任何一条，立即打回）：**
- 不许小言情（"没有你我就怎样怎样"）→ 必须砍掉
- 不许鸡汤（"你值得更好"）→ 禁用
- 不许狗血（"生死、天荒地老"）→ 降级为现实句
- 不许高呼 → 曲高音区 G4 以上不超过 2 处
- 不许哭腔/感叹号 → emotion-truth 强制打回

**改写策略：**
- 把"永远"改为"今晚"
- 把"生死"改为"月底前"
- 把"最爱"改为"习惯了"
- 把"我恨你"改为"我也不是太坏"

**目标：** 要残忍，但不夸张；要诚实，但不泄愤。

### 检验标签

- NLP标签含「生死」「天荒地老」「没有你我就死」→ 打回
- 曲冲 G4 高音 > 2处 → 打回 lyrics-melody
- 感叹号 > 0 → 打回该句重写
- 尾句归主音（1或5度） → 打回修改结尾

### 输出格式

```markdown

和声悬空 | ❌ 需改 | 末句归主音，建议改为sus4悬空
自嘲力度 | ✅ 通过 | Bridge出现"我也不算太好"类句式
```

### 8维评分执行

| # | 维度 | 满分标准 |
|---|------|---------|
| 1 | 都市感 | 场景是否明确、现代、有城市空间感 |
| 2 | 情绪梯度 | 体面→失衡→沉溺→自嘲→收线是否完整 |
| 3 | 语言锋利度 | 是否有1–2句"听完会刺一下"的句子 |
| 4 | 旋律贴合度 | 每句是否唱得出口、节奏跟语气吻合 |
| 5 | 和声精致度 | maj7/9/sus 和弦运用是否服务情绪 |
| 6 | 编曲美感 | 钢琴+弦乐是否有"音乐厅级质感" |
| 7 | 真相残酷度 | 有没有点出关系本质，而不是粉饰 |
| 8 | 体面收尾度 | 结尾是否"好像放下，又其实没放下" |

### 签发规则

| 总分区间 | 决策 | 动作 |
|---------|------|------|
| ≥72/80 | 通过签发 | 推送team-lead聚合终稿 |
| 64–71/80 | 小修 | 回lyrics-melody重校节拍与转调 |
| <64/80 | 重工 | 回emotion-curve重新设计情绪弧线 |
| <55/80 | 停止 | 主题逻辑错误，重新选题 |

## 安全边界

### 内容安全闸门

以下情况强制调整：
- 全曲过于悲伤/崩溃 → 在Bridge或尾句注入自嘲/淡然
- 出现小言情/高呼/哭腔 → 必须以林夕式隐喻重写
- 曲冲高音 G4 超过2处 → 打回lyrics-melody降调

### 版权边界

- 不直接引用已发表歌词原句
- 原型作品仅作技法参照，不作内容来源
- "写一首像林夕风格的歌"→学技法不学内容
