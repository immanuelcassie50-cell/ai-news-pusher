# 陈辉阳×林夕 词曲一体创作系统（RPD融合版 v1.1）

本技能通过8角色团队协作，生成具备**林夕式都市心理剖析**与**陈辉阳式钢琴弦乐工程学**的完整情感歌曲，并输出MP3试听文件。

**核心理念：** 词不直说、曲不直爆，但两者交缠成一种"优雅地心碎"。用一句话总结——**不崩溃，但全身都在裂。**

## 团队成员

| Agent | 角色 | 核心职责 |
|-------|------|---------|
| `scene-architect` | 场景与身份构图师 | 城市场景 + 关系身份，体面设定 |
| `emotion-curve` | 心理剖面与情绪曲线设计师 | 五段情绪弧线（体面→失衡→沉溺→自嘲→收线） |
| `lyrics-melody` | 词曲共构引擎 | 林夕三层语义 × 陈辉阳情绪波形旋律 |
| `harmony-piano` | 和声与钢琴结构建筑师 | maj7/add9/sus4 钢琴和弦骨架，陈辉阳式留白 |
| `arrangement-designer` | 编曲与声场设计师 | 钢琴+弦乐为核，音乐厅级质感 |
| `emotion-truth` | 情绪真相校准师 | 林夕式"拆穿"，禁止小言情/鸡汤/狗血 |
| `music-production` | 评分签发 | 8维评分，80分制，签发决策 |
| `team-lead`（主控） | 协调 + 终稿聚合 | 监控流程，聚合交付物，生成创作手记 |

## 执行流程

```
用户输入主题（如"见不得光的关系"）
    ↓
[scene-architect] 生成城市场景方案 + 关系身份设定（3-5个）
    ↓（用户确认）
[emotion-curve] 构建五段情绪弧线 + 关键词 + 和声氛围
    ↓
[lyrics-melody] 词曲共构（歌词+旋律注释+和弦）
    ↓
[harmony-piano] 设计陈辉阳式和声骨架（maj7/9/sus为主）
    ↓
[arrangement-designer] 编曲与声场设计（钢琴+弦乐室内感）
    ↓
[emotion-truth] 林夕式校准检验（禁止小言情/高呼/哭腔）
    ↓
[music-production] 8维评分 + 签发决策
    ↓
[team-lead] 聚合终稿 + 创作手记 + 评分卡
    ↓
交付：歌词（含旋律注释）.md + MP3文件
```

## 用户输入 / 产出格式

**用户提供（三选一）：**
- A. 模糊主题（如"见不得光的关系"、"都市孤独"）→ scene-architect 自动发散
- B. 具体情境（如"深夜酒店房间的两个人"）→ 直接进入情绪曲线设计
- C. 指定情绪类型 → 适配调式与曲风

**Claude产出：**
1. 完整歌词（含旋律走向注释、和弦、调式建议）
2. MP3试听文件（via MiniMax TTS）
3. 创作手记（≤500字）
4. 8维评分卡

## 协作规则

1. **用户介入点：** scene-architect 输出后必须等用户确认角度
2. **回工机制：** music-production 评分<64时自动触发回工，附具体原因
3. **安全闸门：** 若歌词出现小言情/高呼/哭腔/感叹号 → emotion-truth 强制打回
4. **迭代上限：** 评分重修最多2轮，超出则以当前最优版签发并标注风险

## Team模式约定

本技能默认开启Team模式。team-lead 在每阶段完成后主动报告进度（SendMessage to "team-lead"），超时3分钟无消息则主控主动询问，超时5分钟则TaskStop并接管。

## 不适用场景

- **已有完整歌词，只需配乐/作曲：** 请使用单独的音乐制作类skill
- **纯欢乐/爆发类歌曲：** 请使用唐恬×钱雷系统
- **纯智性讽喻/冷幽默歌曲：** 请使用林振强×施立系统
- **仅需分析现有歌曲的创作技法：** 请使用歌词/作曲分析类skill
- **用户只需要一个音乐文件，不需要歌词创作：** 请使用纯音乐/TTS类skill

## 交付说明

所有产出文件生成完毕后，使用 `present_files` 工具将以下文件交付给用户：
1. 歌词终稿（含旋律走向注释、和弦、调式建议）的 `.md` 文件
2. MP3试听文件

交付时附上一句话完成说明，例如："已完成陈辉阳×林夕风格歌曲创作和MP3试听，详见文件。"
