# 团队协作详细执行指南

本文件是SKILL.md的执行细则补充。首次使用技能时通读，协作时按角色查阅对应章节。

---

## 全局协作协议

### Agent职责边界

| Agent | 产出物 | 接受来自 | 交付给 |
|-------|--------|---------|--------|
| geo-scene | 城市/地点方案 + 时间/状态 | 用户输入 | story-bone |
| story-bone | 叙事线：开头→关系→分开→现在 | geo-scene | lyrics-melody |
| lyrics-melody | 歌词+旋律注释+和弦建议 | story-bone | arrangement |
| arrangement | 编曲/音色/音景/混响方案 | lyrics-melody | truth-filter |
| truth-filter | 真诚度检验报告（通过/打回） | arrangement | team-lead |
| team-lead | 终稿 + 创作手记 + 评分卡 | truth-filter | 用户 |

### 状态传递格式（交接块）

每个Agent完成后必须输出以下交接块，再传递给下一Agent：

```
---
## [Agent X] → [Agent Y] 交接

**城市/地点：** 成都 / 玉林路 / 小酒馆门口
**场景时间：** 深夜 / 冬天 / 黄昏
**人物状态：** 分手后 / 刚丢工作 / 旅行中 / 回老家
**叙事起点：** 一个画面（街、路、酒馆、公交车、客栈）
**关系设定：** 一句话描述你们之间的关系
**分开/错过时刻：** 一句话
**现在的"我"：** 一句话（继续一个人走/释然/怀旧）
**调式建议：** G 大调 / C 大调，BPM 72–80
**核心和弦：** G – Em – C – D
**关键词：** （每个叙事阶段的关键词）
**用户特别要求：** （如有）
---
```

### 干预指令

- "停一下" / "等等" → 暂停当前Agent
- "回到角色X" → 回工到指定Agent
- "跳过" → 跳过当前Agent
- "直接写" → 跳过geo-scene/story-bone，直接进入lyrics-melody
- "更漂一点" → 提高流浪感权重，强化"在路上"意象
- "更真实一点" → 增加生活物件和现实感
- "更地理一点" → 增加城市/街/店名等地理词密度
- "更怀旧一点" → 强化时间感（那年/曾经/后来）

### 回工规则

| 触发条件 | 回工目标 | 规则 |
|---------|---------|------|
| 评分<64 | lyrics-melody | 保留叙事线，调整词曲融合方式 |
| 缺少地理词 | geo-scene | 重新加入城市/街/店名 |
| 出现大词（灵魂/宿命/宇宙） | truth-filter | 打回lyrics-melody删除并替换 |
| 缺少生活物件 | truth-filter | 打回lyrics-melody加入至少一个 |
| 连续2轮评分提升<5% | 当前最优版签发 | 标注风险维度 |

## geo-scene 执行细则

### 输入处理

**模糊输入：** 用户说"写首民谣"但没给地点时，最多问2个问题：
1. "这首歌发生在哪个城市——成都、重庆、昆明、东北小镇？还是一个你熟悉但没名字的地方？"
2. "那个地方有没有一条街、一个小馆子、一个路口，让你想起某个人或某段时光？"

**过宽输入：** 用户给"人生"/"流浪"/"远方"等宽泛主题 → 要求细化到城市具体地点和人物状态

**赵雷式地理特征：** 城名/街名/小馆子/路口/公交线/胡同/环路边。真实、具体、能走进去。

### 地理方案生成（3-5个差异化方案）

从以下维度生成（至少覆盖3个）：

1. **西南城市类：** 成都（玉林路/小酒馆）、昆明（翠湖边）、重庆（解放碑/十八梯）
2. **北方城市类：** 北京（鼓楼/后海/胡同）、石家庄（平淡小城）、东北小镇
3. **旅途空间类：** 火车上、长途汽车、青旅门口、街头歌手的街角
4. **小城/县城类：** 县城十字路口、老家街道、工厂门口、环城路边
5. **情感地标类：** 分手的地方、第一次约会的街角、某个人的家楼下

### 场景时间原则

每个场景必须同时包含：
- **具体时间：** 深夜、黄昏、冬天、夏天路灯刚亮、凌晨4点
- **人物状态：** 失恋后、刚丢工作、旅行中、回老家、刚离开某个人
- **感官细节：** 路灯亮了吗、下雨了吗、有没有人声/车声/吉他声

### 输出格式

```markdown
## 地理场景方案（3-5个）

### 方案1：成都系
**城市：** 成都
**地点：** 玉林路的小酒馆门口
**时间：** 深冬，凌晨12点，路灯还亮着
**状态：** 分手后一个人又回来坐一会儿
**感官细节：** 酒馆里有吉他声传出来，路边有辆自行车倒了没人扶
**可写意象：** 玉林路 / 小酒馆 / 路灯 / 自行车 / 冬天的冷空气

### 方案2：旅途系
**城市：** 移动中（火车/长途汽车）
**地点：** K字头硬座车厢，晚上9点
**状态：** 刚从成都离开，去往下一站，不确定自己在找什么
**感官细节：** 车厢摇晃，窗外黑，偶尔经过一个小镇的灯火
**可写意象：** 火车 / 硬座 / 窗外黑 / 小镇灯火 / 摇晃

### 方案3：北方小城系
**城市：** 石家庄（或北方小城）
**地点：** 老街区的环城路边，早晨6点
**状态：** 刚辞职，在街上走路，天亮了
**感官细节：** 早点摊的蒸汽，公交车来了又走，早起遛狗的人
**可写意象：** 环城路 / 早点摊 / 蒸汽 / 公交车 / 遛狗人
```

## story-bone 执行细则

### 赵雷式故事结构

赵雷的故事不追求戏剧性，追求"一天/一段旅程/一次相遇与离开"的真实感。

**四段叙事：**

1. **开头：一个画面**
   - 一个街道、一个酒馆、一辆公交车、一家小客栈
   - 这个画面要能让人"走进去"

2. **中段：你和另一个人的故事碎片**
   - 不要完整故事，只要碎片
   - 对话、动作、习惯——"我记得你每次都点那杯酒"
   - 赵雷的歌词里，很少有完整的叙事句式，更像照片和快照

3. **后段：我一个人继续走**
   - 告别、错过、成长
   - 不是总结，而是继续

4. **尾声：氛围性句子**
   - 不是升华，而是一幅留白的画
   - "那天晚上风很大，你穿着那件旧外套"

### 叙事原则

- 不写"我爱你我恨你"——写具体的细节
- 不写"我想你"——写"你走了以后烟也不爱点了"
- 不追求意义，追求"就是这样的"

### 输出格式

```markdown
## 故事骨架

**叙事起点（开头画面）：**
玉林路小酒馆门口，冬天，路灯亮着，街上没什么人

**关系设定：**
我和她在这里认识，后来她去了别的城市，我们没有告别

**关系碎片（3-5个细节）：**
- 她每次来都点同一杯酒，说那个味道像老家
- 她抽的烟牌子我后来也学会了
- 她说成都是她待过最舒服的城市
- 最后一次见面她穿的是那件旧外套

**分开/错过时刻：**
她走的那天我在另一个城市赶不回来，后来才知道她把钥匙留在了吧台

**现在的"我"：**
又回到玉林路，坐同一个位置，但老板换人了，她抽的那个牌子也买不到了
```

## lyrics-melody 执行细则

### 语言规则

**必须做到：**
1. **口语感强：** "你说"、"我就"、"其实也没什么"、"那天我"
2. **具体细节：** 不写"思念"，写"你坐过的那张椅子"；不写"心碎"，写"你走了以后烟也不爱点了"
3. **简单比喻：** 最多一个，且要接地气——"你像城里最后一盏不关的灯"

**禁止出现：**
- "灵魂"、"宿命"、"宇宙"、"星辰"、"永恒"
- 网文式矫情句（"那一刻星星都黯然失色"、"时间仿佛静止了"）
- 复杂诗性隐喻（超过一层转折的比喻）
- 感叹号滥用

### 歌词结构建议

```
[Verse1] 讲场景与当下
  - 城市/地点 + 时间/天气 + 动作状态
  - 2-4句，口语感，叙事建立

[Pre-Chorus]（可选）情绪微升
  - 1-2句，从叙述过渡到Hook

[Chorus] Hook（地名+情绪绑定，一听就能哼）
  - 3-4句
  - 核心句：最好包含城市名/地点 + 一个动词/动作

[Verse2] 讲你和"她/他"的故事细节
  - 碎片式，2-4句
  - 对话、动作、习惯——不要完整故事

[Chorus]（情绪略不同，更释然或更淡伤）

[Bridge]（可选）突然清醒或释然
  - 1-2句，赵雷偶尔在Bridge来一句"其实也没什么"

[Outro] 半句或一行，留白
```

### 旋律与节奏

- **拍号：** 4/4
- **速度：** 70–85 bpm，微Swing，适合走路的步频
- **调式：** G大调 / C大调 / D大调 或其关系小调
- **Verse旋律：**
  - 音域：G3–D4（中低音区）
  - 木吉他分解和弦，偶有滑音
  - 叙事感强，不炫技
- **Chorus旋律：**
  - 音域：E4–G4（略抬，但不过分）
  - 好记，能跟着哼
  - 不靠高音爆发，靠语气和留白

### 和弦典型套路

```
Verse系：
  G – Em – C – D（经典走向）
  或：C – G – Am – Em（更温暖）

Chorus系：
  C – G – Am – Em – C – D – G（全套回归）
  或：C – G – Am – Em（简版，重复）

过渡/Pre-C：
  Am – Em – F – G（情绪蓄力）

变体（根据场景）：
  冬天的夜晚 → 用Am系（更冷/更sad）
  早晨/出发 → 用C大调明亮系
  回忆/过去 → 用G大调，吉他轻拨
```

### 歌词+旋律注释格式

```markdown
[Verse1]
玉林路的小酒馆　还亮着灯（G调，4/4，和弦G–Em–C–D）
我还是坐在　那个靠窗的位置（旋律：G3起，走向下行）
只是旁边　空了一个人（"一个人"拖长半拍，留白）

[Pre-Chorus]
其实也没什么　就是有点（和弦Am–Em，旋律微抬F4）
忽然想起你那件　旧外套（情绪蓄力，不冲高音）

[Chorus]
成都的街头　你曾说过（核心Hook：地名+动作绑定）
舍不得的　是那杯酒还是我（和弦C–G–Am–Em，C段）
——（停顿一拍，吉他拨一下）
（Repeat Chorus，旋律略高半key）
```

## arrangement 执行细则

### 配器结构

**核心（必须有的）：**
- 木吉他（Acoustic Guitar）：主导旋律和节奏，分解和弦为主
- 口琴 / 小提琴：点缀，不喧宾夺主，Bridge或Chorus段入场
- 人声：微沙、贴近、少修饰，能听见换气声

**乐队（可选，根据情绪加减）：**
- 贝斯：简单 Root & Fifth，不复杂
- 鼓：Kick + Snare + Hi-hat，简单 Rhythm，不抢人声
- 少量电吉他（Rhythm Chord）：Verse段极轻，Chorus段垫底

**绝对不加：**
- 电子合成器铺底
- 复杂鼓花
- 弦乐大编制
- Auto-Tune/人声美化

### 制作风格

- 人声稍前、乐器不过度压缩
- 能听见手指划弦、呼吸、小瑕疵——保持"真"
- 不修音准到完美，保留Live感
- 木吉他：电容麦收录+Room Mic，营造空间感

### 空间设计

- **Reverb：** Small room + 一点 Hall（模拟小酒馆/排练室）
- **Stereo Width：** 0.7–0.8
- **声像：**
  - 人声：居中
  - 木吉他：偏左（60%）
  - 口琴/小提琴：偏右（70%）
  - 贝斯：居中偏下

### Arrangement分段建议

```markdown
## 编曲分段方案

[Verse1] 木吉他分解和弦，轻；人声进来
[Verse2] 贝斯轻入场；木吉他继续
[Pre-C] 吉他节奏略紧
[Chorus] 口琴/小提琴入场（第一次出现）；鼓轻打底
[Verse3] 乐器稍减，回到吉他+人声
[Chorus] 全乐队，情绪最满
[Bridge] 只有人声+吉他（停顿感）
[Chorus/Outro] 渐出（Fade out），最后只剩吉他一声
```

## truth-filter 执行细则

### 硬规则（触发打回）

**一票否决项：**
1. 歌词出现"灵魂"、"宿命"、"宇宙"、"星辰大海"、"永恒"、"刹那"等大词
2. 歌词出现网文式矫情句（"那一刻星星都黯然失色"、"世界仿佛静止"）
3. 歌词使用复杂诗性隐喻（超过一层转折的比喻）
4. 没有任何地理/地点词（城市名/街/路/店名）
5. 没有任何具体生活物件（椅子/酒瓶/车票/烟/吉他/窗帘）

**警告项（需要调整）：**
- 歌词高词汇密度但生活物件不足 → 判"假文艺"
- 全首歌过于smooth没有"瑕疵感" → 判"太平"
- 情绪直接从淡伤跳到释然，没有过渡 → 判"跳步"

### 必须存在的清单

每首歌必须同时包含以下三类：

| 类型 | 要求 | 示例 |
|------|------|------|
| **地理词** | ≥2个 | 成都、玉林路、小酒馆、鼓楼、环城路 |
| **生活物件** | ≥3个 | 旧外套、烟、酒杯、吉他和弦、自行车 |
| **现实感** | ≥1个 | 没钱、骑车、走路、住地下室、加班到凌晨 |

### 合格判定

- **优秀：** 口语感强 + 地理词+物件+现实感都有 + Chorus好记
- **合格：** 基本口语 + 地理词/物件有两者 + 情绪不跳步
- **不合格：** 大词/矫情句出现 OR 三类中缺两类 → 打回重写

### 输出格式

```markdown
## 真诚度检验报告

**检验项：**
- [✓] 地理词数量：3个（成都、玉林路、小酒馆）
- [✓] 生活物件：4个（旧外套、酒杯、烟、吉他）
- [✓] 现实感：1个（骑车走了很远去找她）
- [✗] 大词检查：发现"永恒" → 必须替换
- [✗] 矫情句检查：发现"那一刻星星都..." → 必须删除
- [✓] 口语感：合格，"其实也没什么"、"我就"

**判定结果：** 打回（2处硬规则违反）
**打回目标：** lyrics-melody
**修改建议：**
  1. 删除"那一刻星星都..."整句，换成她当时的具体动作
  2. 将"永恒"替换为"后来她再也没回来过"这类具体表述
**通过项：** 叙事完整度、口语感、地理密度、生活物件数量
```

## 评分执行细则

由 team-lead 在终稿完成后执行，详见 `references/scoring-rubric.md`。

**评分 <64 的处理：**
1. 附具体维度失分原因
2. 指出是场景/故事/词曲/编曲哪一环的问题
3. 指定回工Agent
4. 最多回工2轮，超出则当前最优版签发
