## 核心三感

1. **地理感** — 城名/街名/小馆子/路口/公交线
2. **流浪感** — 在路上、不安定、既不成功也不失败
3. **真实感** — 歌词像聊天、像旅途日记、像朋友酒桌上讲故事

## 典型题材

- 城市漂泊：北漂/沪漂，在成都、重庆、西安、昆明等城市打工生活
- 旅途心情：火车、长途车、青旅、街头表演
- 旧情与前任：回到一座城市，才发现其实是来告别的
- 普通人青春：不成功、不失败、就这样慢慢长大

## MP3生成

```bash
node scripts/tts-sing.js \
  --lyrics D:/path/to/歌词文件.md \
  --tempo 78 \
  --key "G major" \
  --voice male-shaonian \
  --output D:/Downloads/赵雷_demo.mp3
```

## 评分标准

8维评分（每项0–10分，满分80分）：
- 地理真实度 / 生活细节浓度 / 叙事完整度
- 口语自然度 / 旋律哼唱度 / 编曲真实度
- 情绪温度 / 共鸣广度

**≥72分：通过签发**
**64–71分：小修后签发**
**<64分：重写**
