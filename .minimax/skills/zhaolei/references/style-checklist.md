# 赵雷风格质感核对表

本文件供 truth-filter 在终检时逐项核对，每首歌必须通过全部核验点方能签发。

---

## 一、地理真实性（必须全部通过）

- [ ] 全文有≥2个具体城市/街区名称（"成都"/"玉林路"优于"城市"/"街道"）
- [ ] 有≥1个具体场所（小酒馆/客栈/环城路/十字路口/青旅）
- [ ] 地理词出现在Verse和Chorus中（全文均匀分布，非只在开头）
- [ ] 地理词不是抽象化使用（"城市"单独出现无上下文 → 不算数）

---

## 二、口语自然度（必须全部通过）

- [ ] 全文口语连接词≥2个（嘛/就/啊/哦/还/也/都/得/dei）
- [ ] 至少1处直接引语（"你说"/"她说"/"我说"）
- [ ] 至少1处"其实也没什么"/"就是有点"类缓冲句
- [ ] 无明显朗诵腔（把歌词念一遍，没有拗口/不自然的停顿）
- [ ] 句式长短有变化（不全是一样的8字句）

---

## 三、生活物件（必须全部通过）

- [ ] 有≥3个具体生活物件（烟/酒/吉他和弦/车票/钥匙/旧外套/自行车/泡面/地下室）
- [ ] 至少1个物件有情感绑定（"你走后烟也不爱点了"而非"我抽着烟"）
- [ ] 物件出现符合叙事逻辑（不是随机堆砌）

---

## 四、真诚感与现实感（必须全部通过）

- [ ] 全文无"灵魂"/"宿命"/"永恒"/"宇宙"/"星辰"等大词
- [ ] 全文无网文矫情句（"那一刻星星都..."/"世界仿佛静止"）
- [ ] 无复杂诗性隐喻（超过一层转折的比喻）
- [ ] 至少1处"穷"/"窘迫"/"骑车"/"走路"/"地下室"/"加班"类现实感
- [ ] 全文感叹号（!）不超过2个（赵雷克制，不宣告）

---

## 五、情绪温度（必须全部通过）

- [ ] 情绪在赵雷光谱内（淡伤/怀旧/释然/少年气），无崩溃大哭/鸡汤/愤怒质问
- [ ] 情绪过渡自然（Verse→Chorus→Verse有递进或转变，无跳步）
- [ ] Chorus不以高音爆发作为情绪出口
- [ ] 无"我要为你..."式宣告（赵雷是"我就是这样"，不是"我为你..."）

---

## 六、叙事结构（必须全部通过）

- [ ] 有开头画面（一个街/路/酒馆/公交的定格镜头）
- [ ] 有关系碎片（2–3个细节/动作/对话，而非完整故事）
- [ ] 有分开/错过的时刻（不一定是高潮，但有）
- [ ] 有"现在的我"（不只是回顾，还有此刻的状态）

---

## 七、Chorus Hook（必须全部通过）

- [ ] Hook包含地名/地点词（或情感绑定极强的动作词）
- [ ] Hook能一听就哼（音域不超过4度，节奏简单）
- [ ] Hook不超过9个字（"和我在成都的街头走一走"=8字+语气词=刚好）
- [ ] Hook不靠高音，情感靠语气和留白

---

## 八、编曲质感（必须全部通过）

- [ ] 木吉他主导（>50%编曲权重）
- [ ] 无电子合成器/EDM底色
- [ ] 无大编制弦乐（偶尔点缀可以，不能主导）
- [ ] 无Auto-Tune/人声美化
- [ ] 有至少1次口琴/小提琴点缀

---

## 九、旋律与和弦（建议通过）

- [ ] Verse音域 G3–D4（胸声区，不跳到头声）
- [ ] Chorus音域 E4–G4（不过分高音，靠语气而非高音撑情绪）
- [ ] 和弦进行是G–Em–C–D系或C–G–Am–Em系（经典民谣进行）
- [ ] 每首歌有至少1个Gmaj7/Em7点缀和弦（不用也可以，但用了加分）

---

## 十、共鸣广度（建议通过）

- [ ] 歌词足够具体，让人"能走进去"（不是"我很难过"而是具体的难受）
- [ ] 同时足够普遍，不是纯私人日记（普通人听了能代入）
- [ ] 有没有一句让人想说"我也是"的句子？

---

## 快速通过标准

**如果以下5项全部通过，其他项可酌情放宽：**
1. [ ] 地理词≥5个
2. [ ] 生活物件≥3个
3. [ ] 无大词/矫情句
4. [ ] 口语感强
5. [ ] Chorus Hook明确且好记

**如果以下任意1项触发，直接打回重写：**
1. [ ] 出现"灵魂"/"宿命"/"永恒"/"宇宙"
2. [ ] 出现"那一刻星星都..."类矫情句
3. [ ] 完全没有地理词
4. [ ] 完全没有生活物件
5. [ ] 情绪崩溃大哭或大灌鸡汤
