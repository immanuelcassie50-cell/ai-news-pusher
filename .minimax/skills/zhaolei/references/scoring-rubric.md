# 赵雷歌曲8维量化评分细则

## 评分标准总览

每首歌按8个维度评分，每项0–10分，**满分80分**。

| 评分区间 | 决策 |
|---------|------|
| ≥72分（≥9分/维度均分） | **通过签发** |
| 64–71分 | **小修后签发**（指出具体维度问题） |
| <64分 | **重写**（指定回工Agent和具体维度） |

---

## 维度1：地理真实度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | 城市/街/店/路口/交通工具齐全（≥5个地理词），每个都能"走进去" |
| 7–8 | 有3–4个地理词，主要城市/地点明确，能产生空间感 |
| 5–6 | 有1–2个地理词，较为模糊，空间感弱 |
| 3–4 | 有地理词但不具体（"城市"而非"玉林路"），缺乏可感性 |
| 0–2 | 几乎没有地理词，或全部抽象化（"远方"/"流浪"无具体地名） |

### 检验方法
- 逐句标出地理词（城市/街/路/店名/交通工具/路口）
- 统计数量和层次（城市→街区→场所三级最好都有）

### 失分原因（常见）
- 只有"成都"没有街道/店名 → 最多给5分
- "我在远方"代替具体地点 → 直接≤3分
- 地理词有但不可感（"我经过那个地方"无具体坐标） → 扣1–2分

---

## 维度2：生活细节浓度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | ≥4个具体生活物件（烟/酒/吉他和弦/车票/钥匙/旧外套/自行车等），每个物件都与情感绑定 |
| 7–8 | 3个物件，物件有情感意义但未完全展开 |
| 5–6 | 2个物件，或物件有但与情感关系弱 |
| 3–4 | 有物件但太泛（"我喝了一杯酒"无细节），或物件与情感无关 |
| 0–2 | 无具体物件，全是抽象情感词 |

### 检验方法
- 逐句标出生活物件名词
- 判断每个物件是否承载了情感（"烟也不爱点了"=情感绑定，"喝着酒"=无绑定）

### 失分原因（常见）
- "我在喝酒"无细节 → 不给分
- "那件旧外套"反复出现但无情感绑定 → 降1级
- 只有情感词无物件 → ≤4分

---

## 维度3：叙事完整度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | 有完整的四段叙事：①开头画面 ②关系碎片 ③分开/错过 ④现在的我；情绪过渡自然 |
| 7–8 | 有叙事线但不完整（缺1–2段），或过渡有跳步 |
| 5–6 | 有叙事感但碎片化，缺少"分开/离开"的时刻 |
| 3–4 | 大量碎片但串不起故事，或情绪直接跳到总结 |
| 0–2 | 无叙事感，只有情感词汇的堆砌 |

### 检验方法
- 按workflow-detail中的四段叙事结构检验
- 情绪过渡是否自然（不能从"沉默"直接跳到"释然"）

---

## 维度4：口语自然度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | 整首歌念出来通顺，口语连接词（嘛/就/啊/还）自然，句式长短有变化，无朗诵腔 |
| 7–8 | 大部分口语化，有少量"歌词腔"但不影响整体感 |
| 5–6 | 部分口语，但有2–3处明显"写出来的句子"（非自然说话） |
| 3–4 | 多处朗诵腔，口语词极少，句式过于工整 |
| 0–2 | 大量朗诵腔，大量感叹号式情感宣告，完全不像说话 |

### 口语检测三问
1. 把歌词念一遍，有没有拗口的地方？→ 有→扣分
2. 有没有"其实也没什么"这类口语缓冲句？→ 没有→扣分
3. 有没有直接引语（"你说"/"我就"）？→ 没有→扣分

---

## 维度5：旋律哼唱度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | Chorus Hook听一遍就能哼，音域不超过4度，节奏简单好记 |
| 7–8 | Chorus有Hook但不够上口，Verse旋律叙事感强但不好跟唱 |
| 5–6 | 有旋律但不好跟唱，Hook模糊，音域有跳跃 |
| 3–4 | 旋律过于平淡无起伏，或过于复杂不适合民谣传唱 |
| 0–2 | 整首歌无明显旋律线，像在念东西 |

### 哼唱度快速检测
- 把Chorus部分唱出来（内心默唱），是否自然？
- 有没有一个"记忆点"（重复的一句或一个音）？
- 音域是否在E4–G4范围内（不靠高音）？

---

## 维度6：编曲真实度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | 木吉他主导+口琴/小提琴点缀，能听见呼吸/手指划弦，有排练室/Live质感 |
| 7–8 | 有木吉他主导，整体真实，有Live感但部分处理过于"干净" |
| 5–6 | 木吉他为主但音色不够真实，或加了过多编曲元素 |
| 3–4 | 弦乐/电音过多，失去了民谣感 |
| 0–2 | 完全EDM/流行制作，木吉他只是点缀，真实感为零 |

### 检验方法
- 检查配器表：木吉他是否主导？
- 检查是否有不该出现的元素（合成器/电子鼓/大编制弦乐）
- 检查声场设计：是否有"能听见手指"的真实感？

---

## 维度7：情绪温度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | 淡伤+怀旧+释然+少年气均有，温暖但克制，无狗血无鸡汤，温度刚刚好 |
| 7–8 | 情绪基本在赵雷光谱内，但有轻微偏差（略甜或略冷） |
| 5–6 | 情绪基本对，但有1处明显越界（突然大爆发或突然灌鸡汤） |
| 3–4 | 情绪越界明显（苦情/愤怒/过度煽情） |
| 0–2 | 完全不在赵雷情绪光谱内（要么太甜太正能量，要么太崩溃） |

### 情绪越界红线
- 出现"我要为你..."（宣告式大爱）→ 直接≤4分
- 出现"我们会更好"（鸡汤式正能量）→ 直接≤5分
- 出现"为什么你要离开我"（愤怒质问）→ 直接≤4分
- 出现"我的心碎成渣"（崩溃式苦情）→ 直接≤3分

---

## 维度8：共鸣广度（0–10分）

### 评分标准

| 分数 | 标准 |
|------|------|
| 9–10 | 歌词足够具体（个人化）但情感足够普遍，"在不同城市漂着的人"都能代入 |
| 7–8 | 个人化细节和普遍情感较好平衡 |
| 5–6 | 过于个人化（只有创作者自己能懂），或过于泛化（没有个人质感） |
| 3–4 | 过于泛化成为套话，或过于私密成为日记 |
| 0–2 | 完全是小众日记或完全套话，无共鸣感 |

### 检验方法
- 把歌词给一个"没经历过类似场景"的人看，他/她能感受到情感吗？
- 是否有哪一句让人想说"我也是"？

## 回工决策矩阵

| 最低分维度 | 回工目标 | 修改要求 |
|-----------|---------|---------|
| 地理真实度 < 6 | geo-scene + lyrics-melody | 增加具体地点词，重写Verse |
| 生活细节浓度 < 6 | lyrics-melody | 加入≥3个生活物件 |
| 叙事完整度 < 6 | story-bone + lyrics-melody | 补全四段叙事，情绪过渡自然化 |
| 口语自然度 < 6 | lyrics-melody | 重写不自然的句子，加口语缓冲 |
| 旋律哼唱度 < 6 | lyrics-melody | 简化Chorus旋律，降低音域 |
| 编曲真实度 < 6 | arrangement | 减少非必要乐器，回到木吉他主导 |
| 情绪温度越界 | truth-filter + lyrics-melody | 删除越界句，重写该段 |
| 共鸣广度 < 6 | lyrics-melody + story-bone | 调整个人化/普遍化比例 |
