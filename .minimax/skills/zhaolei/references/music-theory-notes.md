# 赵雷调式/和弦/步频技法

## 一、调式选择

### 主调：G大调 / C大调

赵雷歌曲80%以上使用G大调或C大调，偶用D大调或关系小调。

| 调式 | 适合情绪 | 适用场景 | 代表歌曲 |
|------|---------|---------|---------|
| G大调 | 温暖、怀旧、释然 | 整体明亮有回忆感 | 《成都》《朵儿》 |
| C大调 | 干净、叙述、清晨感 | 更口语化、说故事 | 《未给递递结果》《理想》 |
| D大调 | 明亮、出发、路上 | 有旅途感、不安定 | 《再也不去丽江》 |
| Em小调 | 冷、暗、冬天感 | 情绪低谷、分开 | 《三十岁的女人》片段 |
| Am小调 | 冷+克制 | 更深沉、更个人 | 《无法长大》片段 |

### 调式转换规则

**Verse→Chorus转调：**
- 赵雷通常不在Verse和Chorus之间转调（和唐恬/钱雷不同）
- 靠和弦色彩变化制造情绪起伏，而非调性转换
- 如果情绪需要微抬：G大调Verse → G大调的V级（C）更常用

**关系小调穿插：**
- 主调G大调中，穿插Em（关系小调）→ 增加"冷"的层次
- 示例：《成都》主调G，穿插Bm（虽然标G但色彩偏暗）

## 二、和弦体系

### 核心和弦进行（赵雷三大套路）

**套路1：G–Em–C–D（最经典）**
```
适用：Verse叙事段 + Chorus回归
色彩：温暖底色+淡淡忧伤
代表：《成都》《少年锦时》
```

**套路2：C–G–Am–Em（更口语化）**
```
适用：更干净的叙事感（无G调的Em偏暗）
色彩：明亮、干净、说故事感
代表：《理想》《未给递递结果》
```

**套路3：C–Am–F–G（北方/冬天/冷调）**
```
适用：冬天场景、更克制
色彩：冷中有暖，矛盾感
代表：《三十岁的女人》
```

### 各级和弦情感色彩

以G大调为例：

| 和弦 | 色彩 | 适用情绪 |
|------|------|---------|
| G | 根音，稳定感 | 叙事起点 |
| Am | 冷、想起、怀旧 | 情绪微沉 |
| Bm | 暗、更深沉的怀旧 | 冬天/分开 |
| C | 明亮、转折、出发 | Chorus起点 |
| D | 属音，不稳定，蓄力 | 情绪蓄力 |
| Em | 温柔、脆弱、回忆 | 温柔时刻 |
| F | 挣扎、矛盾 | 情绪纠结 |

### 进阶和弦（点缀用）

| 和弦 | 色彩 | 用法 | 出现位置 |
|------|------|------|---------|
| Gmaj7 | 温暖、留白 | 吉他独奏段/Outro | Verse结尾/Outro |
| Cmaj9 | 干净、口语 | Pre-C蓄力 | Pre-C段 |
| Em7 | 更温柔 | 情绪柔软的Verse句 | Verse句中 |
| D/F# | 属转斜杠，蓄力感 | 从D过渡 | D→G的过渡 |
| Asus2 | 不安定、疑问 | Bridge或问句后 | Bridge |

**原则：** 赵雷几乎不用7/9/11等高叠和弦，主要用三和弦+挂留，偶尔Gmaj7点缀。

## 三、节拍与BPM

### 核心速度：70–85 bpm

这是走路最舒服的速度区间，也是赵雷歌曲的核心律动。

| BPM | 适用场景 | 风格 |
|-----|---------|------|
| 70–75 | 冬天、深夜、安静、情绪低谷 | 冷调、叙事 |
| 76–80 | 通用标准，赵雷最常用 | 平衡 |
| 81–85 | 稍明快、有出发感 | 旅途、离开 |

### 微Swing节奏

赵雷的木吉他节奏型多带**微Swing**（32分音符三连音感），让人感觉"在走路"而不是"在打拍子"。

```
非Swing（死板）：| ♩  ♩  ♩  ♩ |
Swing（走路感）：| ♩♭  ♩♭  ♩♭  ♩♭ |
```

### 4/4拍的常见节奏型

**分解和弦型（Verse用）：**
```
右手：1–2–3–m–a–2–3–m
      G  C  G  Em G  C  G  G
（每小节一组分解，稳定叙事）
```

**扫弦型（Chorus用）：**
```
右手：下 下 下 下 下 下 下 下
      G  C  G  D  G  C  G  D
（强拍在后半拍，有推进感）
```

**慢扫弦（Pre-C用）：**
```
右手：下─── 下─── 上 下 上
      G    C    G  D  G
（蓄力感，不急不慢）
```

## 四、音域设计

### 赵雷的音域特点

**整体偏低**，不追求高音爆发：
- Verse：G3–D4（胸声为主）
- Pre-C：E4（接近换声点）
- Chorus：E4–G4（到G4已经是情绪高点）
- **从不用A4及以上的持续高音**（那是钱雷的领域）

### 旋律线条类型

**类型1：平行叙事型（Verse用）**
```
G3 ─────────── E3
C4 ─── D4 ────
整句在一个音域区间内小幅波动，像说话
```

**类型2：上行蓄力型（Pre-C用）**
```
G3 ────────── E4
在句尾上行半音或跳到属音，蓄力不释放
```

**类型3：回落回归型（Chorus用）**
```
D4 ─── E4 ── G4 ── D4
冲高后迅速回落，不在高点停留太久
```

**类型4：留白终止型（Outro用）**
```
停在G4或E4，不解决到主音
让吉他填补最后的解决
```

## 五、吉他与人声的配合

### 吉他填补词曲留白

赵雷的吉他不是"伴奏"，而是歌曲的**第四句**：
- 人声唱完一句，吉他接半句/一个音
- 句尾下滑时，吉他同时下滑
- 停顿处（空拍），吉他弹一句旋律填补

### 具体操作

```
[Verse段]
人声："成都的街头" ──── 吉他：接一个G音
人声："走一走" ─────── 吉他：Em分解填补
[空拍] ─────────────── 吉他：一句C音填补

[Chorus段]
人声：全句跟上 ─────── 吉他：扫弦垫底
人声停顿 ────────────── 吉他：一句旋律solo（4–8音）
```

## 六、速度变化的场景适配

| 场景 | BPM建议 | 吉他节奏 | 和弦色彩 |
|------|---------|---------|---------|
| 冬天深夜/分手 | 70–74 | 分解极慢 | Am系/Bm暗调 |
| 骑车/走在街上 | 76–80 | 分解+扫弦混合 | G–Em–C–D经典 |
| 回忆/想起过去 | 72–76 | 分解慢 | Gmaj7点缀 |
| 出发/离开 | 80–85 | 扫弦推进 | C大调明亮系 |
| 民谣口琴Solo段 | 70–74 | 无弦乐，只有吉他solo | 极简 |
