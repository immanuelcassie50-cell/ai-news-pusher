# 赵雷歌曲质量自检10项

本清单供 team-lead 在签发前做最终快速验收，通过全部10项方可交付用户。

---

## 签发前必须通过的10项检查

### 第1项：地理密度检查
**一句话检测：** "如果有人拿着歌词，能按图索骥走到那个地方吗？"
- [ ] 全文有≥2个城市/街区名
- [ ] 有≥1个具体场所（店/路/路口）
- [ ] 地理词不在只在Verse，Chorus的Hook也含地名
- **失败标志：** 全文只有"城市"/"远方"/"街头"等模糊词

---

### 第2项：物件情感绑定检查
**一句话检测：** "这个物件能不能换成别的？换掉之后情感有没有损失？"
- [ ] 有≥3个具体物件
- [ ] 每个物件有情感绑定（换掉情感就消失）
- **失败标志：** "我喝了一杯酒"（物件无绑定，换成水也一样）

---

### 第3项：口语流畅度检查
**一句话检测：** "这段歌词唱出来的节奏，和说话节奏一样吗？"
- [ ] 念一遍，没有拗口的停顿
- [ ] 有口语连接词（嘛/就/啊/哦）
- [ ] 有直接引语（你说/她说）
- **失败标志：** 读出来像朗诵，有书面语腔

---

### 第4项：无大词检查
**一句话检测：** "这段歌词小学生能看懂吗？"
- [ ] 无"灵魂/宿命/宇宙/永恒/星辰"
- [ ] 无"那一刻世界都..."
- [ ] 无复杂诗性隐喻
- **失败标志：** 出现任何一个高难度词汇

---

### 第5项：情绪温度检查
**一句话检测：** "如果唱给朋友听，他会不会觉得我在表演崩溃/正能量？"
- [ ] 情绪克制，淡淡伤/怀旧/释然
- [ ] 无崩溃大哭/愤怒质问/鸡汤式总结
- [ ] 感叹号≤2个
- **失败标志：** 情绪越界（崩溃或鸡汤）

---

### 第6项：Chorus Hook检测
**一句话检测：** "去掉旋律，念一遍这句，能记住吗？"
- [ ] Hook≤9字（或9字+语气词）
- [ ] 含地名或情感绑定动作词
- [ ] 音域不超过4度，好跟唱
- **失败标志：** Hook太长/无记忆点/靠高音撑

---

### 第7项：叙事完整性检测
**一句话检测：** "这首歌有没有一个'分开'的时刻？"
- [ ] 有开头画面（定格镜头）
- [ ] 有关系碎片（不是完整故事，是快照）
- [ ] 有分开/错过的时刻
- [ ] 有"现在的我"（不是只回顾，还有此刻）
- **失败标志：** 只有回顾，没有此刻；或只有情绪没有故事

---

### 第8项：编曲真实感检测
**一句话检测：** "如果我闭上眼睛，能想象到这是一个人在小酒馆唱歌吗？"
- [ ] 木吉他主导
- [ ] 无电子/合成器/EDM底色
- [ ] 无大编制弦乐（点缀可以）
- [ ] 有口琴/小提琴点缀
- **失败标志：** 听起来像流行歌不像民谣

---

### 第9项：旋律行走感检测
**一句话检测：** "这个旋律踩着节拍走路，舒服吗？"
- [ ] Verse旋律有叙事感，像走路时说话
- [ ] Chorus旋律比Verse略抬，但不过分
- [ ] Chorus靠语气/留白/动作词撑情绪，不靠高音爆发
- [ ] BPM在70–85之间
- **失败标志：** Verse像念经，或Chorus高音爆

---

### 第10项：共鸣广度检测
**一句话检测：** "这首歌的情感，是只有创作者自己能懂，还是很多人都有过？"
- [ ] 有至少一句让人想说"我也是"的句子
- [ ] 足够具体（不是套话）
- [ ] 足够普遍（不是纯私密日记）
- **失败标志：** 只有创作者自己能懂的私密细节堆砌，或完全无个人质感的套话

---

## 快速通过标准

**10项全部通过 → 立即签发交付**

**10项中任意1项硬失败（一票否决项）→ 打回对应Agent重写：**
- 第1项失败 → geo-scene（重新设计地理场景）
- 第2项失败 → lyrics-melody（加入生活物件）
- 第3项失败 → lyrics-melody（重写不自然的句子）
- 第4项失败 → lyrics-melody（删除大词）
- 第5项失败 → truth-filter + lyrics-melody（修正情绪温度）
- 第6项失败 → lyrics-melody（重写Hook）
- 第7项失败 → story-bone + lyrics-melody（补全叙事线）
- 第8项失败 → arrangement（修正编曲方案）
- 第9项失败 → lyrics-melody（调整音域和BPM）
- 第10项失败 → lyrics-melody + story-bone（调整个人/普遍比例）

---

## 附加建议（非必须通过，但加分）

- [ ] Outro有留白感（不是鸡汤总结，而是戛然而止）
- [ ] Pre-C有情绪蓄力段（不是Verse→Chorus直跳）
- [ ] Bridge有"突然清醒/释然"的转变
- [ ] 有Gmaj7/Em7点缀和弦（加分项，不是必须）
