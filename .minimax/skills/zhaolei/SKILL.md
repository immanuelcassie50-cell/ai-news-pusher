# 赵雷 词曲全能创作系统（RPD融合版 v1.0）

本技能通过6角色团队协作，生成具备**赵雷式地理民谣**与**普通人命运叙事**的完整歌曲，并输出MP3试听文件。

**核心理念：** 歌不是写出来的，是一个人在城市边缘走路时，从心里走出来的。核心三感——**地理感（城名/街名/小馆子）、流浪感（在路上/不安定）、真实感（像聊天/像旅途日记）**。

---

## 团队成员

| Agent | 角色 | 核心职责 |
|-------|------|---------|
| `geo-scene` | 场景与地理采集师 | 把模糊主题变成"可写城写路"的具体场景 |
| `story-bone` | 故事骨架设计师 | 构建"一天/一段旅程/一次相遇与离开"的叙事线 |
| `lyrics-melody` | 词曲共构引擎 | 赵雷式口语歌词 + 步频旋律 + G/C调木吉他和弦 |
| `arrangement` | 编曲与声场设计师 | 木吉他主导+小乐队，Live/排练室质感 |
| `truth-filter` | 真诚度与"装文艺"过滤器 | 过滤假民谣，确保地理词+生活物件+现实感 |
| `team-lead`（主控） | 协调 + 终稿聚合 | 监控流程，聚合交付物，生成创作手记 |

---

## 执行流程

```
用户输入主题（如"一个人在成都的夜里走"）
    ↓
[geo-scene] 生成城市/地点/时间/状态方案（3-5个）
    ↓（用户确认）
[story-bone] 构建叙事线：开头画面→关系碎片→分开时刻→现在的我
    ↓
[lyrics-melody] 词曲共构（歌词+旋律注释+和弦 G–Em–C–D 系）
    ↓
[arrangement] 编曲与声场设计（木吉他+口琴/小提琴+贝斯+鼓）
    ↓
[truth-filter] 赵雷式真诚检验（禁止大词/网文矫情/复杂诗性隐喻）
    ↓
[team-lead] 聚合终稿 + 创作手记 + 评分卡
    ↓
交付：歌词（含旋律注释）.md + MP3文件
```

## 用户输入 / 产出格式

**用户提供（三选一）：**
- A. 模糊主题（如"一个人在城市边缘走着"、"北漂的日子"）→ geo-scene 自动发散
- B. 具体城市/地点（如"成都玉林路"、"鼓楼十字路口"）→ 直接进入故事骨架设计
- C. 指定情绪类型 → 适配调式与曲风

**Claude产出：**
1. 完整歌词（含旋律走向注释、和弦、调式建议）
2. MP3试听文件（via MiniMax TTS）
3. 创作手记（≤500字）
4. 8维评分卡

## 输出格式模板

```markdown
## 《标题》

**调式：** G 大调 / C 大调 / **节拍：** 4/4 / **BPM：** 70–85
**叙事弧线：** 开头画面 → 关系碎片 → 分开时刻 → 现在的我
**核心和弦：** G – Em – C – D（或 C – G – Am – Em 系）
**配器：** 木吉他 + 口琴/小提琴 + 贝斯 + 鼓（简约）

---

[Verse1]
歌词歌词（建议：地名+动作，口语感强）
旋律：音域 G3–D4，木吉他分解和弦
和弦：G – Em – C – D
情绪：淡伤、叙事建立

[Pre-Chorus]（可选）
歌词歌词（情绪微升）
旋律：略抬 E4
和弦：C – G – Am

[Chorus]
核心Hook句（绑定地名/情绪，一听就能哼）
旋律：音域 E4–G4，不过分高音
和弦：C – G – Am – Em – C – D – G
情绪：淡淡的怀旧和释然

[Verse2]
歌词歌词（关系/相遇/分开细节）
旋律：同Verse1，略有变化
和弦：G – Em – C – D

[Chorus]（情绪略不同）
...

[Outro]
一行或半句，留白
（注：G大调，吉他轻拨，呼吸感）

---

## 创作手记
（≤500字，说明地理感/流浪感/真实感如何实现）

## 8维评分卡
| 维度 | 得分 | 说明 |
|------|------|------|
| 地理真实度 | X/10 | 地点与场景是否"能走进去" |
| 生活细节浓度 | X/10 | 有多少真实物件与小事 |
| 叙事完整度 | X/10 | 能否串起一个"遇见到离开"的小故事 |
| 口语自然度 | X/10 | 唱出来像说话，而不是朗诵 |
| 旋律哼唱度 | X/10 | Chorus 是否一听就能哼 |
| 编曲真实度 | X/10 | 是否像真实排练场 / Live |
| 情绪温度 | X/10 | 淡淡伤、有一点暖、不狗血 |
| 共鸣广度 | X/10 | 是否让"在不同城市漂着的人"感觉是写给自己的歌 |
| **总分** | **XX/80** | ≥72通过；64–71小修；<64重写 |
```

## 协作规则

1. **用户介入点：** geo-scene 输出后必须等用户确认城市/地点
2. **回工机制：** truth-filter 评分<64时自动触发回工，附具体原因
3. **安全闸门：** 若歌词出现"灵魂"/"宿命"/"宇宙"/复杂诗性隐喻 → truth-filter 强制打回
4. **迭代上限：** 评分重修最多2轮，超出则以当前最优版签发并标注风险

## Team模式约定

本技能默认开启Team模式。team-lead 在每阶段完成后主动报告进度（SendMessage to "team-lead"），超时3分钟无消息则主控主动询问，超时5分钟则TaskStop并接管。

## 不适用场景

- **已有完整歌词，只需配乐/作曲：** 请使用单独的音乐制作类skill
- **纯欢乐/爆发类歌曲：** 请使用唐恬×钱雷系统
- **纯智性讽喻/冷幽默歌曲：** 请使用林振强×施立系统
- **都市情感/优雅心碎类：** 请使用陈辉阳×林夕系统
- **仅需分析现有歌曲的创作技法：** 请使用歌词/作曲分析类skill
