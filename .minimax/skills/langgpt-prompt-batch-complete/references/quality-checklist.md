# 质量检查清单（精要版）

> 完整版见原版 skill：`langgpt提示词大师/references/quality-checklist.md`

---

## 五维质量评分

| 维度 | 权重 | 核心问题 |
|------|------|----------|
| 精准度 | 25% | 需求理解准确吗？ |
| 完整度 | 25% | 九大模块完整吗？ |
| 可执行度 | 25% | 可直接使用吗？ |
| 专业度 | 15% | 注入专业术语了吗？ |
| 启发度 | 10% | 示例丰富吗？ |

**通过标准：综合分 ≥ 70 且 error数 = 0**

---

## 必检项目（逐文件）

### 1. YAML frontmatter ✅
- [ ] 有 `---` 开头和结尾
- [ ] `name` 有意义（不是 "my-prompt"）
- [ ] `description` 有触发力（包含动词+场景+边界）

### 2. 模块完整性 ✅
- [ ] Role（角色定义）— 必填
- [ ] Background（背景说明）— 推荐
- [ ] Profile（能力档案）— 必填
- [ ] Skills（核心技能）— 必填
- [ ] Rules（行为准则）— 推荐
- [ ] Workflow（工作流程）— 必填
- [ ] Goals（目标设定）— 推荐
- [ ] Knowledge Base（知识储备）— 可选
- [ ] Initialization（初始化）— 推荐

### 3. 占位符扫描 ✅
- [ ] 无 `[xxx]` 形式的未填充占位符
- [ ] 无 "示例示例" 类空内容

### 4. 模糊表述扫描 ✅
- [ ] 无 "可能"、"也许"、"大概"
- [ ] 无 "视情况而定"
- [ ] 无 "差不多"、"基本上"

### 5. Skills模块 ✅
- [ ] 有至少2个具体Skill
- [ ] 每个Skill有：名称+描述+应用场景+执行方式
- [ ] Skills之间有逻辑关系

### 6. Workflow模块 ✅
- [ ] 有至少2个阶段
- [ ] 每个阶段有目标
- [ ] 每个阶段有具体步骤

### 7. Examples模块 ✅
- [ ] 有至少2个完整示例
- [ ] 每个示例有：用户输入 + AI输出

### 8. 字数范围 ✅
- [ ] 目标：2000-5000字
- [ ] 下限：1500字（低于此报错）
- [ ] 上限参考，不强制

### 9. 序号合理性 ✅
- [ ] 序号接续现有最大序号
- [ ] 无跳跃（如03→05跳过04）
- [ ] 无冲突（不覆盖已有文件）

---

## 评分速算

```
完整度分 = 100 - (缺失模块数 × 15)
可执行度分 = 100 - (error数 × 10) - (warning数 × 3)
综合分 = 完整度分 × 40% + 可执行度分 × 60%
```

## 自检问答

```
□ Role能在2秒内说清楚这个AI是做什么的吗？
□ 每个Skill都有"执行方式"吗？（不只是标题）
□ 有人会说"这个我早知道了"的内容吗？
□ 有没有"示例示例"类的空内容？
□ frontmatter的description能让人知道什么时候用吗？
□ 用户说"不满意"，我知道Prompt会怎么处理吗？
```

**有任何问题为"否" → 回到对应模块修正**
