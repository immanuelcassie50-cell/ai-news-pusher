# 路径与语言规则

## 文件生成路径

所有生成的文件（代码、文档、配置、Skill等）：
- **默认路径**: `D:\Downloads\xinjian`
- **临时文件**: `D:\CC\temp`

## 文件命名

- **文件**: 英文，camelCase/kebab-case
- **文件夹**: 简体中文，简洁明了

## 多文件生成

- 1个文件 → 直接放 `D:\Downloads\xinjian\`
- 多个文件 → 创建子文件夹如 `D:\Downloads\xinjian\新功能\`

## 语言优先级

1. **前端界面**: frontend-slides > distinctive-frontend > frontend-design
2. **Office 文档**: 读取 skill 包内的 SKILL.md，不询问用户
