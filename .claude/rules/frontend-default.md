# 前端输出规范

## 默认风格（信息图、海报、PPT类）

### 配色
浅色背景 + 深色头部/主题条 + 模块网格 + 侧边栏

### 信息完整
- 目标受众
- 差异化定位
- 配套产出
- 模块导览

### 排版
紧凑，充分利用空间，去掉大面积留白

### 打印输出
白底无阴影，Ctrl+P 可直接打印

---

## 流程

1. **先找参考**：搜索 `D:\Downloads` 下的 `.html` 示例
2. **确认规格**：询问纸张规格或默认横向A3
3. **打印优化**：添加 `@page { size: A3 landscape }` + `@media print`
