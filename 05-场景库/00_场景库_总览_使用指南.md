# 课7【组织统筹能力】场景库（按行业分版本）

> **设计目的**：让管理者和知识工作者"穿上"一个具体行业角色的工牌，进入真实工作场景，体验"人 vs 人+智能体"的统筹协作差异，学会判断何时引入智能体、如何建立人机信任。
>
> **不是案例库，是演练剧本**。每个场景都可以直接做小组演练、角色扮演、决策推演。

---

## 二、为什么"按行业分版本"而不是"按统筹方法分版本"

| 维度 | 按行业分版本（当前选择） | 按方法分版本（备选） |
|------|----------------------|------------------|
| 学员代入感 | ✅ 强（"我就是这个岗位"） | ⚠️ 弱（抽象方法） |
| 跨行业迁移 | ⚠️ 学员需识别共性 | ✅ 方法框架可移植 |
| 课程节奏 | ✅ 可作为小组任务书 | ⚠️ 易变成纯讲知识 |
| 真实决策感 | ✅ 行业细节带出判断 | ⚠️ 容易纸上谈兵 |

**取舍**：本课程已经有按方法组织的教学文档，场景库作为配套，**主要价值在"让统筹方法落到具体岗位"**。所以选择按行业分版本。

跨行业共性沉淀在 [`01_场景设计公式.md`](01_场景设计公式.md) 和 [`02_讲师使用手册.md`](02_讲师使用手册.md) 里。

## 三、每个场景的"标准结构"

所有场景遵循统一结构，**讲师和学员拿到任一场景都知道怎么用**：

```
┌────────────────────────────────────────────────┐
│ 🎭 角色卡                                        │
│   姓名 / 岗位 / 公司背景 / 教学对象 / 性格特征    │
├────────────────────────────────────────────────┤
│ 📋 背景任务                                      │
│   今天这个角色要完成什么具体统筹任务              │
├────────────────────────────────────────────────┤
│ 🛑 关键节点                                      │
│   统筹决策停在哪一步、人机协作卡在哪一环          │
├────────────────────────────────────────────────┤
│ 💭 留白提问                                      │
│   个人思考的开放问题（不讲给学员听，写给学员看）  │
├────────────────────────────────────────────────┤
│ 🤝 互动流程（个人→两人→全班）                    │
│   90 秒独立想 → 3 分钟两人对谈 → 8 分钟全班讨论  │
├────────────────────────────────────────────────┤
│ 🎯 四层提问清单                                  │
│   事实层 → 感受层 → 原则层 → 行动层              │
├────────────────────────────────────────────────┤
│ 💡 可迁移原则                                    │
│   一句话点透这个场景的核心统筹方法                │
├────────────────────────────────────────────────┤
│ 📚 对应课程知识点                                │
│   属于课程第几模块/第几个方法                     │
└────────────────────────────────────────────────┘
```

详细设计方法见 [`01_场景设计公式.md`](01_场景设计公式.md)。

## 四、8 个行业版本的设计差异

| 行业 | 典型角色 | 统筹难点 | 高频"翻车"点 |
|------|---------|---------|------------|
| 互联网产品 | 产品经理、技术 Leader、增长负责人 | 节奏快、术语多、抽象概念 | 用"显然"开句、人机分工不清 |
| 制造业 | 车间主任、质量工程师、生产主管 | 老师傅不爱说话、表达直接 | 忽视经验知识、人机信任建立难 |
| 培训HR | 培训经理、HRBP、组织发展专家 | 学员抗拒、动机低 | 纯流程化、人机协作形式化 |
| 教育咨询 | 课程设计师、咨询顾问、培训师 | 知识密度大、怕讲错 | 过度依赖AI、忽视人的判断 |
| 电商零售 | 电商运营、店长、客服主管 | 时间紧、流量焦虑 | 人机分工一刀切、忽视用户情感 |
| 财务法务 | 财务经理、法务顾问、合规负责人 | 准确性优先、表达严谨 | AI辅助决策风险、留痕责任 |
| 销售客户成功 | 销售经理、客户成功经理、BD | 客户抗拒、关单压力 | 人机交接断层、信任链断裂 |
| 医疗健康 | 科室主任、护士长、医疗AI产品经理 | 专业壁垒、情绪紧张 | 人机边界模糊、伦理风险 |

**关键设计原则**：
- 每个行业都有"专属坑"（不是简单换名字的同质场景）
- 每个行业的"好统筹标准"不一样（财务要严谨、医疗要共情、销售要关系）
- 角色卡里**一定包含性格特征**（性格会影响统筹决策时的反应模式）
- 每个场景都要回答"这个场景要不要/怎么引入智能体"

## 五、4 种使用强度（按课时选）

| 强度 | 时长 | 做法 | 适合场景 |
|------|------|------|---------|
| 🟢 轻量 | 15-20分钟 | 抽 1 个场景做"人工作业 vs 人机协作"对比讨论 | 模块结束回顾 |
| 🟡 标准 | 45-60分钟 | 抽 1 个完整场景做小组演练 + 全班分享 | 单元小练 |
| 🟠 深度 | 90-120分钟 | 1 个行业全套场景演练 + 学员互评 | 一天工作坊 |
| 🔴 沉浸 | 半天 | 一个行业全套 6 模块演练 + 产出实际统筹方案 | 行业定制课 |

**默认推荐 🟡 标准**，覆盖一节课，又能完整跑通一个角色的一个统筹决策片段。

## 六、场景之间的"接力设计"

每个行业的 6-8 个场景**不是平行的，而是连贯的统筹任务链**：

```
场景1：语境对齐——接到任务，先建立共同业务语境（共同语境方法）
   ↓ 识别"我们到底要解决什么问题"
场景2：目标拆解——把大目标拆成可行动的子目标（目标分解方法）
   ↓ "这个目标里，哪些该人做、哪些该机器做"
场景3：人机判断——判断哪些环节真正需要智能体介入（人机判断方法）
   ↓ "这个任务，智能体能做到什么程度？"
场景4：信任建立——人和智能体协作时怎么建立信任（信任建立方法）
   ↓ "我怎么能相信AI的判断？"
场景5：统筹协调——多角色多任务时怎么统筹（统筹协调方法）
   ↓ "优先级怎么排、时间怎么分"
场景6：综合实战——完整一次人机协作的统筹决策（综合演练）
   ↓ 学员两两对练 + 全班点评
```

学员跟着一个角色走完一个统筹任务链 = 把 6 个模块的统筹方法**穿成一条链**，而不是孤立地学知识点。

## 七、与课程其他材料的关系

```
教学文档        ── 理论框架（统筹方法是什么、为什么）
       ↓
场景库（本库）   ── 角色体验（穿上工牌、做过决策）
       ↓
练习册           ── 知识巩固（判断题、选择题、方案设计）
       ↓
成果demo         ── 标杆示范（一份真实统筹方案的完整产出）
       ↓
学员手册         ── 长期工具（清单、模板、自查表）
```

**场景库是"教学文档"和"练习册"之间的桥**：
- 教学文档偏方法（"什么是人机判断"）
- 练习册偏巩固（"判断这个任务该用AI还是人"）
- 场景库让学员**自己成为统筹决策的主角**

## 八、使用建议

### 学员视角
- **第一次学**：跟着讲师做 1 个标准场景（🟡 强度），感受节奏
- **第二次学**：选自己行业的场景集，自学 + 找同事演练
- **学完后**：把场景里的"四层提问清单"**直接用到下一次统筹决策中**

### 讲师视角
- 第一次讲：选 **培训HR** 或 **教育咨询** 行业版本（角色相对熟悉，演练摩擦适中）
- 老学员复训：选 **医疗健康** 或 **财务法务**（统筹挑战性高）
- 课前 30 分钟准备：通读场景的"留白提问"和"四层提问清单"
- 现场演绎：可以请 2-3 位学员分别演"纯人工作业版""人机协作版""人机信任建立版"三个角色

### 企业内训定制
- 优先用本企业**主力行业**的版本
- 角色卡里的"公司背景"可以替换为学员熟悉的真实公司
- 任务用本企业真实统筹场景替代（讲师课前 1 周收集）
