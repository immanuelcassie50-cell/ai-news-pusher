# 邮件模板编写详细指南

## 占位符规范

在 `email_template.txt` 中使用双大括号 `{{字段名}}` 定义动态内容。

### 占位符类型

| 类型 | 格式 | 说明 |
|------|------|------|
| 直接值 | `{{字段名}}` | 原始数据 |
| 格式化值 | `{{字段名_格式化}}` | 自动格式化（货币/百分比） |
| 固定值 | `{{生成日期}}` | 自动填入当前日期 |

### 可用占位符

**基础信息（自动填充）**
- `{{项目编号}}` — 来自配置的 project_id_column
- `{{项目名称}}` — 来自配置的 project_name_column
- `{{报告期}}` — 来自配置的 report_period_column
- `{{生成日期}}` — 自动填入当前日期，格式：2026年05月25日

**项目经理信息（需通讯录）**
- `{{收件人姓名}}` — 来自项目经理通讯录
- `{{收件人邮箱}}` — 来自项目经理通讯录

**财务数据（来自 field_mapping）**
- `{{总预算}}` — 原始数值
- `{{总预算_格式化}}` — 格式化为货币字符串，如 ¥1,200,000.00
- `{{实际支出}}` / `{{实际支出_格式化}}`
- `{{预算余额}}` / `{{预算余额_格式化}}`
- `{{执行率}}` — 小数值（如 0.875）
- `{{执行率_格式化}}` — 百分比字符串（如 87.5%）
- `{{直接材料}}` / `{{直接材料_格式化}}`
- `{{直接人工}}` / `{{直接人工_格式化}}`
- `{{制造费用}}` / `{{制造费用_格式化}}`
- `{{其他费用}}` / `{{其他费用_格式化}}`
- `{{备注}}` — 原始字符串

### 命名规则

占位符名称须与 `bc_email_config.json` 中 `field_mapping` 的 key 一致。

格式化版本自动识别：以 `_格式化` 结尾的占位符会调用 `format_currency()` 或 `format_percent()`。

## 推荐结构

```
主题：【财务通知】{{项目名称}} - {{报告期}} 成本情况通报

{{收件人姓名}} 您好，

[简要说明]

一、成本概览
  • [数据项1]：{{数据项1_格式化}}
  • [数据项2]：{{数据项2_格式化}}

二、[其他模块]

[备注说明]

[结束语]
财务部
{{生成日期}}
```

## 常见问题

### Q: 占位符写错了会怎样？
生成时未匹配的占位符会显示为 `{{⚠️ 未找到字段: xxx}}`，检查配置后重新运行。

### Q: 如何添加自定义字段？
1. 在 `bc_email_config.json` 的 `field_mapping` 中添加映射
2. 在模板中添加 `{{字段名}}` 或 `{{字段名_格式化}}`

### Q: 预算余额怎么计算？
两种方式：
- 在 BC Excel 中预先计算好，配置列名直接引用
- 在 `field_mapping` 中填写公式 `总预算-实际支出`，脚本会自动计算

### Q: 如何添加预警提示？
邮件末尾会自动添加预警（当执行率超过阈值时），无需在模板中手动添加。

## 预警提示格式

脚本自动在邮件末尾追加预警信息：

- 执行率 ≥ critical (默认 1.0)：`⚠️【预算已超支】请项目经理关注并说明原因`
- 执行率 ≥ warning (默认 0.9)：`⚡【预算接近上限】执行率已超 90%，请做好剩余控制`

预警阈值可在 `bc_email_config.json` 的 `alert_thresholds` 中修改。
