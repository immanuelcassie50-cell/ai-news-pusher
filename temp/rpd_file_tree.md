## 二、课程文档格式规范总结

| 部分 | 内容 | 产出物 |
|------|------|--------|
| 开篇 | 课程背景、对比案例、自测表 | 自我诊断表 |
| 第一部分 | 学员需求分析（专家思维vs培训师思维） | 学员分析表 |
| 第二部分 | 课程设计方法上（模块框架图） | 模块框架图 |
| 第三部分 | 课程设计方法下（案例化知识点） | 案例化知识点 |
| 第四部分 | 互动启发式教学方法 | 互动设计方案 |
| 第五部分 | 培训评估方法 | 课堂检验清单 |
| 第六部分 | 公众表达技巧 | 30秒开场稿 |
| 第七部分 | 综合演练与总结 | 完整教学方案 |

### 2.2 讲师手册标准格式

根据 `讲师手册demo` 目录，标准格式包含：
- 讲师开场引导语
- 各模块时间分配
- 学员练习指引
- 常见问题应对
- 讲师点评要点
- 课堂节奏把控

### 2.3 学员手册标准格式

根据 `学员手册demo` 目录，标准格式包含：
- 课程目标
- 学习路径图
- 核心知识点
- 练习题
- 自我检验
- 课后行动

### 2.4 评估工具包标准组件

根据 `评估工具包` 目录，标准7组件包含：
1. 前测题库（学员版）
