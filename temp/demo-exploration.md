## 三、核心组件用途总结

### 1. 成果Demo（标杆示范）
**文件格式**：`md` + `xlsx` + `html` + `py`

这是整个Demo库的核心示范，展示了"从单向讲解到双向互动"的完整改造过程：

- **主线**：互联网产品经理场景（产品需求评审，90分钟）
- **Day 1**：懂/会/信诊断 → 结构化大纲 → 清晰化改写 → 生动化案例
- **Day 2**：留白引导案例 → 互动流程时间表 → 四层提问清单 → 异议应对话术 → 综合改造方案

每个文件都是**真实的完整产出**，不是模板，让学员能照着做、能看到"做到"长什么样。

---

### 2. 场景库（角色演练剧本）
**文件格式**：`md` + `html`

8个行业版本（互联网产品/制造业/培训HR/教育咨询/电商零售/财务法务/销售客户成功/医疗健康），每个行业场景集约8000-12000字。

**标准场景结构**：
- 角色卡（岗位/背景/性格特征）
- 背景任务
- 关键节点
- 留白提问
- 互动流程（90秒独立想→3分钟两人对谈→8分钟全班讨论）
- 四层提问清单（事实→感受→原则→行动）
- 可迁移原则
- 对应课程知识点

---

### 3. 混合学习课前包（学员预习）
**文件格式**：`html` + `md`

7个文件，总耗时约50分钟。设计理念是"把最有价值的时间留在课堂上"。

| 文件 | 类型 | 用途 |
|------|------|------|
| 01_课前导读 | HTML | 理解为什么有这门课 |
| 02_预习材料_方法速览 | HTML | 建立六方法认知地图（25分钟） |
| 03_自我诊断问卷 | HTML | 18项自评，训前基线 |
| 04_我的场景卡 | HTML | 锁定课程中要迭代的那节课 |
| 05_行前清单 | MD | 课前24小时检查 |
| 06_开营破冰活动指南 | MD | 讲师主持用（30-45分钟） |

---

### 4. 评估工具包（量化教学思维转变）
**文件格式**：`md` + `html`

7个组件覆盖前测→课中观察→后测→数据分析全流程：

| 组件 | 视角 | 用途 |
|------|------|------|
| 前测题库 | 学员自评 | 课前24h，发现起点 |
| 后测题库 | 学员自评 | 结课后30分钟内，量化提升 |
| 参考答案与评分细则 | 讲师专用 | 批改标准 |
| 行为观察量表 | 讲师观察 | 六大方法实操过程打分 |
| 数据分析与课程改进指南 | 讲师专用 | 数据怎么解读 |
| 可视化评估看板 | 讲师/管理者 | 班级整体数据（A3横向） |
| README | 全员 | 整体使用流程 |
