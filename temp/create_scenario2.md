# 场景2：触发条件被激活

**场景类型：** 假设触发与应急响应
**发生时间：** 2024年8月15日
**涉及人员：** 赵敏（业务顾问）、李晓峰（项目经理）、南方子公司张总
**假设编号：** H005
**假设内容：** 各子公司愿意放弃本地流程，接受集团统一流程

---

## 场景背景

### 假设H005的状态

| 项目 | 内容 |
|-----|------|
| 假设内容 | 各子公司愿意放弃本地流程，接受集团统一流程 |
| 假设依据 | 项目章程中获得各子公司总经理签字确认 |
| 风险等级 | 高 |
| 计划验证时间 | 2024年7月25日 |
| 实际验证时间 | 2024年7月25日 |
| 验证方式 | 在启动会上正式访谈各子公司负责人 |
| 触发条件 | 任何一家子公司明确表示抵制统一流程 |

### 预警信号

在2024年7月28日的双周会上，林晓华提到：
> "我前两天跟南方子公司的张总通了个电话，感觉他对统一流程有些想法，你们后续访谈时可以注意一下。"

### 触发事件

2024年8月15日，赵敏按计划前往南方子公司进行访谈。

---

## 响应过程

### 阶段一：触发识别（8月15日上午）

**地点：** 南方子公司会议室

**对话实录：**

**赵敏：**
> "张总，您好。感谢您抽出时间接受访谈。根据项目计划，我们需要了解各子公司对统一流程的看法，以便设计出更合适的方案。"

**张总：**
> "赵顾问，我直说了——你们那个方案，我没同意过。"

**赵敏：**
> "张总，我理解您的顾虑。能详细说说吗？"

**张总：**
> "你们要我放弃本地流程，用你们统一的流程。我们南方子公司有自己的生产特点，我们用的本地MES系统已经10年了，运行很稳定。你们现在要我换，我换一个试试？出了问题谁负责？"

**赵敏：**
> "张总，我理解您的担心。您提到的这些顾虑，我能直接向项目组反馈吗？"

**张总：**
> "你尽管反馈。我不是反对集团ERP统一，我是反对'一刀切'。给我一个过渡期，让我先试点，行不行？"

### 阶段二：紧急上报（8月15日下午）

**赵敏立即联系李晓峰：**

**赵敏：**
> "李经理，出问题了。南方子公司张总明确表示抵制统一流程，要求先试点后推广。"

**李晓峰：**
> "触发条件被激活了。我马上启动应急方案。"

### 阶段三：应急方案启动（8月15日-16日）

**李晓峰查看触发条件与应急方案：**

| 项目 | 内容 |
|-----|------|
| 触发条件 | 任何一家子公司明确表示抵制统一流程 |
| 触发指标 | 子公司总经理会议纪要明确反对 |
| 监测责任人 | 赵敏 |
| 应急方案 | 1.立即向项目总监汇报<br>2.组织专项沟通会，了解抵制原因<br>3.评估是否需要调整统一流程方案<br>4.如无法协调，启动范围变更流程 |
| 应急权限人 | 张明华 |

**李晓峰向张明华汇报：**

**李晓峰：**
> "张总，有个情况需要向您汇报。H005假设被触发，南方子公司明确抵制统一流程。我已经启动了应急方案。"

**张明华：**
> "我知道了。你先把情况整理一份书面报告，我明天向陈永强汇报。"

### 阶段四：专项沟通（8月20日）

**地点：** 华东制造集团总部

**参会人员：**
- 王建业（常务副总裁）
- 陈永强（CIO）
- 李晓峰（我方项目经理）
- 张总（南方子公司总经理）

**沟通过程：**

**王建业：**
> "张总，我听说你对ERP统一有不同想法？我想听听你的意见。"

**张总：**
> "王总，我不是要跟集团对着干。我是担心'一刀切'。我们南方子公司的情况比较特殊，生产线老旧，工人习惯了现有系统，突然换可能会出生产事故。"

**王建业：**
> "李经理，你们怎么看？"

**李晓峰：**
> "王总，我们理解张总的顾虑。我们建议一个'先试点后推广'的方案：南方子公司先选择一个试点产线，运行3个月，如果没有问题再全面推广。试点期间，旧系统并行运行，给南方子公司一个过渡期。"

**张总：**
> "这个方案我可以接受。"

**王建业：**
> "好，就这么定。陈永强，你来协调具体实施方案。"

### 阶段五：方案调整（8月25日）

**调整内容：**
1. 南方子公司采用"先试点后推广"策略
2. 试点期间新旧系统并行运行
3. 试点周期3个月
4. 项目周期延长1个月

---

## 最终结果

| 项目 | 原计划 | 调整后 |
|-----|-------|-------|
| 南方子公司上线策略 | 一次性全面推广 | 先试点后推广 |
| 新旧系统并行期 | 无 | 3个月 |
| 项目周期 | 12个月 | 13个月 |
| 预计成本 | 800万 | 815万 |

## 关键技巧

### 1. 建立预警机制

林晓华在双周会上提到"张总有些想法"，这是一个预警信号。虽然不能确定是否会触发，但及时预警让项目组有了准备。

**做法：**
- 在双周会上鼓励客户方分享"异常信号"
- 对预警信号不轻视，及时跟进
- 做好触发条件被激活的心理准备

### 2. 触发后立即响应

赵敏在触发后立即联系李晓峰，而不是"等一等看看情况"。

**做法：**
- 触发条件被激活后，第一时间上报
- 不要试图自己解决超出权限的问题
- 及时启动应急方案

### 3. 准备多个解决方案

李晓峰在汇报时准备了多个解决方案，而不是只说"有问题"。

**做法：**
- 永远带着解决方案去汇报
- 评估每个方案的优缺点
- 让客户方做选择题，而不是问答题

### 4. 借助高层力量

当部门利益与集团利益冲突时，需要更高层来协调。

**做法：**
- 及时将问题升级到双方高层
- 准备好向上汇报的材料
- 高层沟通时保持专业和客观

## 场景反思

### 做对了什么？

1. **预警信号没有忽视** - 林晓华的提醒引起了注意
2. **触发后立即响应** - 没有拖延，快速上报
3. **应急方案有案可循** - 之前已经制定了应急方案
4. **解决方案准备充分** - 带着方案去沟通

### 还可以改进什么？

1. **预警信号可以更早** - 如果7月28日就深入跟进，可能更早触发
2. **替代方案可以更丰富** - "先试点后推广"只是其中一个选项
3. **成本影响评估可以更详细** - 1个月延期的影响可以更早量化

---

## 延伸思考

### 如果没有假设管理机制，会发生什么？

**没有预警机制：**
- 林晓华的预警可能被忽视
- 问题不会被提前发现

**没有触发条件：**
- 不知道什么情况算"假设失败"
- 可能错过最佳应对时机

**没有应急方案：**
- 出现问题后手忙脚乱
- 决策没有依据

**结果：**
- 可能在设计完成后才发现南方子公司的抵制
- 返工成本可能是现在的5倍以上
