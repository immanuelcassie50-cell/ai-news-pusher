# 行动学习 - 创新解决方案 授课 PPT 设计规范

## 项目信息

- **主题**：行动学习 - 创新解决方案（不是要创新，是要找到真正有效的解法）
- **页数目标**：150-180 页
- **配色**：红灰配色，浅底
- **风格**：极致美学、视觉化、多样化
- **输出目录**：`D:\2026年课程\行动学习2026\行动学习-创新解决方案\授课PPT`

## 配色（5 色主题对象）

```javascript
const theme = {
  primary:   "6B0F0F",  // 深酒红 - 标题、章节号、主色
  secondary: "3D3D3D",  // 深灰 - 正文文字
  accent:    "B8232C",  // 砖红 - 强调、关键数据
  light:     "D4C5BE",  // 浅灰红 - 装饰线、次要背景
  bg:        "F5F0EC"   // 米白底 - 主背景（浅底）
};
```

辅助色（在 theme 外可使用）：
- `FFFFFF` 纯白（卡片底）
- `1A1A1A` 极深灰（极重要数据）

## 字体

- **中文**：`Microsoft YaHei`
- **英文标题**：`Georgia` 或 `Cambria`（有书卷气）
- **英文正文**：`Arial`

## 风格

**Soft & Balanced**（中等圆角，专业且亲和）
- 小元素圆角：0.05"
- 中等元素圆角：0.08"  
- 大元素圆角：0.12"
- 页面边距：0.4"
- 元素间距：0.2-0.3"

## 尺寸

- **10" x 5.625"**（LAYOUT_16x9）

## ⚠️ 关键设计要求（与默认 PPT 规范不同）

1. **不要右下角的页码徽章**！用户明确要求
2. 页码采用**页脚左侧**的极简文字格式（如：`课程名 / 03`），字号 9pt，theme.secondary 颜色
3. 页脚右侧可放**章节名/小标识**，呼应页码

## 页脚统一规范

每页（封面除外）底部加入：
- **底部 0.05" 高的细线**（y=5.42"）：左 1/3 段为 theme.primary，中段空，右 1/3 段为 theme.light
- **页脚左侧文字**（x=0.5" y=5.46"）："行动学习 · 创新解决方案"  + 页码（"03"），字号 9pt
- **页脚右侧文字**（x=6" y=5.46"）：当前章节名（可空），字号 9pt
- 文字颜色 theme.secondary

### 页脚代码模板

```javascript
// 页脚细线（左 1/3 红 + 右 1/3 浅灰）
slide.addShape(pres.shapes.RECTANGLE, {
  x: 0.5, y: 5.42, w: 3, h: 0.02,
  fill: { color: theme.primary }, line: { type: 'none' }
});
slide.addShape(pres.shapes.RECTANGLE, {
  x: 6.5, y: 5.42, w: 3, h: 0.02,
  fill: { color: theme.light }, line: { type: 'none' }
});
// 页脚左侧文字
slide.addText(`行动学习 · 创新解决方案  /  ${pageNumber}`, {
  x: 0.5, y: 5.46, w: 5, h: 0.25,
  fontSize: 9, fontFace: 'Microsoft YaHei',
  color: theme.secondary, align: 'left', valign: 'middle', margin: 0
});
// 页脚右侧文字
slide.addText(sectionName, {
  x: 6, y: 5.46, w: 3.5, h: 0.25,
  fontSize: 9, fontFace: 'Microsoft YaHei',
  color: theme.secondary, align: 'right', valign: 'middle', margin: 0
});
```

`pageNumber` 是字符串（"03" 这种格式），`sectionName` 是当前章节名。

## 功能页规范

### 封面 (Cover)
- 浅米白底
- 左侧：大标题 + 副标题 + 课程编号
- 右侧：装饰性几何块（深红 + 浅灰红组合）
- 不加页脚

### 章节扉页 (Section Divider)
- 整页主色块（theme.primary 深酒红）作为左侧 1/3
- 右侧浅米白底
- 大数字编号 + 章节标题
- 章节副标题 1 行
- 底部细线 + 简短导语

### 课程地图 (TOC)
- 浅米白底
- 6 个章节卡片，2x3 网格
- 每张卡片：序号 + 标题 + 1 行描述
- 不同卡片可用深红或浅灰红做小色块装饰

### 结束页 (Closing)
- 与封面呼应（左右对调或镜像）
- 大字"不是要创新，是要找到真正有效的解法"
- 副标题：回到原点的金句

## 内容页（Content）规范

**核心：视觉化、多样化，绝不重复同一布局！**

### 可用布局库（每页必须用其中之一，且相邻页必须不同）

1. **大数字引述**：核心论断用 60-72pt 大字居中
2. **三栏并排**：3 个并列概念，各有图标块
3. **2x2 矩阵**：4 个象限（如 4 种天花板）
4. **流程/时间轴**：横向 4-5 步骤带箭头
5. **对比卡片**：左右对比（A vs B）
6. **引述+出处**：大引号 + 引文 + 出处（小字）
7. **大数字 + 说明**：60-96pt 数据 + 一句解读
8. **图标行**：4-6 个小圆图标 + 短文字
9. **图文混排**：左侧文字 + 右侧几何/色块图示
10. **列表 + 装饰**：要点列表 + 右侧大型几何装饰
11. **案例框**：醒目边框 + 案例标题 + 案例内容
12. **章节小结**：3-5 个关键要点 + 大图标

### 装饰元素库

可用几何形状：
- 矩形色块（红/灰填充）
- 圆形（小圆点作为强调标记）
- 横向/竖向细线（分隔）
- 大数字水印（淡灰色作为背景装饰）
- 角标（页面角落的小红色矩形或圆形）

### 案例页特殊要求

每个 ⚡ 案例/💡 提示/📌 强调 都用：
- 顶部：色块条 + 案例图标
- 内容区：故事化叙述，关键数据用砖红色突出
- 底部：1 句"启示"或"运用要点"

## 配色使用规范

| 用途 | 颜色 |
|------|------|
| 大标题、章节号 | theme.primary 深酒红 |
| 正文 | theme.secondary 深灰 |
| 关键数据、强调字 | theme.accent 砖红 |
| 装饰线、卡片边 | theme.light 浅灰红 |
| 页面背景 | theme.bg 米白底 |
| 卡片底 | FFFFFF 纯白 |
| 弱化文字（页脚/出处） | theme.secondary 透明度 60% |

## 通用规则

- **不用渐变**（design-system 禁止）
- **不用动画**
- **不用加粗正文**（design-system 禁止）
- **正文左对齐**，标题可居中或左对齐
- **每页必有视觉元素**（非纯文字）
- **页边距 ≥ 0.4"**
- **绝不重复使用相同布局的连续两页**
- **避免中英文混杂的标点混用**
