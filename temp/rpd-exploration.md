## 3. 【15.AI大模型底层原理】详细内容

### 课程定位
**课程编号**: 15（计算机科学类第1门）
**课程名称**: 《AI大模型底层原理:非工程师的认知框架》

### 五维边界

| 维度 | 内容 |
|------|------|
| **面向人群** | 高频使用AI工具(如Claude、GPT系列)进行内容生成、分析、决策辅助的知识工作者和内容创作者——已有大量"怎么用"经验，但缺少"为什么"层面的理解 |
| **要解决的问题** | 市面上AI科普两极分化：技术论文门槛过高 vs 过度简化的"人工智能就是模仿人脑"式比喻严重误导。重度使用者需要中间层次的认知框架 |
| **输入** | 不要求编程或数学基础，但假设用户已有较丰富的AI工具使用经验，课程会结合真实使用场景讲解原理 |
| **输出** | 理解transformer架构和自注意力机制的直觉原理(不涉及矩阵运算)；理解预训练、微调、强化学习对齐(RLHF)各自解决什么问题；理解"幻觉"产生的根本机制及为什么无法被完全消除；建立评估新模型发布真实意义的判断框架 |
| **实现的目标** | 让重度AI使用者从"经验型用户"升级为"原理理解型用户"，能够更准确预判不同任务该用什么模型、判断模型能力边界 |

### 课程边界（不涉及的内容）
- 不涉及编程实现和API调用细节
- 不做具体模型的横向评测（时效性太强）
- 聚焦在稳定的底层原理框架

### 核心知识点覆盖
1. **Transformer架构与自注意力机制** — 直觉原理，不涉及矩阵运算
2. **预训练 vs 微调 vs RLHF** — 各自解决什么问题
3. **幻觉( Hallucination)的根本机制** — 为什么无法被完全消除
4. **模型评估框架** — 如何区分真正的能力突破与营销包装

### 在整个课程体系中的位置
- 属于**计算机科学类**（第五批，共3门）
- 同批次课程：《计算机科学史》《算法思维》
- 前置背景：用户已有丰富的AI工具使用经验
