├─ 使用3位数字编号: 001, 002, ... 009
├─ 短横线分隔
├─ 中文描述性名称
└─ 示例: 005-文化即业务-培训教师指导手册

文件命名:
├─ 3位数字前缀
├─ 内容描述
├─ 版本号标识(如V3.0)
└─ 示例: 001-课程说明书-文化即业务V3.0.pptx

【版权标识标准】

【文档结构标准】

工具表单结构:
├─ 顶部: 公司信息和工具名称
├─ 标题: 工具表名称和编号
├─ 副标题: 方太从零快速突破百亿实战案例推演-系列工具表
├─ 左侧: 方太核心价值观介绍

└─ 页脚: 版权和保密声明

├─ 案例编号: 案例X-X：名称
├─ 案例萃取师
├─ 案例摘要
├─ 关键词
├─ 情景聚焦
├─ 案例正文
├─ 案例分析
├─ 案例启示
└─ 参考附录

【排版格式标准】

纸张尺寸:
├─ 标准A4 (210x297mm)
├─ 大尺寸海报 (A2: 420x594mm)
└─ 自定义尺寸 (如沙盘634x430)

色彩标准:
├─ 彩色印刷为主
├─ 统一视觉识别系统
└─ 方太品牌色系

字体规范:
├─ 中文: 宋体/黑体为主
├─ 英文: Arial/Calibri
└─ 标题和正文有明显层级

【内容格式标准】

PPT页面:
├─ 标题栏: 明确的主题
├─ 内容区: 清晰的要点
├─ 注释区: 备选内容(灰色/小字)

话术格式:
├─ 完整的讲授文字
├─ 分步骤引导
├─ 时间标注
└─ 互动提示

【版本控制标准】

版本格式:

├─ 大版本.小版本: V3.0, V2.0
└─ 更新记录标注
