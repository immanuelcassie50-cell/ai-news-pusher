

# 附录：拿来即用的工具与清单

> 这一部分是给"读完想立刻动手"的同行准备的。
> 前面十六章讲的是"为什么"和"是什么"，这一部分讲的是"明天就怎么做"。
> 我把我过去三年陪跑机构过程中用过的工具，整理成可以直接打印的清单和模板。
> 拿过去用、抄过去改、按你的机构改到能用——这一部分的价值，是让你少走至少半年的弯路。

---

## 附录 A：合作前的"产品定义权自检表"

> 用法：和AI公司第一次正式会面前一周，由机构核心团队集体填写。每项10分，总分100分。80分以上再去见AI公司，60-80分先内部补课再见面，60分以下暂停AI合作计划。

**第一块：问题定义（30分）**

1. 我们能用一句话说清楚"我们要解决谁的什么问题"吗？（0-10分）
2. 这个"谁"具体到年龄、职业、付费能力了吗？（0-5分）
3. 这个"问题"具体到学员的某一次具体行为了吗？（0-5分）
4. 我们能用一个数字描述"问题被解决"的样子吗？（0-10分）

**第二块：不变价值（25分）**

1. 我们机构今天最值钱的那门课/那个老师/那个学习环节是什么？我们能用三句话说清楚吗？（0-10分）
2. 这件事里，AI做不了、别的机构给不了、我们自己说不清楚具体怎么给的"那个"是什么？（0-10分）
3. 我们计划怎么在AI合作里"强化"这件事，而不是"替代"它？（0-5分）

**第三块：数据资产（25分）**

1. 我们盘点过自己的数据资产吗？盘点的结果是什么？（0-10分）
2. 哪些数据是"现在就要用"的？哪些是"三年后再用"的？哪些是"绝对不能给"？（0-10分）
3. 我们有专门的数据归属和保护机制吗？（0-5分）

**第四块：合作角色（20分）**

1. 我们这次合作，机构内部谁是一号负责人？他/她每周能投入多少时间？（0-5分）
2. 我们准备在合作中保留哪些决策权？准备把哪些决策权让出去？（0-10分）
3. 如果合作半年后效果不达预期，我们有"暂停机制"吗？（0-5分）

**评分与决策：**

- 80分以上：可以进入AI公司选型阶段，但每个月的"自检"要继续做。
- 60-80分：先关上门做一轮"内部补课"，把得分低的项搞清楚，再去见AI公司。
- 60分以下：暂停AI合作计划，先做产品内部重塑。

## 附录 B：AI合作合同审查清单

> 用法：把这份清单交给你的律师，让律师在审合同时逐项打勾。每一项都"是"才能签字，"否"或"模糊"必须先解决。

**第一块：数据条款**

1. 学员数据、教学数据、考试数据、家长互动数据的归属权，是否明确归机构？AI公司只有使用权？
2. AI公司能否将机构数据用于其他客户的模型训练？是否需要机构的逐项授权？
3. 合作终止后，AI公司多长时间内必须删除或返还机构数据？删除的证据如何提供？
4. 合作期间，AI公司发生数据泄露事故，赔偿标准、责任划分、披露机制是什么？

**第二块：知识产权条款**

1. 共建产品的知识产权归谁？是共建共有还是一方所有？
2. AI公司原有的算法、模型、技术专利，机构能用到什么程度？是否限定用途？
3. 机构原有的品牌、商标、课程内容、师资肖像权，AI公司能否使用？使用范围和授权方式？
4. 合作期间由AI公司员工单独创造、不基于机构数据的IP，归谁所有？

**第三块：合作范围条款**

1. AI公司能服务机构的直接竞争对手吗？合同期内Top 10竞业的范围是什么？
2. 合作产品的对外宣传、品牌露出、案例库收录，机构是否有审批权？
3. 合作产品的二次开发权归谁？机构是否可以独立二次开发？
4. 合作产品的源码、文档、运维手册的交付方式和时间表？

**第四块：付费条款**

1. 付费结构是"一次性买断 / 订阅付费 / 效果付费"中的哪一种？混合结构如何切分？
2. 效果付费的KPI如何定义？如何测量？未达预期如何处理？
3. 是否有"产品验收不达预期"的处理条款？返工、减款、终止的条件是什么？
4. 合同期内价格是否锁定？续约价格的调整机制是什么？

**第五块：退出条款**

1. 友好退出、单边退出、争议退出三套方案，是否都有约定？
2. 退出后，AI公司多久内必须完成源代码、产品文档、运维手册的完整交付？
3. 退出后，学员的账号迁移路径是什么？迁移成本由谁承担？
4. 退出后，AI公司能否在市场上继续销售基于机构数据训练出的产品？

**第六块：争议解决条款**

1. 出现纠纷时，是仲裁还是诉讼？仲裁机构是哪一家？
2. 适用法律是哪一国/地区的法律？
3. 仲裁/诉讼期间，合作业务如何继续？
4. 是否有"调解前置"机制？

## 附录 C：内部需求审计表

> 用法：合作开始前的"内部需求审计"环节，由机构核心团队集体填写。每项 1-5 分，5 分是"非常清晰"，1 分是"完全模糊"。每项 1-3 分的，必须先在内部讨论清楚。

**第一部分：用户洞察（5项）**

1. 我们最核心的付费用户是谁？他们的画像清晰吗？
2. 我们最被低估的用户价值是什么？什么场景下他们愿意多付钱？
3. 我们学员家长最在意的三件事是什么？我们有数据支撑吗？
4. 我们的学员从进入到离开，最关键的5-10个"学习瞬间"是什么？
5. 我们学员离开的Top 3原因是什么？数据有跟踪吗？

**第二部分：产品价值（5项）**

1. 我们今天最值钱的产品/课程/服务是什么？它值钱的本质原因是什么？
2. 这个"值钱"，是"内容值钱"、"老师值钱"、"品牌值钱"、还是"关系值钱"？
3. AI时代，这件事会发生什么变化？是升值还是贬值？
4. 我们的产品"同质化程度"有多高？和同行比，差异在哪里？
5. 如果AI能"看起来"复制我们的产品，学员会怎么区分真假？

**第三部分：组织能力（5项）**

1. 我们核心团队里，谁懂AI、谁懂产品、谁懂运营、谁懂教研？
2. 我们的教研内容资产有多大体量？它能被AI学习、被我们迭代吗？
3. 我们的师资团队里，A类/B类/C类老师的比例是多少？
4. 我们内部有没有"AI产品负责人"或类似角色？
5. 我们机构对"试错"的容忍度有多高？过去一年我们试错过什么？

**第四部分：合作准备（5项）**

1. 我们能投入这次合作的"最高负责人"是谁？他的时间承诺是什么？
2. 我们为这次合作预留了多少预算？预算的"可损失上限"是多少？
3. 我们在合作中"绝对不能失去"的东西是什么？数据？品牌？师资？客户关系？
4. 合作失败的最坏情景是什么？机构能承受吗？
5. 合作成功的"最低标准"是什么？这个标准具体可量化吗？

## 附录 D：师资安置方案模板

> 用法：当机构决定启动AI合作时，同步启动师资盘点。师资盘点不是"裁员计划"，是"重塑计划"——重塑每个人的角色、贡献、收益。模板分四类老师。

**A类老师：可被AI放大的老师**

- 识别标准：有自己的"风格"——讲课有段子、有故事、有情绪、有"金句"；学员评价里反复出现"老师"这个字眼。
- 角色重塑：从"批量教学"转向"关键节点亲自带教 + AI产品监制 + 学员成长辅导"。
- 投入：配备AI助理，把批改、出题、答疑等"批量工作"全部转给AI。
- 收益结构：课时费 + 学员成长档案分红 + AI产品联名分红 + 品牌联合署名权。
- 退出条件：若A类老师主动要求回到纯教学岗位，机构应支持而非阻拦。

**B类老师：可被AI部分替代的老师**

- 识别标准：有经验、有内容、有人格魅力，但核心竞争力是"知识本身"而非"个人风格"。
- 角色重塑：转型方向三选一——学习陪伴者 / 校友关系维护者 / 教研内容策划者。
- 投入：提供"转岗培训"——培训时长3-6个月，培训期间薪资不降。
- 收益结构：转岗后的新岗位薪资 + 转岗成功奖金 + 长期成长分红。
- 退出条件：转岗培训完成后，若老师仍不适应新岗位，机构应坦诚讨论"未来三年的位置"。

**C类老师：确实会被AI替代的老师**

- 识别标准：核心竞争力是"知识的搬运"——主要价值是把大纲、教材、PPT讲解给学员听。
- 安置方式：渐进的、体面的、有补偿的——
  - 选项一：转岗培训。学习AI数据标注、AI内容审核等AI时代新技能。
  - 选项二：创业支持。若老师愿意离开机构去做"个人IP"或"小工作室"，机构在客户资源、品牌授权、起步资金上提供支持。
  - 选项三：职业过渡金。提供6-12个月的过渡金，让老师有时间和空间寻找新方向。
- 沟通时机：在合作方案确定前 3 个月就开始沟通，而不是合作上线前 1 个月。
- 沟通原则：坦诚、直接、有方案。不要"装作没事"，也不要"突然摊牌"。

## 附录 E：选AI合作伙伴的"九道筛子"速查卡

> 用法：见AI公司销售时打印一份，每个问题逐条问、逐条记。AI公司的反应比他们的PPT更能说明问题。

**第一组：在不在"教育经济"里**

1. 问："你们对教育的理解是什么？"——听具体回答，不听PPT话术。
2. 问："你们服务的客户里，有哪家在用你们产品一年后退出了？为什么？"——听"退出"案例，不听"成功"案例。
3. 问："你们认为我们机构最不该用AI做的事是什么？"——看AI公司有没有"克制"。

**第二组：有没有"产品共建"基因**

4. 问："你们的客户有没有'产品共建委员会'这样的机制？"——看AI公司是把你当"渠道"还是"共建方"。
5. 问："你们的Roadmap是怎么形成的？客户参与了多少？"——看产品决策权的分配。
6. 问："你们服务客户的标准流程是什么？最关键的三个决策点是什么？"——看流程的透明度。

**第三组："撤退"姿态**

7. 问："如果合作半年后我们发现产品效果不达预期，你们的退出方案是什么？"——让AI公司提前想"怎么分手"。
8. 问："如果我们想自己二次开发你们的产品，需要具备什么条件？源代码是否开放？"——看AI公司的"开放度"。
9. 问："你们在和我们合作的同时，有没有在和我们同行合作？合作方是谁？"——看竞业和专业度。

**评分：**

- 9题全过：进入短名单，养关系至少一个季度再签。
- 6-8题过：进入短名单但严格控制合作范围，先小规模试点。
- 6题以下：直接淘汰。

## 附录 F：AI合作复盘模板

> 用法：合作进行到第 3、6、12 个月时，各做一次复盘。复盘分三块——做对的、做错的、还没做的。

**第一块：做对的（具体动作 + 带来的具体变化）**

- 例：Q1 把"产品定义权自检表"做完后，重新选择了AI合作伙伴，节省了预计 80 万的无效投入。
- 例：Q2 把数据归属条款明确写进合同，合作至今无数据纠纷。
- 例：Q3 把"九道筛子"用在选型阶段，跳过了至少两家"PPT漂亮但合作风险大"的AI公司。

**第二块：做错的（具体失误 + 失误的代价）**

- 例：合作初期没把"产品验收标准"写清楚，AI公司交付的"AI错题本"在学员端使用率不到15%。
- 例：合作中期没有每月做"战略对齐"，到第6个月才发现双方对"我们要做什么产品"的判断已经完全不同。
- 例：合作末期没有勇气承认"这次合作效果不达预期"，拖了 3 个月才止损，多花了 40 万。

**第三块：还没做的（接下来要做的具体动作）**

- 例：下季度启动"产品共建委员会"，让机构核心团队成员正式参与AI产品Roadmap review。
- 例：下季度完成"数据资产清单"的二次梳理，把"现在要用"和"三年后再用"的数据明确分开。
- 例：下季度组织一次"跨行业交流"，和至少 3 个非教育行业的朋友交流 AI 合作的判断。

**复盘会的纪律：**

- 全员参加（机构核心团队 + AI公司核心团队）。
- 不追责，只总结经验。
- 复盘结果形成书面文档，双方签字存档。
- 下一次复盘会先回看上一次的"还没做的"，看是否落地。

# 后记：致正在读这本书的你

写到这最后一个附录，外面的天已经亮了。我不知道你是在什么场景下读这本书——是在高铁上、出租屋里、办公室深夜的台灯下、还是某个午休的间隙。

但无论你在哪里，我都想跟你说几句话。

第一，**读完这本书不会让你立刻成为AI合作的专家。** 真正让你成为专家的，是接下来你做的每一个具体决策。这本书能给你的，是每一个决策的"判断框架"，不是"具体答案"。

第二，**AI赋能合作这件事，没有标准答案。** 我写的所有判断，都来自我自己的经验和我陪跑过的机构样本。这些样本有它的局限性——我陪跑的多是中等规模机构、成人教育居多、东部地区居多。你的机构可能在我的样本之外。

第三，**不要被AI吓住，也不要被AI迷惑。** AI是工具，是机会，是变量，但不是你命运的"决定者"。决定你命运的，是你对教育的判断、你对学员的责任、你对机构品牌的承诺。AI只是放大器——它放大你好的部分，也放大你坏的部分。

第四，**如果合作失败了，不要怪AI。** 合作失败的真正原因永远是"人"——你的判断、AI公司的能力、双方的角色错配、双方对"成功"的理解不一致。AI不是失败的原因，也不是成功的捷径。

最后，**我希望这本书能让你"多撑一年"。** 在AI浪潮里，"多撑一年"是了不起的成就。一年之后，你会更懂AI，更懂你的机构，更懂这个行业。到那时回头看，今天的焦虑会变成"那时候怎么会那么紧张"。

你不需要做一个完美的转型者，你只需要做一个"活下来的转型者"。活下来，比什么都重要。

> **AI赋能合作中真正决定输赢的，是你在合作前对自己产品想清楚了多少。AI公司交付代码的那天，恰恰是合作最容易失败的那天。**

祝你在AI时代，活下来，活成你自己。
