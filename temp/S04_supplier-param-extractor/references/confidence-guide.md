# 置信度标注说明

本指南说明置信度体系的设计原理和使用方法。

## 置信度等级定义

| 等级 | 标识 | 含义 | 处理建议 |
|------|------|------|----------|
| 高 | `high` | 在文档中明确标注为"规格值"、"额定值"、"标准值"，可直接引用 | 直接使用 |
| 中 | `medium` | 从上下文中推断，需要结合多处信息判断 | 参考使用，建议核实 |
| 低 | `low` | 仅找到关键词但无具体数值，或使用了"约"、"参考"等模糊表述 | 必须人工核实 |
| — | `—` | 文件中完全未提及此参数 | 必须人工补充 |

## 高置信度关键词

在参数值附近出现以下关键词时，置信度判定为 `high`：

| 关键词 | 说明 | 示例 |
|--------|------|------|
| 规格 | 正式规格说明 | "工作电压：规格 12V" |
| 额定 | 额定工作条件 | "额定电压 220V" |
| Specification | 英文规格书标准表述 | "Operating Voltage: 12V (Specification)" |
| Rated | 英文额定值表述 | "Rated voltage: 5V" |
| Nominal | 标称值 | "Nominal value: 3.7V" |
| 标准值 | 标准规格值 | "标准值：5A" |

## 低置信度关键词

在参数值附近出现以下关键词时，置信度判定为 `low`：

| 关键词 | 说明 | 示例 |
|--------|------|------|
| 约 | 近似值 | "约 12V" |
| 大约 | 近似值 | "大约 5A" |
| 参考 | 参考值，非正式规格 | "参考值：3.5A" |
| approximately | 英文近似值 | "approximately 12V" |
| typical | 典型值，非保证值 | "Typical current: 2A" |
| Typical | 同上 | "2A (Typical)" |

## 置信度判断逻辑

脚本按以下顺序判断置信度：

1. **关键词扫描**：在提取上下文（关键词前后150字符）中搜索 high/low 关键词
2. **优先 high**：找到 high 关键词即判定 high（不再继续搜索 low）
3. **低关键词覆盖**：找到 low 关键词即判定 low
4. **默认 medium**：未找到任何关键词时，默认 medium

```
high 关键词命中 → high
│
└── 未命中 → low 关键词命中 → low
              │
              └── 未命中 → medium
```

## 如何提高整体准确率

### 1. 优化同义词列表

同义词越精准，提取到的上下文越相关：
```json
// 较差：同义词过于宽泛
{"synonyms": ["电压", "V"]}

// 较好：加入限定词，减少噪声
{"synonyms": ["工作电压", "供电电压", "VCC", "Supply Voltage"]}
```

### 2. 添加品类特定关键词

根据采购品类添加专业关键词：
```json
{
    "confidence_keywords": {
        "high": ["AEC-Q", "车规级", " Automotive Grade"],
        "low": ["仅供参考", "Typical Value"]
    }
}
```

### 3. 优先使用结构化文件

参数表 Excel > Word 表格 > PDF 表格 > 叙述性文本

结构化文件提取准确率更高，置信度也更可靠。

### 4. 定期维护关键词库

每次处理完一批文件后，将"待人工确认"Sheet 中发现的新表述加入配置。

## 置信度与待确认项的关系

| 置信度 | 是否进入"待人工确认"Sheet |
|--------|---------------------------|
| high | 否 |
| medium | 否 |
| low | 是 |
| —（文件未提及） | 是 |

进入"待人工确认"Sheet 的条目，需要在原文件中找到原始表述并人工核实后补充到主表。
