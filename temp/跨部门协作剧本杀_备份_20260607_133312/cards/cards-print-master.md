# 信息卡打印母版（18 张）

> 本文件是「跨部门协作剧本杀」中 18 张信息卡的**打印母版**。
> 培训师在打印时使用本文件，**每页一张信息卡**，**A4 横向双栏布局**。
> 18 张信息卡是**事实性背景资料**，不包含建议或分析。
>
> 培训师在游戏开始时按信封分发对应卡；玩家只读自己的信息卡。

---

## 一、打印规格

| 项 | 设置 |
|---|------|
| 纸张 | A4 横向 |
| 边距 | 上下 1.5cm，左右 2cm |
| 字体 | 思源黑体 / 微软雅黑 |
| 标题字号 | 14pt |
| 正文字号 | 10pt |
| 表格字号 | 9pt |
| 背景色 | 浅色（#F5F5F5） |
| 边框 | 1px 灰色边框 |
| 每页 | 1 张信息卡 |
| 装订 | 每张单独打印，1 份即可 |

---
