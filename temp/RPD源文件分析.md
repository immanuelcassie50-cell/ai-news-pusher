## 三、课程05核心内容拆解

### 课程05：技能图谱新范式：从岗位培训到技能驱动的学习体系

**课程定位**：
> 呼应"从按岗位培训转向识别驱动绩效的核心技能"这个行业判断

**一句话价值**：帮助培训团队用AI快速构建动态技能图谱，避免技能图谱变成脱离实际的空表格。

**核心训练内容**：

| 维度 | 内容 |
|------|------|
| **技能图谱构建** | 怎么用AI快速构建动态技能图谱 |
| **可迁移技能识别** | 识别岗位之间可迁移的核心技能 |
| **业务真实判断** | 在AI生成的技能建议基础上加入组织对业务的真实判断 |

**与其他课程的逻辑关系**：

```
课程05（技能图谱）
    ├── 是课程10（员工发展导向）的数据基础
    │       └─ 技能图谱 → 学习行为数据 → 个人发展路径
    ├── 是课程01（培训师角色转型）的具体落地工具
    │       └─ AI生成技能图谱 → 培训师判断 → 学习体验设计
    └── 支撑整个系列的核心判断
            └─ "从按岗位培训转向识别驱动绩效的核心技能"
```

**解决的核心痛点**：
- 传统岗位培训是静态的、以岗位为中心的
- 技能图谱是动态的、以技能为中心的
- AI可以快速生成技能图谱，但"组织对业务的真实判断"必须由人来完成

## 四、各课程之间的逻辑关系

### 整体架构：三层结构

```
第一层：培训师自我转型（课程1-3）
├── 课程1：角色转型认知框架（入口母课）
├── 课程2：人机协同边界与内容质检
└── 课程3：AI陪练脚本设计

第二层：核心场景AI化（课程4-6）
├── 课程4：AI领导力教练 + 人类教练聚焦不可替代部分
├── 课程5：技能图谱驱动（动态的技能管理体系）
└── 课程6：智能入职 + 管理者的有温度对话

第三层：效果落地与文化保留（课程7-11）
├── 课程7：培训闭环与ROI证明
├── 课程8：内容审计与信任建设
├── 课程9：组织级AI素养通识课
├── 课程10：学习数据 → 个人发展路径
└── 课程11：培训自动化中的师徒温度
```

### 关键逻辑链

1. **角色转型链**：课程1 → 课程2 → 课程3（培训师从内容生产者变为体验设计者）

2. **数据闭环链**：课程5（技能图谱）→ 课程10（学习数据）→ 课程7（ROI证明）

3. **温度保留链**：课程6（入职温度）→ 课程4（领导力温度）→ 课程11（文化保留）

4. **信任建设链**：课程2（内容质检边界）→ 课程8（内容审计机制）→ 课程9（AI素养通识）
