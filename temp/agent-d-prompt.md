## HTML质量标准（国际版权课水准·必须全部达到）
1. **印刷品质感**（衬线字体为主，金色装饰线，米色背景）
2. **SVG矢量图**（用于框架图、流程图、矩阵图、时间线）
3. **印刷支持**：`@page { size: A4; margin: 1.5cm; }` + `@media print`
4. **A3挂图特殊规则**：`@page { size: A3 landscape; }`（仅全景图）
5. **响应式断点**：720px（移动端单栏）、1024px（中等屏）、1280px（大屏）
6. **单一文件**（无外部CSS/JS依赖，所有样式内嵌）
7. **内嵌SVG**（无外部图片依赖）
8. **每HTML文件 ≤ 800KB**

## PPT质量标准
1. **128页**（位于100-160区间）
2. **16:9**（1920×1080）
3. **每页3-5个要点**（不堆字）
4. **视觉系统统一**（酒红/金/米色配色）
5. **讲师备注详细**（每页都有，按结构：【本页目的】【讲解要点】【案例/故事】【互动设计】【时间控制】【衔接】【常见问题】）
6. **关键概念用图示**（SVG流程图、矩阵图、时间线）

## Office文档质量标准
- **docx**：分章节、有目录、格式统一、衬线字体、可打印A4
- **xlsx**：含11个sheet、表头冻结、酒红表头+米色表内、表单可填写、checkbox、合并单元格
- **pdf**：A4/A3规格、视觉统一、SVG图标、分页合理
