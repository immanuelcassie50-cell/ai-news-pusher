# 组织统筹能力 - HTML可视化与数字工具包

> 课程七：组织统筹能力：智能体型组织里的新领导力技能

## 课程概述

基于德勤2026年全球人力资本趋势报告、麦肯锡关于智能体型组织的分析、IBM关于人机混合团队领导力的研究。
核心定位：训练"统筹"这项麦肯锡点名的关键新能力——既要围绕共同业务语境和成果对齐团队，又要判断哪些场景真正需要智能体介入，并在人与智能体之间建立信任。

**目标学员**：中高层管理者、HR负责人、组织发展专业人士

## 设计特点

- **浅底配色**：米白背景(#fafaf8/浅灰#f5f0e6)，深色字体
- **主色调**：专业蓝(#1A5F7A)
- **可交互**：点击展开模块详情、流程图决策树、导航搜索
- **打印友好**：支持A3横向打印，预设打印样式
- **响应式**：适配桌面和移动设备

## 使用方式

1. 直接在浏览器中打开HTML文件
2. 左侧导航栏快速跳转到各章节
3. 使用搜索框查找关键词
4. 点击模块标题展开详细内容
5. 打印时使用Ctrl+P，选择A3横向

## 核心内容结构

### 六大模块

1. **智能体型组织的本质** - 理解智能体类型、能力边界、组织新特征

### 三大核心能力

- 共同语境建立能力
